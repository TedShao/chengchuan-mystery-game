# 故事规范：你的离线时间

状态：2026-10-20，经过第二轮关闭指引的作者纸面反证后修订。**不是陌生玩家盲测，尚未证明好玩。** 当前事实以本文为准；可见材料、分支和逐步排演见 [SLICE](SLICE.md)，执行状态只在 [PLAN](../PLAN.md) 维护。未改游戏代码。

## 本幕现在讲什么

入职第 47 天，林见收到老学员罗青的消息：昨晚“他”说先别撤掉申请，她想确认这句话还算不算数。实际回复者是同事小雨，正常的课程代班被用在了课程之外。

林见可以马上问清、停用名字、拒绝继续接待。这些行动都有效。但罗青手上还有一个远桥发来的链接，对方说可以用它重开退出申请。打开后，页面却要求她确认把现有项目资金留到下一期。

**撤掉名字解决了一个真实问题；接下来是否继续调查，取决于玩家是否在意这个入口究竟发错了，还是本来就打算这样用。** 公司是否能安排远桥客服只作旁证，不再承担高潮。玩家可以早早发现链接问题，跳过身份调查；也可以拒绝再联系任何人，到此结束。

本幕保留公司电脑、罗青、小雨、周衡和自由探索。删掉转正填报、答疑会、收齐回执、“结束交班”总按钮、第二天排班与固定绑架结局。上一轮两个骨架的比较留在 Git 历史，不继续占据当前故事正文。

## 公司与工作的事实边界

澄川是境内财经内容与用户运营公司；知禾学堂是它运营的课程品牌；远桥是课程之外的投资项目服务品牌。真实授课、资料分发、课程退款与发工资都存在。澄川核心经营者同时为境外虚假投资团队引流、维系客户，并隐瞒这种协作。这不是一家没有业务的纯空壳。

| 人 / 岗位 | 日常工作 | 本幕可接触的范围 |
|---|---|---|
| 林见，24 岁，课程运营助理 | 上传资料、解决播放问题、接待课程学员 | 分给自己的会话、自己名片、公开网页、客户主动提供的材料；没有投资账户操作权 |
| 何小雨，28 岁，学习服务 | 代班、课程订单售后、把超出权限的问题交给主管 | 知道自己发过什么及收到的安排；看不到项目资金处理 |
| 周衡，36 岁，客户运营主管 | 分配接待、安排项目介绍、处理持续投诉 | 知道引流用途和两端联系安排；可以决定重发什么，不能读玩家本地草稿 |
| 罗青，39 岁，小店经营者 | 经营店铺；曾购买课程并接触远桥 | 自己收到的消息、自己的项目申请；不认识全部内部人员 |

林见待业三个月才找到这份工作。此前 46 天他确实解决过课程问题，4 月 7 日帮罗青恢复过播放。课程组可以借用学习助理名片代班，后台记录真实经办人。林见知道这种安排，**不能让熟悉自己工作的他假装完全不懂代班，只为陪玩家猜盗号**。

他此前没有参与罗青的项目事项。昨晚小雨以其名片作了承诺，再将课程会话交回他；今早第一次看见原本分开的事项。为什么没早发现，靠岗位及会话范围解释，不靠员工集体迟钝。

现实依据仍限于公开案例存在的境内引流、境外协作及分层组织；姓名、系统、链接及本幕安排均为虚构，不称为真实案件复刻。[2024 年典型案例](https://www.court.gov.cn/zixun/xiangqing/439351.html)、[2022 年典型案例](https://www.court.gov.cn/zixun/xiangqing/371131.html)。共用客服、境外地址和外包关系本身不足以证明犯罪。

## 人物要什么，为什么现在这样做

**林见**先想把自己的责任说清。他可以止用名字、帮罗青核实、先相信公司或离开。继续调查的理由应是刚看到的行为与承诺不相容，不是突然被赋予拯救所有人的使命。撤名不需要重新接手案件；更正误判也不等于同意继续工作。

**罗青**在远桥投入了两万元，这一金额目前只是她的陈述。她想退出，怕自己弄错步骤，既不愿无休止等，也不愿误确认继续。她信任林见来自过去一个具体的小忙；不会因陌生员工一句“诈骗”就全盘相信。她把链接交给林见是为了问昨晚的建议，不是专门给侦探送线索。她可以自己读懂页面并选择不确认，不需要玩家解救才有判断能力。

**小雨**想留住沟通，也不想承认自己承诺过满。她办成过罗青的课程退款，因此高估了公司处理另一项业务的能力。昨晚她只知道周衡说今天会有人接；没打开远桥的新入口。玩家直接问，她直接承认代班。若玩家把页面内容发给她，她会自己打开检查；确认页面要求继续后，她撤回对入口的推荐，追问周衡。她仍不知道投资后台，不能突然说完整犯罪真相。

**周衡**需要罗青继续留在项目沟通中。退出申请迟迟没有结果，远桥提供了继续参与的入口；他知道这个入口的用途，并把它当作维持客户的办法。他愿意撤掉林见的名字，愿意取消原链接的发送，但不会主动帮罗青完成退出。被具体内容质疑后，他改为安排项目人员解释下一期，而不是无休止坚持“只是重开申请”。这一次让步暴露了目标差异，却还不能证明完整诈骗网络。

周衡并不是把“犯罪自白”留在普通后台。他相信让项目方解释、保留客户意愿能被员工接受；真正在网页上暴露的是他打算促成的动作与罗青要的动作不同。不要在本幕追加销毁记录、定位 IP 或恶意暗号。

## 表二：角色认知与传播边界

| 人 | 开场所知 | 误解 / 隐瞒 | 什么会改变其行动 |
|---|---|---|---|
| 林见 | 自己的岗位、课程代班惯例、没有作过项目承诺 | 不知道新入口内容与主管目的 | 由实际打开、询问和收到材料取得信息，不由作者旁白宣布 |
| 罗青 | 自己想退出、昨晚建议、远桥新消息 | 以为一直是林见跟进；尚未确认页面里的继续条款 | 收到澄清后区分代班；看到页面后可自行拒绝确认；无依据的指控会使她要求出处 |
| 小雨 | 自己代班、主管答应有人接 | 以为新入口能处理问题，没看过页面 | 收到具体链接/页面内容后打开检查，停止替它背书；仅被问“是不是你回的”不会凭空知道页面内容 |
| 周衡 | 入口用途、两端安排、客户想退出 | 把继续参与包装成处理出口 | 收到对页面的明确质疑后改联系方式；仅撤名只处理署名，不自动得知玩家怀疑 |

**企业会话不是私密保险箱。** 课程会话标明团队可查阅；发给罗青不等于只有她永久可见。周衡接手或有人转发时可读到相应记录；他必须实际打开或接收后才反应。员工私聊、未发送草稿和本地笔记不自动进入团队会话。复制给小雨哪几项，她就先知道哪几项；有权限不等于全知。

## 表三：现有材料如何成为证据

| ID / 载体 | 初读解释 | 核实后的用途 | 证明不了什么 |
|---|---|---|---|
| E1 罗青的新消息及昨晚引用 | 她在找熟人确认步骤 | 承诺被归到林见；能找发送人 | 盗号、所有员工知情 |
| E2 代班详情与名片用途 | 正常课程组协作 | 解释谁发的；允许课程代班不等于项目担保 | 小雨知道新链接用途 |
| E3 罗青转来的远桥消息卡 | 对方提供退出的处理入口 | 固定是谁、何时、怎样介绍这个链接 | 页面内容正确、客户已经点击确认 |
| E4 链接的继续参与确认页 | 可能发错链接或流程令人误解 | 正文要求把现有资金留到下一期；没有重开退出申请的操作 | 法律效力、真实资金去向、公司必然涉诈 |
| E5 周衡的待发转发 / 对重发的实际回复 | 他可能也不知道链接错了 | 同一入口已由他选定；收到具体质疑后仍改谈下一期，说明当前目标差异 | 整个平台所有人共谋；仅草稿存在不能证明他已发给客户 |
| E6 本人名片状态及实际发送历史 | 员工自保或普通交接 | 停用、拒绝、撤回未发项、重新说明分别真实发生 | 撤销对方看过的内容或替客户作决定 |

不需要 P7 额外申请截图、转介页的边界声明或一堆预约回执才能发现核心矛盾。原来的“共用后台因此可疑”降为背景，删除“已核实”一词的语义考试。客户页面是游戏内只读材料，林见不能代她按资金确认按钮。

## 表四：竞争解释与可用的验证

| 解释 | 为什么合理 | 玩家可做的区分 | 尚不能下的结论 |
|---|---|---|---|
| 普通代班说过头 | 小雨有权限，也确实曾帮过忙 | 直接问发送者即可解决这部分，不拖成主谜题 | 此后入口一定没问题 |
| 远桥或周衡发错入口 | 客服复制错链接很常见 | 把页面要求继续的部分发给周衡，要求的是退出入口；观察重发或取消后的实际内容 | 重复一次链接就证明完整诈骗 |
| 继续参与是退出的必要步骤 | 可能存在玩家不了解的产品流程 | 问此操作是否会延长参与；查看页面有没有退出路径或条件说明，要求提供对应依据 | 没看到依据就断言任何现实产品都不可能这样设计 |
| 公司有意把退出诉求转成继续参与 | 周衡希望维持客户，能安排新联系 | 具体指出矛盾后，他撤掉原“重开”说法，改谈下一期且不处理退出；这是可观察目标变化 | 境外地点、最终资金控制和法律责任 |

本幕是调查行为与目的的悬疑，不伪装成“多个凶手中猜一个”的本格案件。玩家可以早猜公司有问题；真正需要验证的是具体安排，不能以猜到坏人就判失败。

## 表六：这次否决了什么，修订后还缺什么

| 维度 | 原稿问题与证据强度 | 本稿修订 / 未决风险 |
|---|---|---|
| 真相 | `explicit` 小雨代班；`missing` 单靠撤名后换接待有什么不能用正常外包解释的事 | 承认代班为小问题；固定入口及用途构成新的可核实矛盾 |
| 认知 | `explicit` 主管能接手；`missing` 为什么团队会话里发给客户的指控他永远看不到 | 区分收件、可访问、实际读到；接手可读该会话，不读私人草稿 |
| 线索 | `weak inference` 预约不能支持“已核实结果”，但原话没有明确说结果已核实 | 删除该推断；消息介绍与页面将执行的动作直接比较 |
| 动机 | `strong inference` 主管想维持接触；`missing` 玩家撤名后必须在乎接替者的理由 | 不要求必须在乎；给开场已有、关系到客户真实选择的矛盾，保留退出 |
| 场景 | `explicit` 结束交班才推进；`strong inference` 仍像办公待办 | 删除总按钮与回执高潮，动作分别生效，人物依据收到的信息行动 |
| 公平性 | 再加一封匿名警告会成为临时补丁 | 同一链接开场已存在；不随玩家选择偷偷改内容；错误说可以被验证 |
| 心理与现实感 | 若小雨一直说看不到，就成了阻挡器；若主管永远重发同一句，就像脚本 | 小雨拿到内容后真去看；周衡具体质疑后改变方案，不能停在口头辩解 |
| 结构 | 修订后可能仍被理解成“发错一个链接” | 必须检查第二次回应能否改变判断；没有真人证据，不能宣称修好兴趣 |

上一轮仅凭结构表就给予的乐观判断收回。旧稿主要成立为署名纠纷，持续调查动机不足；修订稿可继续排演，但体验结论仍未定。后续境外关联、资金调查及终局暂不扩写。
