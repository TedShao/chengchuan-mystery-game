# 《回来以后再联系》｜故事总纲

当前唯一故事基线，修订于 2026-10-21。完整剧透；文本尚未实现，未经过陌生玩家验证。已确定的方向：境内招聘公司、境外诈骗与人员受控、允许主角被骗出境的坏结局。结局必须由人物经历和实际选择产生，不能反过来逼人物行动。

## 先读这个故事

林见做过两年电商售后。原公司的业务收缩后，他失业了三个月，最后进澄川做招聘助理。工作谈不上理想，但工资按时发，同事也正常。他每天回复求职者的问题、调整面试时间，把录用和合同问题转给负责的招聘顾问。

澄川主要替本地电商公司招客服。林见见过真正入职的人，也处理过夜班、通勤和工资争议，因此渐渐相信：这里至少是一家做实际事情的公司。入职第三周，他看见孟宁负责的一份海外中文客服职位。那是自己做得来的工作，广告里的待遇又比眼下好。他主动问过，自己能不能报名。

孟宁没有把他升成海外主管，只让他按候选人的条件了解。林见当时没有决定。他刚找到工作，不想再折腾，况且出国不是点一下报名那么简单。这段询问留在自己的聊天里；以后去不去，是他的个人求职选择，不是招聘助理的出差任务。

入职第五周，他替同事接待陈平。陈平应聘的正是同一海外项目，曾为赶面试改过一次时间。林见只接待、转交问题，没有给他办出发手续。将近两周后，陈平去了国外。

故事开始于林见入职第七周。陈平的父亲先找过孟宁。她说岗位有调整，陈平不适应，正在协调。父亲想知道儿子实际答应了什么，按面试通知上的公司电话打来，前台查到接待人是林见，才把电话转给他。

“他说干的不是面试讲的那个活。你还留着当时那份招聘说明吗？”

林见记得自己交出去的介绍，也记得自己看过它。陈平当初想去，并不能反驳他现在后悔；真正值得核实的是，介绍中的工作和他现在做的究竟是不是一回事。这不只关系到一名求职者，也关系到林见曾经考虑过的下一份工作。

孟宁可以配合。她能转达问题、约一次联系，却不能让陈平随时自由通话。陈平在联系中说想回来，没有给出自己能落实的离开安排。林见可以相信这是尚未谈妥的用工纠纷，也可以问清岗位、联系条件和离开受阻的具体原因。一次没回电话不是拘禁的证明；“见到本人了”也不是安全保证。

为了核实招聘介绍中的经验是否可信，林见可以去找赵启明。赵曾由同一渠道出去，后来已经回国；他那段在岗介绍仍附在陈平收到的材料里。小雨认识他，只能替林见转达联系请求，不能交出他的私人聊天。

赵起初不愿再和澄川的人说话。林见若只是替公司索取一份好评，他会拒绝；若说明陈平的情况、出示仍在使用的那段介绍，他便有了回应的具体理由：他不愿自己的名字继续让别人放心出发。他可以只要求撤下介绍，也可以进一步说明自己的经历，不必先成为主角的盟友。

他首先说清一件事：“我不建议你去。那不是给电商店铺做客服。”愿意继续谈时，他会直说自己被要求参与诈骗、无法自行离开，不为了保留悬念把危险藏在第三轮问答里。真正的反转在后面：那段看上去正常的介绍确实是他发的，但发出时他已经在争取离开。他想让当地负责人觉得自己愿意配合，希望处境能好一点；没人因此兑现过“说好话就放你走”的承诺。

赵最终回来，是家人持续求助和交涉后，对方收取了其索要的钱，选择放他离开。这是这一个人经历过的结果，不是正常离职，也不是可复制的赎人办法。赵及家人已经向有关部门反映情况，返国不意味着全链条调查同时结束。他现在仍不愿把经历公开给所有人，尤其不愿面对那些曾相信他介绍的人。

赵回国后找过孟宁，明确说过实际工作、离开受阻，并要求别再用他的介绍。事情没有解决，他又把同样的情况发给了郑立。两人的答复分别留在赵自己的往来里。它们并非一份写着“我们知道这是诈骗”的秘密文件，而是接到具体指控后，选择如何处理当事人、是否撤下介绍的实际回应。

林见自己的发件记录补上了赵没有的一段：在这些反馈之后，陈平仍收到原岗位承诺和赵的介绍，项目负责人仍把它用于招募。赵知道自己投诉过，却不知道后来谁还看过那些材料；林见知道自己发过什么，却此前不知道有人要求停止使用。两个人的资料接起来，问题才从“境外出了事”变成“公司为何收到明确警讯后仍继续这样招人”。

这仍不是一封邮件足以替司法机关定罪。公司可能辩称自己相信了合作方。但它已经无法把所有事情说成第一次听说，也无法把林见的接待当成与后续结果完全无关的工作。

郑立的应对不是突然坦白。他愿意停这一批招聘，撤掉相关介绍，帮家属联系境外；他要避免更多投诉影响真正赚钱的国内业务。这些让步可以是真的。林见也可以接受帮助，同时继续提供事实、与当事人独立求助。公司能停国内招募，却不掌握境外放人的决定，不能用一个“已处理”勾选结束陈平的处境。

从这里开始，结局分开。林见把自己经手的承诺与当事人的反馈交给能采取行动的人，停止无依据的保证，可以阻止更多人按同样的说法报名，并帮助查清国内责任。陈平的去向、能否脱离以及何时回家，仍要经过外部调查和协助；好结局用一段明确的时间跳转，落在父亲终于接到不由公司安排的电话上。

林见也可以只退出、不再参与，留下一次有限的纠正。作品承认这是一个可以理解的选择，不用绑架惩罚他。

出境的坏结局发生在另一条较早分开的路线：林见只确认了陈平能接电话，接受“个别人不适应”的解释，没有接触到具体受控经历，继续了自己原有的求职打算。他按海外客服候选人的身份申请，明确离开国内助理岗位，又在出发前选择继续。之后被欺骗、转移和控制，才形成“到岗通知”的结尾。已经查明危险的林见不会在主线末尾忽然接受同一邀请，也不会被公司以“去现场核实”为名派去救人。

## 一、公司与主角的关系

澄川人力资源服务有限公司是一家虚构的十余人公司，主营本地电商客服招聘。企业客户支付招聘服务费；实际入职后按约定结算。澄川不是这些客服的用人单位，不负责发其岗位工资，也不是劳务派遣公司。

| 部门 / 负责人 | 实际工作 | 海外项目中的位置 |
|---|---|---|
| 郑立，负责人 | 客户合作、经营决定、重大投诉 | 收到赵的具体反馈后继续合作；有权停止国内招募，没有权力命令境外放人 |
| 国内招聘组，何小雨等 | 招聘需求、面试安排、国内入职回访 | 大多不接触海外项目实情；小雨知道赵回来，不知道他交给主管的具体陈述 |
| 孟宁，项目主管 | 招聘介绍、候选人沟通、录用衔接 | 负责海外项目；知道实际工作与招聘承诺不符，并已获受控、涉诈的具体反馈，仍维持招募 |
| 林见，招聘助理 | 基础咨询、预约、接待、发送指定职位资料 | 前四周主要做国内岗位；第五周起协助少量海外初面。只看自己经手的资料和正常岗位介绍 |
| 行政、财务 | 考勤、发薪、按批准资料结算 | 不能从知道海外项目收入推定知道受控事实；不替玩家提供全知账本 |

对外职位称为泰国中文电商客服，境外合作方负责后续雇佣安排。作者真相是：这一渠道向缅甸境内的诈骗经营团队招人，候选人之后被欺骗转移、限制自由并被迫参与诈骗。国内公司收取招募协作报酬，不经营整个园区、不掌握全部资金与人员位置。本稿不描写转移路线或控制方法。

“合作方负责”只是公司的说法，不能替代应有资质或证明实际工作合法。岗位资格、真实雇主、工作地点、受控事实需要分别核实。现实依据与虚构边界见 [REFERENCES](../research/REFERENCES.md)。

**林见出境的关系必须写清：**他先主动咨询，后来才可能辞去国内助理工作，转为报名海外客服的候选人。孟宁利用的是他对公司的信任和原有客服经历，不是突然赋予新人海外管理能力。公司没有为卖他专门养七周；国内助理原本就有正常用工需要，他也可以一直留下。只有他主动求职且公司仍认为他信任该项目时，才会发生招募衔接。掌握并质疑核心事实的员工不是值得额外冒险送出去的对象。

## 二、人物需求与知识

| 人物 | 要什么 / 为什么现在行动 | 实际知道什么 | 会隐瞒、拒绝或误解什么 |
|---|---|---|---|
| 林见 | 稳定收入，也希望回到熟悉且待遇更好的客服岗位；陈平让个人选择变成现实问题 | 自己咨询、发件、接待和实际收到的反馈 | 对国内工作的信任不能证明海外岗位；未读与已知不能被剧情混同 |
| 陈平 | 离开并自由联系家人 | 自己经历的工作和限制，不知国内责任分工 | 联系条件影响能说多少；不靠密码台词替作者慢慢放答案 |
| 陈志远 | 确认儿子原本答应的工作，取得可用的帮助 | 本人消息、孟宁解释、面试通知 | 已在向外求助，不等林见查完全案；不会因一句“没事”取消所有求助 |
| 赵启明 | 停止以自己名义继续招人；保护家人和隐私 | 自己受控、求助、返国及向两位负责人反馈的经过 | 不掌握陈平现址，不知后来谁收到介绍；愿谈时先说明危险，不故意卖关子 |
| 何小雨 | 完成国内招聘，不替陌生项目作保证 | 自己接待过赵，知道他回来；未收过详细求助 | 可转达联系，不能替赵透露经历；看见具体事实后才改变协作 |
| 孟宁 | 保住收入、解释权，减少公司和候选人追责 | 在陈平入职前已获具体涉诈与受控反馈，知道自己仍使用旧介绍 | 可以承认收到反映、辩称曾信合作方；不会在对话里自称犯罪共谋 |
| 郑立 | 保国内经营、降低曝光及损失 | 收到赵直接转交的同类事实，仍批准继续合作 | 可真停项目并善后；不能保证境外结果，也不能删掉当事人的自存记录 |

赵的推荐与返国是两件事：推荐发生于受控期间，返国另有实际过程；不能用时间先后暗示他靠“带来下一人”交换自由。公司归还费用或停止项目，也不自动解释所有既往责任。

## 四、读者应如何逐层改变判断

| 段落 | 可行动的问题 | 核实后改变的认识 | 不能跨过的推论 |
|---|---|---|---|
| 1. 我交出去的那份工作 | 陈平答应做什么？现在说的不一样具体在哪里？ | 林见既是资料经办者，也曾考虑同一职位；有理由认真核实 | 面试积极不反驳后来后悔，不能据此判孟宁撒谎 |
| 2. 接通以后 | 他能否在自己方便时联系、能否落实离开？ | 接通没有解决父亲真正的需求；需要具体事实而非语气判断 | 一次沉默或没回电话不证明拘禁；足以担忧时不必等定罪证据再求助 |
| 3. 回来的人说了什么 | 推荐是否仍可代表赵现在的意见？为何不愿再被引用？ | 真实的人也可能在压力下说过安抚话；正常推荐的外观被重新理解 | 赵参与过不等于自愿获利；他自己的经历不自动证明陈平处在同一地点 |
| 4. 谁在什么时候收到过 | 赵反馈了什么？谁回应过？之后陈平收到的又是什么？ | 两份原本各自合理保存的记录相接，支持公司事前收到具体警讯仍继续承诺 | 单次广告失实、一般投诉或已读不能直接等于明知全案；郑立单独核实 |
| 5. 愿意停下为什么还没结束 | 哪些招募真的停了？哪些人已出去？善后承诺实际做到哪里？ | 停止未来招募与查明既往、帮助已出去的人是不同事情 | 不能为继续调查制造新事故；接受帮助不等于放弃独立求助 |

资料减少时允许较窄结论。赵拒绝交出往来，玩家仍能处理陈平的安全担忧，但不能凭空获得“两位负责人事前收到具体反馈”的完整证明。后续调查可以拓展事实，不能回头把玩家未完成的推理算成完成。

## 五、线索、对照与责任判断

| 线索 | 初看含义 | 核实方法与回收位置 | 证明边界 |
|---|---|---|---|
| C1 林见自己的职位咨询 | 普通换工作打算 | 开场可读；与陈平收到的同岗位介绍对照 | 建立个人关联，不强制玩家选择出境 |
| C2 发出的面试通知、附件与改约 | 普通接待工作 | 第 1 段定位原岗位；第 4 段取实际发送版本和日期 | 证明林见经办内容，不证明他知道境外真相 |
| C3 家属消息及实际联系 | 岗位不符、希望回家 | 问具体工作、独立联系及可落实的回家安排 | 支持担忧，不用一次失联或一句语气确定犯罪地点 |
| C4 赵的在岗介绍与自愿说明 | 返国前辈的经验 | 询问本人、停止自己未发送的引用；赵自行决定纠正范围 | 说明推荐不能代表自由选择，不把受控者定为同谋 |
| C5 赵给孟宁的具体反馈与回应 | 当事人求助、要求停用 | 看本人提供的原会话和上下文，再与 C2 对照 | 针对具体事项的答复比已读强；资料有疑点可继续核对，截图不自动确证 |
| C6 赵给郑立的单独反馈与回应 | 升级给负责人的投诉 | 单独核对内容、身份与先后 | 不能从孟宁知道推定郑立知道；不能仅靠抄送列表 |
| C7 实际取消、纠正及后续联系 | 公司善后 | 对照通知送达、候选人回应、陈平后续联系 | 停项目能是真的；并不等于过去从未发生，也不证明陈平已自由 |

核心链条：原承诺与具体经历不符 → 有足够理由求助和核实 → 赵提供同渠道亲历并纠正推荐 → 当事人反馈的具体内容、真实接收与招募先后相接 → 有理由调查管理层在严重警讯之后继续合作的责任。境外地点、全部组织关系和法律责任留给外部调查，不用一句主管“承认了”包办。

| 对象 | 动机、机会、手段 | 合理竞争解释 | 区分的事实 |
|---|---|---|---|
| 赵 | 想脱身，发过推荐，知道自身经历 | 羞耻、畏惧和受控配合，不必是主动招募 | 自己承认的发送情境、返国过程、此前纠正请求 |
| 小雨 | 完成国内工作，认识部分求职者 | 只知回国，不知受控 | 实际收件和她经手的工作，不能看职位猜心思 |
| 孟宁 | 招募收入与项目利益，有编辑和联系渠道 | 曾误信境外解释 | 警讯是否具体、是否实际收到，以及之后继续发了什么 |
| 郑立 | 保经营，能决定合作和暂停 | 事后才知道或正在合理处理 | 独立于孟宁的原往来及当时后续安排 |
| 境外合作方 | 提供虚假职位并控制人员 | 正常岗位调整、用工纠纷 | 当事人明确工作与限制的经历，结合调查；不以“在境外”判定 |

## 六、结局先后与条件

这不是一条路走到最后选三种结局。**完整调查路线、有限退出路线、早期误信后的个人求职路线，在不同位置分开。** 系统不能用隐藏的“正确率”替代这些事实。

| 结局 | 实际形成过程 | 最后看见什么 |
|---|---|---|
| 回来以后再联系 | 具体事实送达能行动的人；林见停止无依据保证、提供自己经手记录；外部调查与协助继续 | 明示时间跳转后，陈平能自主给家人打电话。国内招募处理和其后续情况分别交代，不保证所有人同日回国 |
| 我不做了 | 拒绝背书或离职，按实际范围纠正和转交；未选择个人海外求职 | 已通知的人收到更正；没确认的人员状态仍未知。不是因退出而遭惩罚 |
| 到岗通知 | 在较早阶段仍误信项目，未获具体受控信息；继续本人原有海外客服求职，离开国内助理岗位并选择出发 | 后来被欺骗转移、受控；熟悉的通信页面上出现被要求发出的报平安草稿。它重现赵的处境，不是“查得太多所以被灭口” |

### 坏结局必须补齐的四个因果环节

1. **原本为什么想去：**林见有电商售后经验，失业后转做助理；同项目广告让他看到回到熟悉工作并改善收入的可能。先有本人询问，再有陈平事件，不用临终前突然加债务或家人重病逼出国。
2. **为什么没有被陈平劝退：**他只确认了接通，接受“个案不适应”的解释，并主动停止进一步核实；赵的真实处境与事前具体投诉尚未进入他的实际知识。不得把已明确获悉诈骗受控的主角又写回毫不知情。
3. **公司为什么接受报名：**他主动申请的是同类客服职位，有相应经历；国内助理可以正常离职补员，海外合作方仍在招人。不是海外负责人缺席后临时把新人派过去，更不是用救人、公务考察或岗位培训作强制出差理由。
4. **怎么走到出发：**玩家明确提出报名，收到具体求职安排，决定离开现职，经过可见的数日间隔再确认继续。其间能取消、核实或改变打算。是否做过安排与是否实际出发分别记录，不因回邮件自动跳到园区。

一旦收到赵的明确受控经历，或收到可核对的同类具体警讯，剧情转为核实风险；即使玩家尚未向公司表态，也不能继续把他描述为“不知道”。公司只有在收到其质疑、退出等实际信息后才改变对他的态度，不能读私人草稿。此时不续写同一条受骗出境结局；玩家可以继续核实或退出，不强加一个“我就是要去”的冒险选项。

家属担忧、岗位不合适和未接来电本身不等于充分知情，但也不应被旁白轻描淡写。出发前仍列明哪些事实没有核实，人物作出的选择有其错误判断，责任仍属于欺骗与控制者。

## 七、读者视角的因果复核

本轮审查的是完整梗概及场景设计，非成品试玩。表中“明确”表示文本已写清，不等于现实案例或体验已证明。

| 严重问题 / 原来缺什么 | 修订后的闭合方式 | 证据等级与残余风险 |
|---|---|---|
| 助理为什么突然赴海外；公司为何送他 | 改为有原职业经历的个人求职，早期询问、误信、离职与出发连续发生；去掉海外协调岗 | 因果已明确；职位吸引力仍需读者检验，不能靠三次点击冒充动机 |
| 已查明危险为何还被骗 | 出境线提前分流；具体警讯进入本人知识后结束该受骗路线 | 明确；必须与公司是否知情分开，不能读心 |
| 面试时想去为何是矛盾 | 父亲改问实际岗位；积极面试与后悔不再承担证据作用 | 明确；开场只能产生具体疑问，不可直接定罪 |
| 赵为什么能回、为何不先求助 | 写清家属求助交涉和此次放人结果；他已反映情况，不等主角才知道求助 | 作者事实明确；非行业通则，需避免把付款写成可靠营救方法 |

| 公司收到一般投诉就等于明知诈骗？ | 反馈包含具体工作与限制；两名管理者分别收到并针对性回应；再与实际后续招募相接 | 明确支持调查，不替代司法结论；不把已读、抄送或语气当证据 |

| 家属已经求助，玩家是否多余 | 家属有处境信息，林见有实际招募版本与经办事实；两者互补，玩家还可停止自己的后续承诺 | 明确；不是“警方等玩家破案” |
