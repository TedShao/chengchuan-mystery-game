# 故事规范：你的离线时间

状态：2026-10-20，本轮否决“双身份足以推动公司调查”的结构假设。**仅保留局部冲突，暂不作为完整悬疑片段的实施依据。** 已知真相的作者纸面反证不是真人盲测。操作与逐步记录见 [SLICE](SLICE.md)，重选核心事件见 [PLAN](../PLAN.md)。未改代码。

## 当前保留什么，撤掉什么

入职第 47 天，林见收到老学员罗青的消息：昨晚“他”叫她先别撤掉申请，她来确认这句话。实际回复者是小雨，正常课程代班作出了超出课程服务的承诺。罗青拿到的“重开退出申请”入口要求继续参与；周衡又可能把“只回复退出问题”转述成“愿意了解下一期”。这些足以形成署名越界、入口不符和失实转述的局部冲突。

**撤掉后半段：**周衡以项目身份复述自己的摘要，再引用回课程端，靠玩家查到同一账号制造反转。原文没有明确承诺存在另一方独立审核；“项目回的是这条”也可以是对代运营渠道的普通称呼。不能把作者期待的独立性先塞给玩家，再把它推翻当揭示。

同一个人代回两个品牌保留为正常业务背景，直接问就回答，不隐藏在必须破解的来源链中。失实转述被指出后，停止和更正有效。本片段可以到此结束。**“停发后仍会想查整个公司”没有足够结构依据，本轮不再声称已经修好这个动机。**

自由办公、名片停用、引用发送、已有消息留痕与按收件范围回应保留。转正填报、答疑会、回执验收、总交班、连续转问、双身份自证和强制下一任务均不属于当前主线。
