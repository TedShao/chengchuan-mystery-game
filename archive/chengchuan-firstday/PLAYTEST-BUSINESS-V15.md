# v15：更正汇报之后，为什么还要查

## 本轮试玩方法

从新浏览器存档进入，关闭工作指引。先读罗青的来信和历史，跳去共享摘要与表格，再提交个人稿、收窄共享引用；没有按工作向导的顺序走。随后直接问主管公司为什么处理平台款项，误以为个人资金付给本公司，再改口询问委托关系。沿回复链接索取财务范围与介绍原话，第二天拒绝窗口安排、跳过现场培训，继续核对本人工作和旧记录。

这是开发者以新玩家视角进行的认知走查，以及实际界面操作回归；开发者知道设定，不是独立玩家盲测。验证了入口和后果可达，不能据此宣称所有玩家都会产生追查欲望。

## 发现与修改

| 实际问题 | 修改及意图 |
| --- | --- |
| “我们不是做课程的吗，为什么还要管平台的钱？”被当作催款，只说没有到账确认。 | 增加业务范围话题。周衡说明课程与持续服务的关系，唐婧只讲本公司服务委托，何小雨只讲介绍和转交。可通过普通文件链接核实，不给犯罪结论。 |
| 共享更正像故事结束；没有解释为何还有后续事项。 | 更正后周衡发送服务窗口说明：收窄案例并未终止原服务委托。个人稿与共享更正使用不同措辞，不虚构同步修改。 |
| 可读的费用说明缺乏委托对象，境外关系仅靠口头标签。 | 将合同项目栏节选放在已有费用附件里，说明委托方、国内承接方和服务类别；原件明确不含用户个人资金流水，内部境外归档不等于独立核实境外实体。 |
| 玩家可能只把服务范围当作另一个待办。 | 周衡提出下周国内窗口安排，玩家需要知道可能替谁做什么；可先问或拒绝。接受才产生实际交接清单，拒绝仍可核对自己经手的记录，不用为了调查先接手。 |
| 罗青为什么回到课程客服缺少当事人的解释。 | 玩家发信询问时，罗青才讲自己的理解：课程方介绍了联系，自己以为后面仍是同一项目的服务。不知道内部委托关系，也不读玩家的私人稿。 |
| 小雨能谈到没有发给她的私人项目拟稿。 | 检查实际收件人范围，仅共享线程或确实附送的拟稿才进入她的回应。 |
| “不接窗口还能查吗”复述整段介绍经过，没有回答当前问题。 | 先回应可以核查，再根据是否已经提供材料指向旧记录或索取入口；去掉让同事联系她自己的链接。 |
| 拒绝后确认框仍覆盖工作页面。 | 所有安排确认完成后关闭对话框；重复答复不重复发邮件。 |
| 协作复核的工作范围回复署名与提示人不一致。 | 范围问题由唐婧回复；动作/结果由小雨回复，邮箱和通知一致。 |

## 实际分支后果

- 仅修改个人稿：只发个人稿收悉及服务范围说明，不把共享摘要假装改掉。
- 修改共享稿：引用同步到修订版；后续服务问题仍存在，个人汇报不必重做。
- 漏看罗青、提交普通案例：不捏造调查知识；第二天业务安排仍有正常来信，能完成培训和本人复核。
- 接受窗口：发出确认，周衡回复，小雨提供三类工作交接原件。本周客户跟进归属和境外意向保持各自记录。
- 拒绝或先核范围：窗口留给小雨，询问和旧材料不锁死。接受后再拒绝保留已发生的交接邮件；不改写历史。
- 误认“个人两万就是本公司收入”：财务明确文件无法支持这个判断；改口仍能询问委托方，不触发惩罚或自动结论。
- 私人阅读、普通聊天：只改变阅读与话题记忆，不代玩家接受任务、发邮件或获得受限原件。正式询问实际保存问题、附送资料及回信。

## 尚不能证明的部分

本章只推进到第二天上午/午休，不用一份委托节选证明完整犯罪链。自由输入仍是有限语义和设定回复，未接入 AI。是否足够吸引真正首次接触的玩家继续调查，需要独立盲测；这次保证的是疑问有具体来源、可核实路径和不会被拒绝安排切断的后续。
