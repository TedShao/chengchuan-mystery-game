# 网页片段：替你说的话

状态：2026-10-21，对 [bd1d22f](https://github.com/TedShao/chengchuan-mystery-game/tree/bd1d22f95ba76d209841a5e614ffec99644a94ca) 做无指引、非预设路线纸面复查并删改。作者已知底稿，以下限制每步可用信息，不冒充真正陌生玩家。**局部伪装可识别，公司调查衔接尚未成立。** 无真人、网页运行或代码修改。

## 先重建证据，不把作者计划当发现

| 审稿类别 | 从旧稿提取的内容 | 判定 |
|---|---|---|
| 事实 | 顾成代班并明确否认雇佣关系：explicit | 支持这一处有意伪装 |
| 认知 | 沈航不知坐席身份：explicit；知道更正后还想调查公司：missing | 不能由 NPC 替玩家延长调查 |
| 线索 | 原问答、操作者、本人头像：explicit | 原问答与操作者承担局部证明；头像只承担个人牵涉 |
| 动机 / 机会 / 手段 | 顾成有权限、想留客户：explicit；公司将欺骗作为付费业务：仅作者层 explicit | 正常工具与项目归属不足以区分个人越界、公司批准 |
| 场面 | 内部接管、改卡、披露、停代发：explicit | 不是强制顺序，但并列呈现仍像复杂客服控制台；部分动作重复承担相同表达 |
| 验证 | 停止有效、更正可送达：explicit；此后可操作的公司分歧：missing | 应允许结束，不能拿“还能搜索历史”当继续动机 |

## 旧稿完整反路线：先允许合理结束

| 路线 | 所见 → 自选动作 → 回应或状态 | 当步判断与结束点 |
|---|---|---|
| A 直接问顾成，不读前文 | 复访、我的头像 → “昨晚谁用我的号？” → “昨晚是我” → 不接、要求停用 | 合法代班仍足以解释已见内容；可以离开。不能替玩家写下一步必读否认句 |
| B 只看半段 | 看到“小林取过钱” → 想到顾成可能说自己经历 → 不作保证，结束自己接待 | 未见关系问答，不足以证明假独立；也没有被迫做调查的理由 |
| C 先回复，不看历史 | 员工身份送达 → 沈航问是否换人 → 玩家只答现在由我值班 | 沈航仍可把两人分开；必须实际告知昨夜关系才改变其认知，身份卡不是测谎器 |
| D 全读后直接问并更正 | 明确否认 + 顾成发送 → 确认局部撒谎 → 要求更正、停止代发 → 均落实 | 局部问题结束，“顾成个人撒谎”仍成立；没有证据自动转成公司制度 |
| E 拒绝接手，但读历史 | 不回复、停用代发 → 自行查原文与操作者 | 可以知道过去被骗过，但沈航不自动得知。还愿不愿查是开放选择，不是任务缺一项 |
| F 自己更正，沈航离开 | 原文已明 → 说明真实关系 → 沈航取消预约 → 本席停用 | 现实诉求解决，没有理由让沈航反复追问同一句来维持悬疑 |
| G 自发按“同学交流”搜索 | 分类及远汀归属 → 查看本席已有目录 | 原稿没有规定一个能区分个人越界与公司业务的结果；不能把搜索操作本身记作成功衔接 |
| H 先错判、后改口并重复 | 把代班当诈骗 → 收回笼统指控 → 另见具体否认 → 更正已发解释 → 重复暂停 | 应分别纠正两个判断；重复与改口不生成额外证据、损失或角色失忆 |

D、F 是主断点：本案比旧退款案多证明了一次明确撒谎，但**没有因此获得一个能区分公司业务与个人越界的后续行动**。玩家仍可能因头像被用而追问，那是可观察的个人动机假设，不是纸面已取得的行为结果。

## 修订开场：少解释，只给生活与值班位置

> 失业三个月后，你进了澄川，负责课程服务。今天是第 47 天。昨天六点下班，夜间由组里代班。

删掉开场“你没投过远汀、你不操作钱”的定向说明：前者提前提示如何读获利话，且不能证明顾成经历为假；后者是已退役退款案的多余边界。岗位权限仍在设计层约束，不要求玩家先读一遍。

沈航：

> “昨晚跟我聊的那个人今天在吗？我还有一句想问他。”

打开对话就能见到熟悉的头像与“小林”昵称；正常详情可查昨夜接待顾成。旧名片与分类可看，不高亮为犯罪线索。可以直接问人、回话、看前文或停止，不弹操作清单。

## 原对话保留，但不让它自动解决公司问题

原记录从开场可读，属于真实已发送会话；普通消息详情标示顾成操作。以下只精简人物语气，不改事实：

> 沈航：我想找个自己做过的问问，别再转介绍项目的人了。
>
> 小林：你想问什么？
>
> 沈航：你也在澄川上班？
>
> 小林：不在。我也是上课才知道的。
>
> 沈航：你自己取过钱吗？
>
> 小林：取过一次，后来才又放进去。

删去旧稿沈航第二次概括“所以不算问销售”的台词，避免人物替读者复述推理。第一次明确问雇佣关系已经够用。获利句保留作人物当时关心的事，不能偷换成已证明虚假收益。

原问答 + 实际操作者支持顾成这次有意伪装；公司的接待分类、客户归属和允许代班都不能单独证明其批准伪装。完整读过也允许止步于个别员工越界。

## 把设置流程改成直接回应

不再把“内部接管 / 改身份设置 / 发身份卡 / 解释身份”列成一套主要玩法。状态区别留给实现，玩家只需做有意义的联系决定：

| 玩家动作 | 明确反馈与底层效果 | 不替玩家做什么 |
|---|---|---|
| 在原会话直接回复 | 草稿上方显示将以“林见 · 澄川课程服务”发送；发送时同时接管当前对话并显示身份 | 不另发一张空名片；不自动补关于昨夜的解释 |
| 停用本席代发 | 本席其他代班新发送停止，历史可读 | 不向沈航解释原因，不取消他的预约，不换席绕过 |
| 向顾成提出问题 / 要求更正 | 消息实际发送后，他按收到范围回应；代更正需具体授权 | 不把他承诺“我来说”当作已送达 |
| 结束自己的项目接待 | 不再安排本席接续，普通课程工作可保留 | 不等同全公司停业；也不锁历史调查 |

停用后仍可由本人发单次真实说明，不恢复组内代发。若自由办公允许改个人设置，设置本身不触发沈航回应，不作为推进任务。正文内容允许口语与省略；实际告知了哪些事实才决定回应，不要求照抄一句更正模板。

## 回应到哪一步就知道哪一步

| 情况 | 人物可说的话 / 具体事件 | 限度 |
|---|---|---|
| 只问顾成昨晚谁回的 | “我回的。你要是不接，就先停了。” | 不额外讲身份问答或公司计划，不迫使接手 |
| 只发了员工身份，没说昨夜是谁 | 沈航：“换人了？我想找昨晚那位。” | 只问一次；不能自动知道顾成，不能循环触发同一句 |
| 已说明昨夜也是公司员工，尚未回应原否认 | 沈航可引用原问题：“可我问过是不是公司的人。” | 指向同一已有原话；只有这个未回应分歧才有此追问 |
| 已完整更正昨夜关系 | 沈航：“那今天不用安排了，我不想再听介绍。”他请求取消预约，操作落实后结束 | 允许当事人满足于离开，不给玩家追加调查任务 |
| 玩家仅给出怀疑、没有事实 | 沈航：“那你先问清楚吧，别替他保证。” | 预约不自动取消，对方不因玩家怀疑立即相信全案 |
| 玩家授权顾成更正 | 顾成可实际发送：“昨晚是我回的，我在澄川做项目。之前那句‘不在’更正一下。” | 这是处理已指出的问题，不是揭露公司全案；沈航收到后按同样事实反应 |
| 完全拒绝参与 | 本席停止状态保留，玩家可自由办公或结束 | 不生成追加受害事故、假冒恢复或同事代查送答案 |

更正后的局部收尾不是认定公司清白，也不是主线通关。这里没有足够的新事实让下一段调查成为可玩的分歧，必须如实留空，而非要求主角自己说“我要查清公司”。

## 误判、改口、重复与实际发送

- “顾成代班，所以公司诈骗”需要撤回；“顾成对这句关系问询撒了谎”可由具体记录支持。两者不能互相吞掉。
- 若先给沈航发过“已经核实没问题”，后来更正时，他可问“你刚才核实了什么”。实际说明有限范围后不循环追问，不强制再次索证。
- 私下改判断或换头像不改沈航记忆；实际发送的更正才改变已知。已读与未读分开，离线时不即刻出现对话。
- “我不接了，但昨晚到底谁说的”分别执行停止与问题；不把拒绝解读成撤销所有询问。
- 停用重复执行只返回已有状态；本人回复接管当前对话，不替本席其他历史会话批量发身份通知。顾成只能知道收到或实际查阅的内容。

## 删后同路复查与未解决的问题

| 路线 | 修订后结果 | 判定 |
|---|---|---|
| 直接问顾成后拒绝 | 不必先接回或改卡，停止生效；有限信息仍可按普通代班理解 | 去掉虚假前置，不强制出现真相 |
| 直接回复 | 一次发送同时接管及展示身份，沈航按实际内容回应 | 减少设置操作；发送没说明昨夜就仍不知昨夜 |
| 只看半段 | 不自动补关系否认，可以保留“同事讲自己经历”的判断 | 信息公平，不把漏看当错题 |
| 更正后停用 | 沈航可取消并结束，顾成可配合，局部冲突收尾 | **公司调查衔接仍缺失，不标通过** |
| 拒绝对外联系只读历史 | 本人可知局部撒谎，对方保持未告知 | 不把调查与继续接待绑在一起 |
| 误判改口重复 | 更正按收件更新，已回应的问题不循环，重复不造事件 | 只验证纸面状态一致，不是真人可用性证据 |

**本轮决定：**保留原问答对局部撒谎的证明，删掉五项身份设置作为主要玩法、重复解释台词、按分类搜索的自动续查承诺。原稿本已允许自由顺序，本轮不是声称它强制五步，而是削减它让玩家理解和操作的设置负担。公司调查回 R01/R02：需要能区分“个人越界”和“公司业务”的具体行为冲突，不能只补更多同类聊天、换一个坏员工或让停止失效。

局部可以继续做理解观察，完整公司片段未就绪。真人可能因个人身份被用而继续，也可能合理离开；不能把两者预写成结果。状态见 [PLAN](../PLAN.md)、[H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
