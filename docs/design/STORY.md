# 故事规范：还有谁在听

状态：2026-10-20，R01 两案比较后选定本案，R02 完成纸面动作与反路线设计。**这是待陌生玩家验证的候选，不是体验已通过或可直接扩章的批准。** 替换《你的离线时间》及罗青、双身份结构；旧稿留在 Git。当前只做一个短片段，未改代码。屏幕、材料和实际后果见 [SLICE](SLICE.md)。

## 两个核心事件，先比较再选择

### A《退款来自下一位》：已经收到的钱，究竟是谁付的

主角是售后助理，昨天向一位退出者承诺替她跟进到账。今早她感谢退款，另一个首次接触项目的人却拿着自己的付款说明来问为什么收款人不是公司。两人的材料指向同一笔支付：一方以为拿回投资，另一方以为把钱交给项目。公司解释为合作方垫付。

玩家要区分合法代付、错误收款与以新投入支付旧退出。可以先阻止第二笔、向财务追问，或拒绝经办；已经发生的第一笔仍可调查。若成立，下一问题是“项目真正产生过回款吗，谁在安排资金来源”，而不是改退款状态。局部代价是暂缓会让尚未收到钱的人继续等待；不能要求玩家为了取证放行付款。

**主要短板：**两张不同银行回单未必有可直接对应的编号，金额相同不能证明同一笔；需要当事人许可、收款账户和财务资料，才能排除正常代付。十分钟很容易花在核对和申请权限。未补齐这些前提，不写成已经查明的资金骗局。本案本轮落选，不展开成第二份并列剧本。

### B《还有谁在听》：课堂里的假设，被谁活成了亲身经历

主角是课程内容助理，上周制作过一张标明虚构的到账示意图。今早临时接手课后讨论的素材核对，看见“老学员陈姐”昨天已经把裁掉说明的同一张图说成亲历；真实学员唐雯正在据此判断要不要保留已经约好的项目咨询。下一条进一步保证可以退出的消息，尚未发出。

玩家可以停发，可以直接问同事，也可以只处理图片。核实的重点会从“图用错了？”变成“一个不存在的到账经历为何要被包装成同伴经验？”再到“免费课把相信这些经验的人送给谁？”真实课程、制作人员和接待人员都存在，虚构的是投资经验；玩家自己的正常工作正为这种经验提供可信外观。

### 比较与取舍

| 检验 | A 退款来自下一位 | B 还有谁在听 |
|---|---|---|
| 开场吸引力 | 感谢与付款疑问相撞，利害直接；银行材料阅读负担高 | 熟悉的图成为陌生人的经历；群里有人正据此决定，画面与处境可同时读懂 |
| 核心逻辑 | 必须排除合法代付与记录误配，当前证据权限不足 | 虚构素材原件、公开第一人称宣称、真实听众的理解可以交叉验证；不靠同一经办推定欺骗 |
| 直接追问 | 财务承认代付后仍需难取得的资金去向 | 同事承认角色运营不解决虚构到账被当真；说“忘标”可以用原话、原件和纠正后的行动检验 |
| 提前阻止 | 第二笔可停，第一笔仍在；但主角未必有权限核实 | 下一条保证真正取消，昨天已发布内容、自己做的原件和既有预约仍在 |
| 拒绝参与 | 可保留原来收到的材料，后续资金调查可能断开 | 不接角色、不发推介，仍可用内容岗位权限查素材用途、以本人身份回应学员；彻底退出也成立 |
| 为什么查公司 | 公司把钱从谁转给谁，是否真有项目收益 | 公司为何付钱制作“学员经历”，免费课向谁交付咨询，平台承诺由谁兑现 |
| 最大退化风险 | 回单质检、财务办案员 | 只识破一个营销号、停发后就结束；必须让用途与接收方可见，不能凭气氛续章 |

**选 B。** 理由是玩家能以已有岗位能力做有区分力的操作，不需金融知识或临时获得资金后台。A 冲击强却仍缺关键前提，不以分数包装主观选择。B 也不以“所有群友都是托”作既定结论：本片段仅核实陈姐这个角色和这一条业务链。

## 一段故事梗概

林见入职澄川第 47 天。此前他剪回放、做课件，偶尔处理学员打不开资料的问题。今天负责社群的许蔓要去接电话，把一条尚未发布的课后材料交他核对。群里“陈姐”说自己已经顺利拿回过钱，唐雯追问等了多久。她引用的那张图，林见似乎在哪里见过。

不是破解密码。林见从图片回到自己做过的课程原件，再从课程首页走进学员真正看见的讨论。图中的交易是为了讲清页面而编的；群里的话却说“我自己的”。直接问许蔓，她不否认陈姐是工作角色，但把这叫做案例互动。唐雯并不知道这些，她已经预约了陈姐提到的咨询，只差有人回答她最担心的问题：钱还能不能取回来。

林见可以取消待发保证、告诉唐雯图片的来源，也可以相信解释交回工作。被指出后，许蔓会撤下自己的错误图片；她不会因此自动取消唐雯此前自愿提交的咨询。主管顾成接手，想保住的是这次咨询是否接通。他同意不用这张图，却没有打算把免费课程当成业务终点。

课程活动说明、学员预约页和已有接待状态指向同一个项目 F27。林见终于能区分：自己以为交付的是课程，公司在本场向合作方交付的却是愿意接受项目介绍的人。这个商业关系本身不犯罪；让它变得值得追查的是，公司正用虚构的取款经历促成对资金安全的信任。即使唐雯取消、当天没有新的转账，玩家仍有具体可查的对象：F27 的接收方、承诺范围，以及自己做过的哪些材料也被用作亲历证明。

这是一次局部识破，不是查明整个诈骗集团。玩家可以在保护唐雯、说清自身责任后停下；故事不能把“不继续”判为失败。

## 公司、人物与作者真相

澄川对外提供线上课程内容制作、学习社群运营和活动推广。知禾学堂是它经营的课程品牌，部分免费课程由合作方采购推广服务。真实课程不保证背后的推荐可信；免费、外包、境外登记单独都不是异常。

作者底稿：核心经营者明知 F27 是境外虚假投资团队的获客渠道，仍交付运营服务。普通内容岗只接触课件；社群岗制造投资经验；主管安排咨询转接；境外接收方控制后续投资接触和平台。**当前片段不能证明实际办公地点、资金损失、全员知情或平台全部虚假。** 公司不是为了把所有员工卖出去才雇人，其当前产出就是带着信任进入咨询的人。

## 现实依据与虚构边界
