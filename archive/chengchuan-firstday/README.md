## 当前剧情

国内公司为知禾学堂维护课程、资料、通知和用户服务。玩家可以从任意软件开始，也可选择普通课程通知案例完成工作。异常来自实际材料之间的时间、事项范围和结果差异；没有密码寻宝、证据完成度或正确答案菜单。

- 工作记录、课程通知、服务邮件与折叠历史。
- 服务事项快照、回访记录、当前追加表，以及可编辑的个人副本。
- 共享复盘的原件、按请求提供的初稿和部门核对邮件。
- 收件人分别记住实际收到的材料。读取、收藏和写草稿不传播信息。
- 个人稿、共享复盘、培训待用稿分别保存。撤回、修改范围和整条替换有不同后果。
- 跟进分工、境外岗位意向与材料处理独立确认，支持改口；实际发送记录不被倒改。
- 第一天不确认完整犯罪链、不替玩家获知银行回函，也不把离开或拒绝立即当作坏结局。

## 办公与休闲

保留多窗口、文档编辑及副本、表格筛选/编辑/基础公式、PPT 新页与放映、OA 组织/通讯录/用品申请、邮件、同事聊天、便签、咖啡、翻牌、壁纸与雨声。办公功能是轻量模拟，非完整 Office 或真实邮件服务。

聊天未接入 AI。采用有限意图识别、当前进度、收件人范围和对话记忆；不确定的自由文本会请求澄清。会改变工作状态的操作要在发送窗口确认，不由聊天关键词直接触发。

## 文件

- `web/case-data.js`：虚构原始材料及固定历史。
- `web/app.js`：桌面、软件内容、材料流转和第一天分支。
- `web/business-bridge.js`：更正之后的业务疑问、合同范围、经办人回复和独立窗口安排。
- `web/workdays.js`：个人工作交付闭环、下午交接、项目拟稿、培训现场快照、第二天协作复核和旧存档迁移。
- `web/coworker-dialogue.js`：同事的有限话题、连续追问、否定改口、知情范围和操作入口。
- `web/office-ui.js`：办公菜单、编辑工具、组织架构和工作向导。
- `web/prologue.js` / `.css`：三页序幕及渐变、暂停、跳过。
- `.openai/hosting.json`：已有公开 Site 的配置。

无需安装第三方依赖。运行 `npm run dev` 同时启动网页和剧情接口；`npm run build` 生成可发布 Worker。`web/` 是客户端源码，`src/domain/` 是剧情规则，`src/server/` 是接口，`dist/` 只存生成产物。不要用纯静态服务器替代新的前后端预览。
