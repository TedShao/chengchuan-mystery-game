# 故事规范：替你说的话

状态：2026-10-21。在 [a294217](https://github.com/TedShao/chengchuan-mystery-game/tree/a294217ca66b187b9cf000f6a7a2dfa65ac2eb40) 上重写公司调查。保留原会话中的局部撒谎；后半改为**撤掉出席者之后，公司还向谁出售什么服务**。先作限制信息的作者纸面验证，再回写本稿；不是陌生玩家测试，未改代码。分场与反路线见 [SLICE](SLICE.md)。

## 一个事件，两次改变问题

沈航来找昨晚给他讲远汀经历的“小林”。林见接回自己的课程服务席，发现昨夜代班的顾成明确说过自己不在澄川上班。林见可以更正身份、停掉代发；沈航可以取消预约，事情在这一层真正结束。

后半不再让沈航受损或不断追问。林见查看自己的出席安排时，发现自己被安排的这场交流不是免费的同学互助：**这段出席时间由被推荐的远汀向澄川购买。** 付费推荐本身未必欺骗，顾成也仍可能只是擅自夸大。问题来自同一服务的两个正常视图：内部排的是公司员工，对学员承诺的却是“非澄川、远汀工作人员的参与者”。

玩家可以提出一个非常普通的边界：“课程和项目问题可以答，挂我的岗位；别再说我是同学。”也可以直接撤掉自己、不接任何工作。项目负责人孟宁实际收到员工身份与对外承诺之间的冲突后，允许林见退出。若没有人要求暂停整项服务，她会将**同一笔远汀服务订单**中的出席人改为顾成，保留那项非工作人员承诺，再以公司交付负责人的权限将调整正式确认给远汀。不是再冒用林见，也不是恢复沈航的预约。

**关键不在换人，而在负责人明知换上的也是员工，仍把“非工作人员参与者”作为公司要交付的商品确认给付款方。** 玩家不需要配合说谎、不需要等新的学员被联系。确认到客户账户的服务承诺已经是公司层面的商业行为；它证明这个项目在经营虚假独立性，尚不证明下一场会谈已经发生，更不等于证明资金诈骗或全体员工知情。

由此，玩家的问题可以从“谁拿我的号撒谎”转成“远汀为什么出钱，买一个看起来不替远汀说话的人”。这份好奇是待测目标，不预写为每个玩家的必然反应。

## 公司与场面为什么存在

澄川有真实的知禾课程服务业务，通知、资料、排课都是正常工作。林见在这里做了 47 天，熟悉的是这一层。远汀另向项目组购买咨询接待与参与者交流：公司端按出席时段配置资源，学员端不付这笔服务费。这是本故事的虚构经营结构，不声称真实公司都如此。

林见不需要突然取得合同库权限。林见可撤自己的出席，整单暂停需孟宁收到请求后实际执行，不给普通员工全公司停业权限。每个值班人本来就能打开**自己的出席卡**，知道替谁工作、何时出席、对方会看到什么。卡片关联一笔服务订单，人员更换前后仍可看本次交接结果；不能由此浏览全公司客户或私聊。公司给客户确认服务的动作，出席人能查到“已确认给远汀 / 尚未确认”，这是工作出处，不是暗藏的犯罪日志。

后半只增加这一张可交互的出席卡和一名有明确权限的负责人。它替换原来无结果的分类检索，不堆合同、凭证、绩效表或另一批聊天。林见的真人头像只属于他本人；撤出后同时从本订单对外展示及可约名单移除，不设置五个地方分别删。

### 表一：事实、时序与因果

| 时间 / 条件 | 世界中实际发生的事 | 局部原因、可观察结果 |
|---|---|---|
| 昨日下班 | 林见结束课程值班，组内代班开启 | 正常制度；代班本身不指向犯罪 |
| 昨晚 | 沈航明确询问是否在澄川工作；顾成用小林席否认，并讲取回投入的经历 | 他要接住沈航对独立亲历者的要求；原文及普通消息详情从开场可读 |
| 开场 | 沈航想找同一人；林见自己的出席卡仍列远汀预留的交流时段 | 复访造成身份冲突。预留的是付费服务时段，不等于沈航仍有预约 |
| 玩家更正、停止、取消 | 按实际发送更新认知；停代发和沈航取消都生效 | 沈航可以离开，不追加事故。取消一个学员预约不会伪造成取消公司间订单 |
| 玩家只撤自己 | 本订单移除林见及其对外形象；孟宁收到缺员通知 | 她可正常安排替补；只看到这个结果，仍不足以判断她明知欺骗 |
| 玩家实际指出员工身份与非员工承诺冲突 | 孟宁读到同一订单链接、原承诺及人员关系；可简答“顾成也在我们组，我知道” | 公司是否改正成为可观察问题。只给她一句“我不干”不算完整告知 |
| 玩家没有要求整单暂停，且选择查看交接结果 | 孟宁安排顾成；将保留非员工承诺的人员调整正式确认至远汀客户账户 | 她想保住已经卖出的交流服务；林见退出不影响她交付。只到草稿则不能作此结论 |
| 玩家明确要求冻结本单，对该承诺提出异议 | 孟宁先冻结订单的新增出席安排；客户侧显示暂停，既有错误承诺不静默抹除 | 公司想避免带着具体异议继续确认。此路成功阻止上述新确认，不强行换账号续发 |
| 玩家撤回暂停请求 | 原则性让步仍保持暂停；明确同意恢复员工咨询，孟宁才改本单为员工答疑并送客户确认 | 撤掉不实资格，状态变为待客户确认；客户接受前不开放学员预约，不因“继续”恢复伪装 |

事件按玩家实际动作推进；自由办公、读得慢、反复看同页不引发秘密倒计时。更正沈航、退出个人、异议暂停是不同对象，界面须说清范围，不能利用这个区别暗坑玩家。

### 表二：人物知道什么、想要什么

| 人物 | 知情 / 盲点 | 需求及反应 |
|---|---|---|
| 林见 | 知道自己及顾成是员工；一开始不知远汀购买了自己的出席时间 | 想保住正常工作，不想替别人的推荐负责；可只处理自己，也可核实购买者和用途 |
| 沈航 | 知道昨晚自称独立的人说了什么；不知公司的排班及交易 | 想听真正的亲历者。收到完整更正后可以取消，不替玩家调查公司 |
| 顾成 | 知道自己的关系否认及项目接待；不知道玩家未发送的草稿 | 可承认昨晚是他、配合更正。个人认错不代表交付负责人已知情 |
| 孟宁 | 项目交付负责人，知道本组雇佣关系及自己负责的服务；只在实际收到后知道林见的异议、沈航的更正 | 要保住远汀订单，可换人，可在异议下暂停；既不突然坦白全案，也不为了悬疑强迫继续联系沈航 |

远汀在本片段是实际订单的付费客户，不新增一个泄密联系人。确认送到客户账户不等于客户某人已经阅读或赞同所有内容；公司自己确认提供什么，已足以检验本轮命题。

### 表三：对象、初读与重新理解

| 对象 | 第一次可如何理解 | 用什么行动区分 |
|---|---|---|
| 原会话与顾成操作者信息 | 正常代班，或同事讲自己的经历 | 结合针对雇佣关系的明确否认，支持个人有意伪装；获利真伪仍未知 |
| 我的出席卡：委托客户远汀、服务时段、林见 | 普通外包咨询，付费采购并不等于欺骗 | 打开同卡的“对方看到的介绍”；不因客户名称直接定罪 |
| 学员介绍：非两家公司工作人员的参与者 | 可能人员配置错误，或顾成擅自改了角色 | 将实际员工关系与这一句一起告知负责人，要求按真实岗位出席或不出席 |
| 撤出后的顾成替补 | 正常调度；顾成可能被要求改正 | 查看**已经确认给客户的本次安排**是否同步撤掉非员工承诺，而非只看人名 |
| 完整告知后，负责人确认“员工履行非员工交流”的服务 | 不是昵称误会，不是孤立同事发言 | 已知身份、公司交付权限、实际对客承诺三项合取，才支持项目层经营伪装 |
| 异议后实际暂停 | 公司暂时处置异议；未证明改正，也未证明继续交付 | 可结束，或允许真实员工咨询并观察是否接受这个条件；没有自动生成更强证据 |

原会话可从头跳读；出席卡与服务介绍开场已有入口，不凭“读齐材料”解锁。负责人是否收到冲突与是否真正确认到客户是行为证据，不增加秘密附件。

### 表四：动机、权限与竞争解释

| 解释 / 人物 | 动机、机会与手段 | 会出现什么不同结果 |
|---|---|---|
| 顾成个人越界，公司正常服务 | 顾成想留住咨询，有代班权限；负责人此前可能不知道错误承诺 | 完整告知后撤掉非员工承诺、找到真实独立人员，或停止卖这项服务；不能继续保证现有员工是非员工 |
| 正常代运营 / 隐私昵称 | 公司可替品牌服务，员工可用工作昵称 | 昵称不必改为全名，但必须撤掉与事实冲突的雇佣关系否认；不是禁止所有代运营 |
| 公司交付这个项目的伪装 | 孟宁有人员和客户确认权限，知道用的是谁；保住已经承诺的服务比换一张身份牌重要 | 她在完整知情后，仍以公司身份正式确认由本组员工提供非员工交流；不靠顾成承认制度 |
| 公司在销售真实独立学员交流，暂时找不到人 | 可以合理退单、暂停或另找确实符合资格的人 | **拒绝林见实名出席、报价不同、取消订单本身都不能排除这一解释**；只有明知员工还实际确认非员工承诺才区分 |
| 全公司及远汀共同实施资金诈骗 | 本轮尚缺对资金、履约、远汀实际知情的事实 | 不作结论；境外公司名、服务器位置和外国时区也不能补足 |

不把孟宁也有错自动写成“所有公司都在犯罪”。本段支持的范围是：**这笔公司服务经有权限的负责人知情确认，以虚假独立性为交付条件。** 即便管理层更高处不知情，也已超出顾成私人代班撒谎；更高授权是新问题。

### 表六：纸面验证结论及否决线

| 检查 | 修订结果与边界 |
|---|---|
| 行动能否区分两种解释 | 条件齐全的确认路线能：不是单凭替补、拒绝员工或订单存在；必须完整告知后实际对客确认不实资格 |
| 是否靠新一批聊天证明 | 否。旧聊天证明顾成；同一出席卡与自己引发的实际业务变更证明公司项目。新负责人只回答权限内必要信息 |
| 是否又变成审批流程 | 删除写说明、填理由、交材料、等评语；只保留实际撤出、要求实名身份、暂停或查看结果。若玩家只在清待办，仍判体验失败 |
| 提前阻止能否成功 | 可以。阻止路线不会必然取得“告知后仍实际确认”的证据；不因证据较少罚坏结局 |
| 是否要求放任新的受害 | 不要求。客户是原有远汀，确认是公司间的服务承诺；沈航和林见的停止持续有效。不给新学员发消息、不发生新损失 |
| 为什么公司没藏证据 | 正常出席人需要知道对外角色和客户安排；孟宁认为换人能化解林见个人不愿意，尚未把他当调查者。明确整单异议后会暂停，不故意表演罪证 |
| 仍未验证什么 | 新玩家是否自发回看交接、能否区分服务承诺与已发生会谈、是否仍只觉得营销失信；需真人观察，不能把逻辑闭合等同好玩 |

## 本轮删掉与保留的边界

删掉以“同学交流”分类搜索续命、反复找顾成解释、请求更多同类聊天、追加受害事故和退款核验。保留真实员工回复即接管、更正按收件生效、停止不抹历史、自由办公和无指引探索。新公司场面替换缺失的后半，不扩成第二天。

沿用此前核读的[最高法典型案例二](https://www.court.gov.cn/zixun/xiangqing/439351.html)作为课程引流和角色运营的背景。本文出席卡、两种服务视图及公司确认机制均为虚构，不是该案事实，不作法律定性或现实操作指导。
