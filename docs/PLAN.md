## 当前复核发现与处理

1. 撤回赵的联系请求再发起，不应被“一次回答”去重吃掉：区分重复点击与新的请求。
2. 两个互斥联系安排可以同时进入草稿：按实际发送后的状态逐项校验，失效后项不再发送，给出反馈。
3. 手机列表可能把新联系人放到不可见末尾：当前与最近会话前置，保留横向滚动。
4. 资料摘要不能替玩家完成先后对照：只保留两次反馈的实际时间和内容，不自动写“早于后续招募”的结论。
5. 保存的草稿刷新后仍应是草稿；多窗口进度变化不能覆盖；导入旧故事存档应拒绝且不破坏当前进度。
