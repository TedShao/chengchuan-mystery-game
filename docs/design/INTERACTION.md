# 网页交互与叙事行为约定

《回来以后再联系》的待实现规格。故事事实归 [STORY](STORY.md)，场景内容归 [SLICE](SLICE.md)。本页只定义玩家如何操作、如何知道结果，以及系统不能替玩家做什么；不代表旧网页已经具备这些行为。

## 产品承诺与范围

玩家扮演招聘助理，在公司电脑中理解一件牵涉自己工作的事。主要体验是自己提出问题、核实解释、决定把什么告诉谁；自由办公与摸鱼可以提供间隙，但不会解锁犯罪证据或充当通关工作量。

本轮不决定全套 Office 的复刻规模，不接 AI、不发送真实邮件电话、不要求注册或支付。保留模拟文档、表格、演示、邮件、聊天、OA、浏览器的产品方向；首先制作故事真正需要的界面，其余功能不得装成能操作的空按钮。后续工程规划必须区分已有代码能复用什么与哪些只是设计。

## 屏幕与信息架构

| 界面 | 本故事中真正的用途 | 不承担什么 |
|---|---|---|
| 公司桌面与任务栏 | 在已打开窗口间切换；时间、声音、存档和帮助入口 | 不弹必须完成的调查任务列表 |
| 工作通讯 | 同事对话、来电、实际邀请、消息发送历史 | 不在私人草稿写字时更新 NPC 知识 |
| 邮箱 | 面试通知、材料分享、可查看收件范围的外部模拟联系 | 不把保存当发送，不把收件当全部理解 |
| 招聘系统 / OA | 自己经手候选人、接待记录、日历、岗位责任人、公司组织关系 | 不向新人开放全员邮箱、全部财务或位置追踪 |
| 浏览器 | 公司公开主页、招聘页、对外岗位说明、模拟外部求助入口 | 不靠源码、真实网页搜索或现实时事知识通关 |
| 文档 / 表格 / 演示 | 看原通知附件、招聘介绍；可自由写笔记、做普通办公 | 不用字符数或标准答案控制调查 |
| 私人便签 | 自选引用和问题；并排比对原件，保留来源 | 不自动填“凶手是谁”，不算正式对外表态 |

公司首页写实际主营业务，招聘页写特定职位，OA 的人员架构只说明负责人和分工。三者外观和目的区分；共享浏览器地址栏、返回、历史和书签。内部虚构地址不实际跳到私人第三方站点。陌生网页打不开时说明是未实现入口，不用“服务器损坏”伪装谜题。

## 动态操作教学

教学只教第一次接触的操作。打开对话 → 看懂来电与留言 → 打开通知 → 返回原线程 → 在需要时演示收件人和发送。玩家已自主做过就不重播；每一步观察实际操作后结束，不靠点“下一步”假装学会。

高亮跟随当前可操作对象，并配短动词，例如“点这里打开来电记录”。无动画模式用同样文字。已经关闭指引时仍有按钮名称、送达结果和返回路径，不把基本可用性藏在教程里。

不高亮可疑句子、不说“对比后发现矛盾”、不通过百分比暗示还有几条线索。卡住时三级帮助分别是：怎么操作、正在谈哪件事、去哪里找自己已经知道的对象；最后一级仍不代替结论。帮助可关闭、可按需再开，不强制每次刷新复学。

## 判断怎么表达

主要使用有上下文的意图选择：问最后联系、请求本人回拨、暂不担保、只转交这一段、取消自己的经办等。选项说明正在做什么，不把未经发现的事实写在选项里；例如没收到求助时不出现“用赵的求助揭穿孟宁”。常识问题始终可问，不以阅读标记上锁。薪资问题分清底薪、驻岗补贴、绩效、试用与批准休假；用短说明回答当下的问题，不把全部待遇作为必读教程。数额只取 STORY 的统一版本。

一次选择多个问题时显示待发送的问题清单，接收者逐项回答或说明哪些不知道。改口选项明确更正的是此前哪条陈述。自由输入可留作便签或模拟办公，但本轮不承诺开放聊天能理解任意语句；以后若加自由聊天，必须另验否定、转述、复合问题和指代，不能退回关键词触发任务。

选错不是“不通过”。说了没有依据的保证，会使接收者暂时相信；误把个人退出当全批暂停，界面必须显示真实仍在的安排；错误指控可能使对方谨慎、减少合作。查看、试选和取消不惩罚。没有“乱点三次 = 出境”规则。

## 行为、知识与事件

| 动作 | 本地变化 | 对方能知道什么 | 后续与重复规则 |
|---|---|---|---|
| 阅读 / 摘录 | 已读、便签引用 | 无 | 重读不生成新剧情 |
| 编辑草稿 | 草稿和预览 | 无 | 切窗口、刷新应保留，取消发送不清空全部笔记 |
| 发送问题 | 留存当时正文、对象、附件范围 | 只知道实际送达内容及自己既有经历 | 同一发送操作重复点击不发两次；后来再问可指回旧回答 |
| 转发摘要 | 摘要明确来源和不确定性 | 不等于看过原件；无权推断未附细节 | 补原件是真正新增信息，才引出新反应 |
| 请求暂停 | 产生请求及目标范围 | 收件者知道请求，不等于已批准或通知 | 有权限的人实际确认后才停对应安排；界面分清请求与结果 |
| 自己退出 | 撤自己参与或待发内容 | 被通知的人知道退出 | 不自动取消整批；不得转写成已替别人发送 |
| 更正已发消息 | 新增更正并链接旧消息 | 实际收到更正的人更新理解 | 旧后果不回滚；未收件者不自动改口 |
| 结束调查 / 个人求职与出发 | 申请、离职生效、取消、出发分别保留；有范围说明 | 按实际通知更新 | 招聘助理不因拒绝任务被调海外；关浏览器不是出发 |

每个关键事件需要在未来实现中保存：谁做了什么、对象、当时内容、实际收件人、事件顺序、是否发生。人物知识按事实和来源记录，不共用一个“全公司知道”的开关；团队会话成员可见，但不把成员之外的人算作收件者。

事实与判断分开：听到“我没事”记录为本人这样说过，不是已确认安全；系统已读不证明角色已理解全部细节；定位和责任不能由元数据自动判断。

## 本人知道什么，与公司知道什么

林见的原售后经历、个人海外客服咨询是背景；报名、离职和出发均不是已发生事实。是否继续求职须由玩家实际选择。误判公司不自动产生求职申请。

听到或读到具体受控经历后，故事不能继续把林见写成毫不知情；不要求他先转发、获得正式定罪或集齐材料才算知道风险。此时结束该受骗出境分支，保留核实和退出。公司只按实际收到的表态判断他的立场，不从私人已读、便签或内部知识状态读心。

初步疑虑、一次未接电话与一般岗位抱怨不自动等于已获具体受控警讯；受骗分支不能用“看了几页”的计数代替内容。停止整项目后不再生成本项目新录用；取消申请不自动恢复已生效的离职，后果逐项说明。

## 同事反应如何避免机械

回答先看其身份、实际知识、此前回答、近期新事件，再看当前问题。没有新信息时可展示之前的回答和时间，不制造一条换同义词的“新回复”。人物拒绝需要具体理由：不愿公开经历、不负责该项目、已无法联系；不说抽象的“权限不足”代替人话。

从拒绝改为愿意配合，先解释什么改变了决定，例如看到自己也发过同一介绍，或获得明确的分享范围。道歉不清空记忆；重复点击不反复收回同意。对方可以承认一部分、兑现一项帮助，再拒绝另一项，这些变化需体现在安排或资料范围上。

## 时序、反馈与自由操作

- 采用剧情事件推进：结束通话、完成一次实际联系、明确到下一时段。阅读和摸鱼不运行现实伤害倒计时。
- 允许打开多个材料并排；返回保留滚动和筛选位置，不每次跳回顶部。打开资料不自动切到便签。
- 发送后有持久的“已发送给谁 / 附了什么 / 时间”，对话里可重新查看；仅有一闪而过 toast 不算反馈。
- 暂停确认、通知候选人和候选人实际回复是不同状态。未回复保持未回复，不能给假的绿色成功勾。
- 收件范围在发送前可见，默认不全选全部材料；后续转发不会暗中扩大。隐去私人段落必须在预览中一致。
- 页签切换、重复点、刷新、恢复、跨窗口操作应保留同一事实。不要求玩家靠重置周目撤销合理误判。
- 自由办公文件可编辑，聊天事件和已发邮件不能靠改本地文档覆盖。普通操作可撤销，对外发送用更正而非时间倒流。
- 字体可放大、键盘能聚焦、状态不只靠颜色；模拟通话提供逐段文字，允许暂停和回看。不开声音也能获得同等信息。

## 实现前的验收例子

1. 初见玩家不读教学，也能从未读与按钮理解如何接听、稍后回拨、查自己发的通知。
2. 点“只撤本人”后，自己的参与取消，仍有效的预约清楚显示当前经办人；随后申请全批暂停不会重复误发。
3. 摘录赵的经历给父亲、不给孟宁：父亲知道选中段落，孟宁只能回应自己的既有知识。
4. 先发安全保证再更正：原消息、改口、不同接收人各自的反馈可见；历史不被覆盖。
5. 拒绝下一工作、全部暂停或提前求助都能合理继续或结束；没有必须制造新损失的正确路线。
6. 关闭应用、刷新、重问、改口不触发新的绑架、重复来信或恢复已撤安排。
7. 林见在私人联系中已获具体受控警讯：不再演无知出境；未收到相关消息的同事不突然警觉。
8. 误信但从未报名、已报名又取消、已离职后取消分别有不同事实；均不能自动跳转受控结局。
9. 将“提前休假”更正为“结束工作”：已送达的更正改变相关收件者的询问内容，不自动改变回程状态。未看待遇条款仍可表达该意图，无需精确术语或正确答案。
10. 连续问补贴、试用、假期、税后，不重复贴完整广告；缺正式税费资料时保留未知，不补造到手收入。咨询待遇、展开明细和试选都不等于报名。
