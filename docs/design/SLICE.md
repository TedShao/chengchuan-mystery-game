# 网页片段：退给你的钱

状态：2026-10-20，新核心事件纸面候选；两案比较、真相与六表见 [STORY](STORY.md)。本稿替换教学组件、金额测试、付款核验和恢复审批，不继承其状态。仅文档设计及作者反路线排演，未改代码、未运行新版、未做真人盲测。

## 第一眼：钱退回来了，事情似乎已经结束

极短背景：林见，失业三个月后入职澄川，第 47 天。你在知禾学堂做课程服务，负责这一组学员的通知、资料和咨询转交；顾成负责远汀项目，投资与退款不是你的账户权限。眼前是平时值班的服务台，办公软件与摸鱼入口仍可自由打开。

唐雯昨晚的留言在今天上班前已到达：

> “三千到了。我发截图是告诉你们收到了，不是让我上宣传图。帮我撤掉，今天的电话也取消。”

同一队列中，沈航昨晚另有一条未读：

> “我昨晚已经转给唐雯了。她是你们哪位财务？我想问一下，入金登记之后还要等什么。”

两条按真实消息时间排列，不因玩家先撤图才触发第二个受害者。没有“同名异常”高亮、疑点计数或阅读全材料任务。先看沈航也成立：原付款指引中带收款人姓名，姓名搜索可在自己服务组找到唐雯的既有会话。仅同名不自动配对案件。

撤图和取消唐雯电话现在即可完成，不索要调查报告；反馈只显示各自状态。撤图不是抹掉已发布副本，取消电话不取消已有资金事实。沈航的预约独立，不能因唐雯取消自动停掉所有人。

## 三处空间与可见内容

| 空间 | 为什么主角能用 | 能操作什么 |
|---|---|---|
| 本组服务台 / 聊天 | 两人原本都由这一服务组接待，当前值班有阅读权限；项目席发言保留操作者 | 搜索组内姓名或会话、展开历史、分别追问、引用实际消息、选择收件人 |
| 两人主动分享的本笔详情 | 各人自行查看自己的收付记录，只分享这一笔 | 查看脱敏对象、金额、时间、原用途说明；不登录银行、猜账号或调别人的流水 |
| 原课程运营入口 | 平时就处理宣传和预约 | 撤图、取消指定预约、停止自己负责的后续介绍；不改账户余额或执行退款 |

网页浏览器可并排保留两个会话 / 详情，普通搜索不设密码。文档、邮件、OA、表格继续是环境，主线不必轮流打开所有软件。材料都来自已存在的交流及当事人的主动回答，不另设“资金真相报告”。

## 核实一：唐雯是财务，还是另一个学员

可先问任何一人。以下是人物知道的回答范围，不是关键词答案表：

- 问唐雯款项来源：“转来的名字是沈航，我不认识。昨晚你们项目那边说是退款。”只有询问本笔且她愿意分享时，展示她自己的收款详情。
- 问唐雯是不是替平台收钱：“我只是把退钱的卡发过去。没有帮他们收钱这回事。”不能由这句独自定案，可返回昨晚账户提交的上下文。
- 问沈航为什么转：“项目那边给了收款人，说是财务。我照着付的。”他可打开付款前收到的原消息，而不是现在重新写一份证词。
- 问沈航是否认识唐雯：“不认识。不是你们给的名字吗？”他不应直接说“我被拿去填别人退款了”，那是他尚不知道的事。

若玩家只看同名就质问唐雯骗人，她会先澄清自己退的是哪笔，并暂不愿分享额外资料；转而说明正在核对收款人、撤回无依据指控后可重新征求许可。不是永久锁线索，也不因重复问就突然配合或发怒。

**配对不是猜数字。** 对照双方主动给出的本笔收付对象、金额和时间，再分别确认该记录的用途。姓名、金额单独相同都不够；不同银行编号不要求相同。模拟详情能支持该笔对应，保留来源与脱敏信息，不让玩家填完整卡号来“解锁”。若一端没有给足信息，结论只到疑似，不自动出现“已证实”。

**本笔材料的最小内容**（均为虚构展示，不提供完整账户）：

| 来源 | 玩家实际能看到的字段 | 作用 |
|---|---|---|
| 唐雯主动分享的收款详情 | 昨日 19:02，收入 3,000 元；付款人沈航、尾号 7721；本人收款账户尾号 4086 | 她只能确认自己收到了这笔；看不到沈航被怎样介绍 |
| 沈航主动分享的付款详情 | 昨日 19:02，支出 3,000 元；本人付款账户尾号 7721；收款人唐雯、尾号 4086 | 与另一端交叉核对；仍不能证明唐雯知道钱被当作投资款 |

两张详情各自保留来源，可并排查看；不自动画红线、不弹出案件结论。两端本人确认后才支持本笔对应。尾号只是多项对应之一，不是任何四位相同就合案的通用规则。

## 核实二：正常代付能不能解释

直接问顾成完全允许，且不要求先找齐材料：

> “合作方安排的代付。你先别把两边的事混着回。”

这是可检验解释，不是坦白，也不是因为语气回避就算罪证。只有给出对应对象，他才谈这两笔；否则先问具体哪位学员。他本来知道自己发过的安排，但不能知道玩家私下问过什么。

玩家此时可以信他并停止，也可以查“代付”究竟解释了哪些事实。唐雯不认识付款人，并不能单独排除正常第三方退款；两人的用途不同也不自动证明犯罪。需要追的是更具体的问题：顾成明知唐雯是退出学员，为何在付款前把她说成平台财务？唐雯的退款上下文和沈航收到的原指引可以互相校验；不是让玩家背诵“代付不正常”。

无需设计一场新的银行转账。两人的昨晚记录可以继续追溯；拒绝执行任何资金动作、取消所有相关预约后，它们仍然存在。顾成即使承认“唐雯不是财务”，也只修正今日说法，不能解释昨天为什么在付款前把她作为财务介绍。

## 核实三：这笔安排是谁作出的

在各自原会话里，普通时间顺序已经留下两次实际动作：

- 唐雯 18:10 提交本人退款账户，项目席顾成回复“按这张卡退回”。
- 沈航 18:35 收到项目席顾成发送的收款信息，身份说明为平台财务；19:02 才付款。

不靠一份写着“挪新还旧”的秘密文件。玩家可从当事人所收原消息进入，也可从同组已发消息按姓名定位；两条是不同入口，不是读齐才能出现的下一关。公司会话不模拟可以任意改写的银行凭证。

**关键重新解释：**收款身份不是转完后的一处错误标签，它在付款前影响了沈航向谁付款；另一端的原用途早已是退出退款。这样才有理由把问题从“图片夸大”推进到“公司在安排谁的钱付给谁”。原材料不要求改字或重新审批。

若只得到唐雯一端，不能证明谁指引沈航；若只得到项目指引，不能凭名字断定收款人未受托。两条不同核实路线都允许止于有限结论，没有主管一段补完真相的对白。

## 选择：让谁知道这两件事其实相连

核心交互从查事实转到实际传达。不同选择改变具体人物的认识与后续联系，不靠结尾评价分。

| 选择 | 实际事件 | 仍不知道 / 不会发生 |
|---|---|---|
| 只撤图、取消唐雯预约 | 撤图与撤约完成；两条历史会话都可返回 | 沈航不自动知道唐雯是学员；不因此出现追加被骗事故 |
| 只把疑问交顾成 | 他知道实际收到的两端关联，可要求后续问题转给他；本组会话保留 | 两人不会自动互知；他不偷偷删掉消息或重开取消的预约 |
| 只对唐雯解释已查明部分 | 她知道付款人可能是另一学员，可以拒绝再用自己截图背书，要求不再共享本案 | 不会自动把钱转回沈航；主角没有决定款项归属的权力 |
| 只对沈航解释 | 他知道收款人是退出学员，主动要求暂停自己的后续咨询；可追问原指引 | 不自动得到唐雯全部经历；她若没收到解释仍以为只是退款 |
| 经双方同意有限核对 | 可转述获许可的交易用途，或建立只含本笔的会话；两人能直接纠正彼此身份误认 | 同意核对不等于公开卡号、身份证或同意任何转账 |
| 不代理钱款，但核对自己的转交 | 保留查询与上述事实沟通，拒绝经办不会被系统翻成继续投资 | 不代理维权、不替人签结案、不让 NPC 自动带回全案答案 |
| 完全拒绝调查 | 自由办公或结束，保持已执行的停止状态 | 不保证看到谜底，不新增惩罚来逼迫参与 |

联合核对不保证气氛友好。唐雯可说：“你说的那笔我确实收到了，但我是拿回自己的钱。”沈航可以反问：“那你们为什么让我按投资款付？”这两句只在双方实际得知对方用途后出现。冲突已经是两个现实处境，不是让主管修改一个页面。

顾成进入共同会话与否由实际邀请决定。若只收到一句“代付有问题”，他不知道玩家已配对了什么；若收到付款前两段指引，他会收窄回应到本案、停止让林见继续解释，不自动自认整套诈骗。**能否证明本笔安排不依赖他继续说话。**

## 误判、改口与提前阻止

- **先信正常代付：**可以向沈航实际发送“已核实是平台财务”，但这属于超出已知的背书。沈航因此暂时接受解释，原预约仍在；不会自动继续转钱。后来取得相反材料，可明确更正，沈航再按新信息决定暂停。私人改口不等于已通知。
- **先怀疑唐雯：**仅有收款记录不证明她知情；具体查到退款上下文后应允许撤回指控。她是否继续分享取决于当前说清的范围，不刷怒气条。
- **最早阻止：**撤掉宣传、取消约谈、停止自己的新转介，均实际生效；昨晚转账与付款前消息照常可查。不要求恢复任何安排换取线索。
- **不愿拉群：**可经许可分别核对必要事实，联合会话不是正确答案；不授权转述则停在自己知道的范围。
- **部分信息 / 多问一句：**问“她的钱是谁的”先澄清指本笔来源还是最终归属；同时拒绝经办并问指引来源，分别保留拒绝与问题。不给金融结论，也不匹配成付款授权。
- **重复操作：**重复撤约只显示已取消；重复已回答的事实沿用原回答及引用，不增加新证词；新证据才改变回应。不生成第二笔转账或第二张撤图事件。

若玩家主动想向银行或警方反映，剧情可保存其选择及实际授权的材料范围，不把法律程序做成密码锁；本片段不模拟追回款项、自动冻结或定罪。所有联系与记录均为游戏内虚构，不调用真实服务。

## 两条非预设核实路径与压力检查

作者排演，仅检验结构及信息边界，不声称陌生玩家真会这么走。

| 路线 | 顺序与能得到的事实 | 可合理停在哪里 |
|---|---|---|
| 当事人先行 | 唐雯收款来源 → 沈航付款用途 → 两人本笔确认 → 付款前项目指引 | 拒绝分享则保留疑似；不需要先问主管或读公司介绍 |
| 指引先行 | 沈航原付款消息 → 搜索本组收款人 → 唐雯退款上下文 → 向两端核对本笔 | 找到同名不能直接合案；需确认收付对象 |
| 直接问主管 | 接受“代付”为待验解释 → 问收款人是否受托 / 付款人原意 → 回看事前指引 | 信解释即可退出；不要求主管说漏嘴才有证据 |
| 最早撤图撤约 | 所有停止完成 → 读已经到达的另一条会话 → 核对既有转账 | 没有新坏事，未发生的新联系不补发 |
| 拒绝资金参与 | 不操作钱 → 自己服务组内核对原转交 → 选择是否更正已发说明 | 完全拒绝沟通可结束，不假装该路也有全部真相 |
| 只看半边 / 后来改口 | 初判正常退款或正常入金 → 后续取得另一端事实 → 更正到实际收件人 | 不以没读齐惩罚；没有事实就不自动变更别人的认知 |

片段的下一问题来自实际安排：“如果他们把一个退出者当成平台财务，我以前转交的那些咨询会怎样被接下去？”这仍是设计预期，不能记为玩家已产生兴趣。验证需观察新人是否自发联系两端、是否理解正常代付与隐瞒角色的差别，以及结束后究竟想继续还是只想离开公司。参考与状态见 [PLAN](../PLAN.md)、[H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
