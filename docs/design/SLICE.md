# 网页片段：替你说的话

状态：2026-10-21。对 [4b9353a](https://github.com/TedShao/chengchuan-mystery-game/tree/4b9353aa1fb37ae9c5fa8e957ce1cd552642b6bf) 作关闭指引、非预设顺序的作者纸面复查，并直接删改本稿。作者知道底稿，以下只限定每步可用事实，**不冒充陌生玩家实测**。没有运行网页、修改代码或取得兴趣数据。结论：局部身份冲突仍可用，远汀调查的动机与行动尚未接上。

## 先写复查发现

1. **“买独立推荐是为了什么”未形成新的未知。** 玩家已经知道远汀是被推荐的项目、又是付费客户，“为了获客”足以解释这笔购买。需要调查的可以是它有没有别的实际业务，但原稿没有给出让这个解释失效的事实。更严重不等于更神秘。
2. **取证动作压过人物行动。** 原稿要求确认孟宁知道雇佣关系、引用资格承诺、只撤自己而不暂停、等待确认、再回看对应版本。口头说不强制，强结论却集中在这个窄窗口，很像为系统准备一份有效投诉。
3. **孟宁的反应存在时序捷径。** 告知后再撤自己，她会继续确认；先撤自己再告知同一个冲突，她就暂停。原稿没有为两次反应给出不同的压力或人物理由。不能靠玩家说话早晚，安排她刚好暴露证据。
4. **结尾停在“可以问远汀”。** 没有规定这次询问要区分什么、哪些实际结果会改变判断。一个联系人和开放入口不是已经完成的调查机制。

这四点是设计审查发现，不是“所有真人都会无聊”的观察。当前更像可处理的身份冒充事件及商业失信冲突，尚不是持续推进的公司谜案。下文保留可成立的部分，删除人为取证流程；不靠新增事故或秘密材料接尾巴。

## 先重建六类信息

| 类别 | 原稿可支持的内容 | 置信度 / 缺口 |
|---|---|---|
| 事实 | 顾成实际否认受雇；远汀购买交流时段；公司卡片将员工列入非员工交流 | explicit；公司对外安排与事实矛盾，不等于远汀已经知道 |
| 认知 | 孟宁知道同组成员是员工，收到具体异议后能理解矛盾 | explicit；没必要再问一次“你知道顾成是员工吗”解锁证明。她是否看过当前对外措辞必须有依据 |
| 线索 | 旧问答、自己的出席卡及学员介绍、撤出后的安排 | explicit；可查身份和提供方，不能证明资金、境外联系或购买者意图 |
| 动机 / 权限 / 手段 | 顾成想留咨询、孟宁负责交付、有排班和客户确认权限 | explicit；同一完整异议为何因到达顺序而触发不同处置：missing |
| 场面 | 更正、撤人、暂停、确认、回看 | explicit；对流程的解释多于新的未知。玩家因此追查远汀：weak inference |
| 验证 | 停止能成功；未读不全知；更正可收尾 | explicit；“为了获客”之外还有什么可检验的问题及结果：missing |

局部推理链仍是：明确否认雇佣关系 + 实际操作者是已知员工 → 这次有意伪装。公司排班与不实服务介绍相连 → 可以质疑公司的交付；负责人知情后仍实际确认 → 才能进一步收窄责任。**后一个条件在逻辑上有区分力，不等于应该编一条她配合取证的路线来实现它。**

## 原版纸面走法：允许停在不想继续的地方

| 路线 | 当时看见什么 → 自选行动 → 原稿结果 | 下一判断与断点 |
|---|---|---|
| A 先直接问孟宁 | 出席卡有我、远汀付费 → “远汀花钱让我们给自己推荐？” | “为了获客”本就可解释；原稿的标准回复未覆盖此自然追问。不能强制先问是否知道顾成是员工 |
| B 直接问身份冲突 | 员工与非员工介绍并列 → “顾成也是员工，换他有什么用？这项别再卖了。” → 整单暂停 | 合理处理，当前可以结束；原稿没有剩下的新业务矛盾 |
| C 先暂停、不追究谁说谎 | 看见资格不符 → 请求暂停 → 暂停有效 | 不应劝玩家先让它确认出去；不因少一项证据判失败。远汀仍只是购买营销服务的客户 |
| D 只撤本人 | 不读学员介绍 → “我不出席” → 我被移除、顾成替补 | 从已有信息看是正常调度；没有必须回看的理由，允许离开 |
| E 撤出后自发核实 | 看过介绍 → 撤自己 → 再见顾成仍配同一资格 → 具体指出矛盾 → 孟宁暂停 | 能把个人问题提到公司，但“请改掉这一项”仍是充分行动。没自然长出另一个调查对象 |
| F 走原稿最强证明路线 | 事先完整告知，只撤本人 → 孟宁仍确认不实安排 → 回看 | 可证明该次知情行为，却仍可用“卖托儿式推荐获客”解释；取证窗口又依赖孟宁反应不一致 |
| G 只看一方 | 仅员工排班，或仅学员介绍 → 问来源 / 撤出 | 无资格矛盾全貌，不应自动定罪；两视图可访问不等于必须看齐 |
| H 暂停后改口 | “正常员工答疑可以，我愿意按这个身份出席” → 改服务、送客户确认 | 行动有效，但结尾是更改服务范围；不能称已开启公司谜案 |

没有把任何一条自然结束的路线偷偷接上“于是我又点了下一页”。F 的逻辑强度不弥补 A—E 的动机不足，也不证明它更好玩。

## 删后分场：只保留人物确实需要做的事

### 1. 找昨晚那个人

> 失业三个月后，你进了澄川，做课程服务。今天第 47 天。昨天六点下班，夜间由组里代班。

沈航：“昨晚跟我聊的那个人今天在吗？我还有一句想问他。”

打开的是自己的课程服务席。原文和普通消息详情从一开始可查，顾成是实际操作者：

> 沈航：我想找个自己做过的问问，别再转介绍项目的人了。
>
> 小林：你想问什么？
>
> 沈航：你也在澄川上班？
>
> 小林：不在。我也是上课才知道的。
>
> 沈航：你自己取过钱吗？
>
> 小林：取过一次，后来才又放进去。

沈航可以离开，顾成可以承认昨晚是他回的并配合更正。只见获利句，仍不能断定顾成没有自己的经历；看见关系否认，才有已知事实上的冲突。对白不替玩家归纳这条推理。

### 2. 更正、退出，看得到结果

回复以“林见 · 澄川课程服务”发送并接管当前对话；只亮身份不自动解释昨夜。完整更正后，沈航可要求取消预约。取消、停代发、撤自己的出席，各自反馈实际结果，不默认替玩家做另外两项。

取消预约的详情原本就关联“远汀 · 同学交流”；可从原会话直接打开，不需要猜另一个日历入口。页面不高亮为线索，也不生成“核查后续”的待办。

退出本人后立即显示“你已退出；对外介绍不再显示你”。**删掉专门推进剧情的“查看交接结果”步骤**。已发生的安排变更就在同一页面正常显示；刷新或重复看不会推动另一轮事件。纸面呈现者只在对应角色实际处理完后更新结果，不替玩家点开它。

### 3. 同一场服务的两个身份

自己的出席详情保留普通事实：远汀是委托客户，出席人是课程服务员工，对学员的介绍却写“本场交流者不是澄川或远汀的工作人员”。员工可看本次服务的介绍和自己关联的安排，不能看全公司客户资料。

这一页值得核实资格矛盾；它**尚不构成远汀业务谜题**。远汀购买交流可以是营销，公司可能故意包装，也可能配置或介绍有误。付费关系不是隐藏罪名，知道谁付钱也不等于知道对方参与了身份伪装。

不再把“顾成也在公司，你知道吧？”单列为证明按钮。孟宁本来知道同组关系；玩家需要明确的是**哪一场、哪句对外介绍**。发本单链接并说“顾成也是员工，这里怎么说不是”，已经足够，不必同时附岗位、原文、版本号三件套。

### 4. 直接问她，别让她像表单校验器

| 玩家意思 | 修订后回应及行动 |
|---|---|
| “远汀为什么给我们钱？” | “他们委托我们做项目交流。”回答已知业务关系，不含糊藏住一个本来公开的客户；不代远汀说资金如何运转 |
| “所以是他们买我们替项目说好话？” | “他们买的是这场交流。昨晚顾成怎么说的，我还没看。”仅当她确未看过旧聊可这样答；已经收到则回应被指出的原句，不再装不知道 |
| “我不接了。” | “好，这场把你撤了。”移除本人及头像，正常处理缺员。未收到资格冲突时可换顾成；单独替补不证明故意欺骗 |
| “换顾成也一样，他也是员工；你看这句介绍。” | 查看本单后：“看到了。这句跟人对不上，这场先停。”随后本单新增安排真的暂停。她可能在纠错，也可能在止损，动作本身不替她洗清历史 |
| “只把我撤掉，我不管其他人。”同时已明确指出资格矛盾 | 先撤本人；孟宁仍暂停这一单核实。她已经知道具体问题，不能因玩家只保护自己就继续确认给他看 |
| “先停这场，我不想争了。” | 实际暂停，不要求先写指控或补证。只需能辨认是哪一场 |
| “你们是不是诈骗？” | 若具体场面已在共同上下文，回应本场问题；只有确实不知道对象时才问“你说昨晚的回复，还是这场介绍？”不机械要求重贴已收材料 |

同样事实和要求，不因先后顺序、礼貌程度或一个关键词改变孟宁的伦理。她想保住业务，也想避免明确的资格异议继续挂在自己的交付上；暂停本单比当着投诉者继续确认更符合这个局部动机。**本轮没有把她是否主导原来的包装写成已证实事实。**

### 5. 改口改变安排，不生成新的谜底

已暂停后，只说“我不怪你了”不恢复任何东西。明确同意以员工身份答疑，则本单撤掉非员工承诺，变为“员工答疑 · 待客户确认”；未确认前不开放新的学员预约。沈航已取消、本席已停止的状态保持。拒绝恢复就维持暂停，可以结束。

如果玩家主动要求联系远汀，当前设计只能提供一个尚未完成的调查出口，**不能假装已有完整分支**。需另行设计具体要核实的问题、双方可能回答及能区分的行动后果；本轮不编一个远汀联系人通过自白补洞，也不把“待客户确认”变成必须等下一封神秘邮件。

## 删后回走与验收状态

| 再走的路线 | 实际变化 | 仍不宣称什么 |
|---|---|---|
| 直接问孟宁 | 直接答委托关系，具体资格异议按已有上下文处理 | “为了获客”尚未被排除，不能宣布买方调查成立 |
| 提前暂停 | 请求有范围即可停，不先补一套证据 | 不把阻止成功写成少拿剧情的失败 |
| 只撤本人、未提矛盾 | 退出反馈一次给清，可离开；日后自发回看才知道替补 | 不安排玩家必然关注别人接班 |
| 只撤本人、已提矛盾 | 与先撤后告知一致：撤人并暂停本单 | 删除只为取证设计的继续确认场面 |
| 不按顺序、只看一面 | 已见事实决定怀疑范围，入口保留 | 不偷偷补玩家未读的条件 |
| 误判、改口、重复 | 撤回指控不等于恢复服务；重复请求不新建订单；旧回答不循环 | 不用程序状态变化冒充新剧情 |

**留下：**个人身份被借用、明确的雇佣关系谎言、自己的出席安排、真实收件与有效停止。**删掉：**显式询问已知雇佣关系的证明步骤、查交接作为推进按钮、对版本/确认的玩家端取证流程、孟宁因时序变化而继续销售的分支，以及“买方付费便会自然想追查”的预设。

公司层面的可疑安排可以保留；“知情后仍确认”只保留为判断标准，不再编排角色强行完成它。完整后半回 R01/R02：缺的是足以让“普通获客”解释不够用的新业务事实及可行动分歧。不要用 R03 的真人待测掩盖这个已能指出的缺口；局部人物理解仍可单独观察，代码阶段未开始。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
