# 故事规范：替你说的话

状态：2026-10-21。推翻《退给你的钱》的退款、代付与对账结构，历史固定于 [b48188c](https://github.com/TedShao/chengchuan-mystery-game/tree/b48188cb2fa2a45d881cc62f102ca767a6acea1f)。本轮先以正常代班与故意伪装两套解释做纸面反路线检查，再形成此稿。局部欺骗已有可区分事实；真人是否想继续调查仍未知。未改代码。动作与排演见 [SLICE](SLICE.md)。

## 核心事件与取舍

沈航来找“昨晚那个做过项目的同学”。玩家执行普通的原会话转接，入口却指向自己负责的课程服务席“小林”。昨晚顾成获准代班，这本来正常；异常是该席向沈航明确说过“我不在澄川上班”，并以普通参与者的亲身经历推荐远汀。

玩家可以先关掉自己席位的代发，再以真实员工身份接回同一段对话。送达的员工身份卡使沈航发现：他特意避开的销售关系，从未离开过聊天。原会话里有他主动询问雇佣关系、坐席针对性否认的往返；不是一张名字填错的卡，也不是未发出的练习稿。

**不修补旧代付案。** 旧事实无法排除代付加称呼错误，本案不声称后来证明那笔钱有罪。退役唐雯、银行尾号、退款截图、撤图任务和联合对账；只保留林见、沈航、顾成与公司电脑环境。没有新受害者、新损失或新凭证。

这也不是“一个人有两个身份就有罪”：课程客服代班、品牌昵称和代运营都可以正常。区分点是**实际受雇的操作者，在真实客户明确询问该关系后，继续将自己表述为无雇佣关系的独立参与者**。游戏只证明这次商业介绍中的有意伪装，不据此宣布整个投资项目诈骗。

## 公司、岗位与个人动机

澄川对外承接知禾课程的社群服务，为远汀提供项目咨询转介。通知、资料、预约和普通客服是真实工作。林见失业三个月后入职，第 47 天，从未投资远汀；他知道团队在下班后会代管服务席，不知道项目组把其中一些席位包装为“热心同学”。本组并非所有普通员工都知情。

知禾是入口品牌，远汀是付费委托方。作者层业务设定：公司卖给远汀的局部服务不是单纯传资料，而是在学员不信销售时，补出一个看似没有利益关系的推荐者。玩家本段只证明本席发生过这种伪装；谁批准、是否普遍、如何收费，尚不能凭单例下结论。社群接待因此成为制造信任的业务。境外经营背景可以继续调查，但本片段没有地点证据，不靠“远汀听起来像境外公司”下判断。

顾成安排代班，是为了接住沈航主动提出的“想问问真正做过的人”。他没有创造一个无缘无故自曝的角色：现成席位有课程联系历史，转接省事，品牌昵称也便于延续信任。对外头像取自林见自己的入职照，原卡用小林的本人介绍，玩家认得；不是替某个另行授权的真实学员管理其个人账号。他的失误是沈航要再次找同一个人，次日课程值班人林见能按原接待接回。这是一次复访撞上不同操作者，非服务器故障或秘密文件掉落。

林见的切身问题是：“我接回去后，是继续当那个不存在的推荐者，还是告诉他昨晚是谁在说话？”停掉代发能停止自己的参与，却不能让沈航自动知道昨天的推荐来自公司。玩家有理由处理已经留在别人认知里的那句话，而非完成一张撤销表。

| 时间 | 世界事实 | 为什么发生 / 玩家如何接触 |
|---|---|---|

| 昨日 20:07 | 沈航在知禾入口问能否与真正做过远汀的人聊一会儿 | 他不满意销售介绍，想听有亲历且无雇佣关系的人；还未在本案付款 |
| 昨日 20:10 | 顾成接入“小林”席，切换其对外角色为“同学交流”，接收原咨询 | 林见负责此席，不等于顾成只因昵称就获准编造独立经历 |
| 昨日 20:12—20:15 | 沈航问雇佣关系；顾成实际回答不在澄川工作，并以第一人称讲述取回投入的经历 | 这些是针对真实追问发送的回复，不是案例引文、自动欢迎语或演练材料 |
| 昨日稍后 | 沈航保留远汀咨询预约，希望次日继续问同一人 | 付钱或受损不是开场条件，不新增被骗事故作为紧迫感 |
| 今日开场前 | 沈航请求找昨晚的人，原会话进入林见的值班队列 | 顾成不在新玩家阅读前突然发一段解释，一切旧会话可直接打开 |
| 玩家接回 | 可停代发、接管本席，并选择向该会话显示真实员工身份 | 这是联系行为，不是更改全站角色或测试数据库；沈航收到后才知道身份 |
| 玩家后续 | 明确更正、保持旧口径、只停不说或退出 | 知情与联系按实际行为变化，原先的虚假陈述不被回溯改写 |

作者真相：顾成知道自己及林见均受雇于澄川，特意用同学角色回应沈航对独立性的要求。关于获利经历是否取自他人、远汀实际资金去向，本片段不作事实判定；**即使那段获利曾发生在别人身上，也不能使“我不在澄川工作”的针对性否认成为真话。**

## 表二：人物认知、需求与冲突

| 人物 | 开场知道 / 想要 | 局部反应动机 |
|---|---|---|
| 林见 | 知道自己是课程员工，未投远汀、昨晚未值班，席位可合法代班 | 愿意承担课程工作，不一定愿意承接独立推荐者的承诺；可以选择不继续调查 |
| 沈航 | 知道对方自称无雇佣关系，自己曾明确询问；不知道“小林”背后的坐席 | 想问亲历，不想再被转回销售；身份暴露后先要求知道谁作了保证，不立即相信全平台都是骗局 |
| 顾成 | 知道自己发过的内容和真实关系，只在实际收到/查阅后知道玩家的新动作 | 可以承认代班、同意更正并转回普通项目咨询，以保留客户；不会必须自曝全公司，也不凭空删历史 |

沈航不是全知证人。他只能解释自己的问题和实际收到的回复；林见的真实员工身份由玩家能控制的正常员工联系方式交付，不靠他替玩家猜测。

## 表三：线索与行动验证

| 可见对象 | 初读解释 | 实际行动 / 重新理解 |
|---|---|---|
| “找昨晚那个人”的请求 | 普通复访 | 打开原会话、转接原席或直接问顾成；原席竟归自己负责，产生个人问题而非自动定罪 |
| 本席当前对外角色“同学交流” | 公司昵称或接待分工 | 接回时选择真实员工身份；只改个人设置不等于已向沈航披露 |
| 原对话中“是不是公司的人”的问答 | 若当独立同学看，是正常建立信任 | 员工身份已明确后，针对雇佣关系的否认与事实冲突；不靠昵称推定 |
| 原回复的操作者信息 | 正常服务台的代班出处 | 普通“消息详情”显示本组顾成实际发送；与其“我接的班”相容，不要求破解日志 |
| 沈航收到真实身份后的反应 | 可能以为只是换了客服 | 保持同一会话，允许他明确问“昨晚那个也在你们公司吗”；玩家按事实说明，不能只展示新身份就宣称昨夜欺骗已证实 |

推理链：**该会话实际收到无雇佣关系的明确陈述 → 该回复由澄川的在岗员工针对问题发出 → 操作者知道自己的雇佣关系 → 此处存在有意伪装。** 单独接管一个账号、发现代班或改变名片都不够；这三项不能偷换成同一个证据。

## 表四：两种解释怎样被区分

| 解释 | 可预期、可观察的结果 | 本案能收窄到哪里 |
|---|---|---|
| 正常代班 / 昵称填错 | 换真实身份后，旧内容仍是员工能够诚实提供的服务；若过去身份被问过，应说明公司关系或未作否认 | 仅“原席是我的”时仍成立；遇到已发送的明确关系否认才被排除 |
| 同事讲自己的投资经历 | 获利经历可能不是林见本人的，不能凭林见没投资就否定全部 | 即使经历真实，顾成受雇却否认雇佣关系仍矛盾；不查银行凭证救场 |
| 给真实独立学员代运营 | 应有被明确指代的独立本人，消息不能冒充操作者自己独立于公司 | 本席对外是林见本人的头像与介绍，无另一个被代理的学员；顾成直接承接“你是不是公司的人”的第一人称问答；不将任何代写一概视为欺骗 |
| 课程演练或误发模板 | 只能在演练环境或作为明确示例被理解；一条孤立误发不够判断意图 | 沈航真实会话中的连续追问、操作者有针对性的回答及次日复访排除单条称呼/模板错误；不靠截图外观 |
| 公司项目必为资金骗局 | 本片段需有资金去向或投资履行的独立事实才可判断 | 未获得，不能宣称已破整个案件或已定位境外园区 |

拒绝承认雇佣关系的**内容**承担证明作用，接回对话承担玩家能够行动并改变他人认知的作用。不是设计一个“点击按钮就检测犯罪”的软件测试。

## 表五：场面推进与真正后果

| 场面 | 当下行动 | 改变什么 / 留下什么问题 |
|---|---|---|
| 复访 | 直接找原接待、问顾成或查看前文 | 先发现自己的席位被用于一种陌生关系；可以先暂停，不强制读完 |
| 接回 | 显示真实员工身份或仅内部接手，亦可保持暂停 | 沈航是否知道公司关系有区别；不是换一行 UI 文字就算已经告知 |
| 对质 | 对照明确问答，说清可证实的角色事实 | 能区分正常代班与局部欺骗，不依赖顾成说漏嘴 |
| 拒绝冒充 | 撤回自己本席的独立推荐表述、关闭本席代发；是否继续普通服务另选 | 沈航失去先前信任的“第三个人”，顾成只能尝试以公开公司身份继续接待 |
| 公司调查入口 | 玩家可在自己有权限的本席会话中按“同学交流”查既有接待；也可结束 | 新问题是“公司把这种独立推荐交付给谁，自己的席位还承担过什么”，不是再索一张退款凭证；不自动宣布查询到更多受害者 |

## 表六：纸面检验结果与限度

| 路线 | 结果 |
|---|---|
| 直接问顾成 | 他坦白“我昨晚代班”也只解释操作者；不要求他给出骗局答案。明确关系否认仍在实际旧会话里 |
| 最早停本席 / 取消后续咨询 | 停止有效，原会话可查；不必发出一句新谎言取证，没有暗中换席恢复 |
| 只看开场或名片 | 只能怀疑陌生角色，正常代班仍合理；不自动授予欺骗结论 |
| 先用真实身份接回 | 沈航可先问是否换了人；追溯同一段的操作者和关系问答即可核实，不强求先读材料 |
| 只查历史、不再联系 | 可以在本席原记录得出局部结论，不强迫沈航配合新的实验；对方不自动获知 |
| 拒绝 / 改口 / 重复 | 停、接回、是否实际披露各自独立；一旦披露不能靠改卡抹去记忆；重复不制造新事件 |

这轮纸面检查修掉了“只要身份切换就证明欺骗”“学员听到员工身份就立刻取消”“暂停后还继续发话”的三个草案问题。当前结构可在约定的虚构世界规则下区分局部伪装与正常代班；吸引力、对话自然度和行动发现率未获真人验证。不得标注整体游戏或整套公司犯罪已经通过。
