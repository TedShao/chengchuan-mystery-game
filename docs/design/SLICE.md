## 调查空间与明确操作

浏览器保留后退、最近访问、标签、在旁边打开和来源卡；知禾课程页、澄川接待台、远桥页面各有自己的外观。模拟域名留在游戏内 `.test` 路由。关键链接有文本和下划线，已访问可辨认；没有内容的栏目不伪装成可点击入口。

常规搜索不加密钥，按姓名、日期、标题和正文检索，可筛选来源。关键材料均有正常业务链接，不靠唯一关键词。并排比较不替玩家高亮矛盾；便签不自动生成“公司涉嫌诈骗”的结论。

文档、表格、PPT、邮件、摸鱼仍从任务栏自由访问，本幕不要求使用它们提交东西。帮助可关，关闭后按钮和反馈仍完整。布局随窄屏改为标签切换；状态有文字、焦点可见；ESC 关闭预览不提交。此处是设计约束，尚未做运行测试。

## 修订片段：只做一次来源核实，不再连环转问

以下场次用于纸面扮演，玩家没有编号、调查清单或答案高亮。

### 入口与局部冲突

只问小雨昨晚是谁回的，她承认：“是我。她一直找你，我就沿着那个会话回了。这事我该先问你。”停名即时生效。若拿 P3/P4 问，她自己打开，停止推荐，把**实际收到的内容**转问周衡；没收到的原话不擅自补进去。

周衡看到页面矛盾：“旧链接先撤。我请项目回她。”旧转发真实取消。罗青若允许新联系，范围是：“可以回消息。就说怎么退，下一期的东西别再发了。”同样意思已经明确时不重复问；玩家没有权限代她许可，只有员工意见时按员工意见处理。

周衡接手且读到限制后，对她说：“旧入口先不用了，项目会回复你的退出问题。”本案 P5 随后出现他发往项目协作渠道的摘要：“罗青愿意了解下一期，请发说明，先不要催她确认。”**这一步仍只是失信挽留，不算公司悬疑已经成立。**

### 另一身份的回复，可从两个方向核实

本案实际发生的项目回复为：

> 远桥项目服务：“您在知禾留的是‘愿意了解下一期’，我把说明发您，先不用确认。”

下面仅有两句续期安排：本期金额转入下一期；确认后按下一期结束时间申请退出。罗青没有自动确认。周衡随后在课程端引用它：“项目回的是这条。”这是他试图结束争议的动作，不是作者提供的权威答案。

玩家可以不再理主管，直接点项目回复的服务身份进入本案协作；也可从 P5 查看关联回复。普通“发送详情”显示：

| 字段 | 本案实际值 | 能检验什么 |
|---|---|---|
| 对客身份 | 远桥项目服务 | 客户看到的名字，不等于经办人的公司 |
| 实际经办 | 周衡（澄川员工账号） | 与 P5 摘要作者是同一账号；不只凭两人同名判断 |
| 关联依据 | P5 的那份摘要；未附客户原会话 | 点开即可对照“愿意了解”究竟谁写的，不靠隐写或猜 ID |

这三项随消息实际发送就存在，属于本案员工协作副本，不能读到其他客户或投资账户。玩家不必截三张图回去提交判定；看完可以直接停下、引用询问或更正。

**不把“同一人代回”当谜底。** 可检验的具体冲突是：周衡已读到“不发下一期”，却把自己改写的摘要称作转来的客户原话，再把自己以项目身份发的回复引用回来。两条消息没有构成两方确认。若看完只觉得公司外包客服正常，仍是合理起点，需要对照依据，不能由系统宣判猜错。

### 直接问、绕过问、拒绝：结果各是什么

| 玩家实际行动 | 简短回应 | 真实后果与证据界限 |
|---|---|---|
| 直接问周衡“她哪说过愿意？你改了她的意思”并给原话 | “这句我改。下一期先不发了。” | 取消未发内容，已发部分向实际收件者更正。若项目回复尚未产生，不补发一份给玩家破案；此路可能停在销售失信 |

| 问小雨“你早就知道是我们在回？” | “我没接过那个号。昨晚我只把她的事发给周衡了。” | 她只说明亲历；若收到 P6 才能评论这次经办，不替主管讲完整架构，也不自动转发玩家私聊 |
| 拒绝本人经办但继续查看本案 | 周衡确认换公司身份接手 | 名片停用、责任交还，保留副本可查已发生消息；询问不恢复经办责任 |

| 玩家只关闭自己的后续同步 | 不再通知玩家 | 不替罗青撤销许可，也不使已授权的公司联系消失；不强推玩家回来阅读 |

## 修订稿再走：三条主路与反例

**统一条件：**关闭指引，不给作者真相、不说双身份。既有材料按需要提供；NPC 动作由已收到的请求与许可决定，阅读和点击数量不推进发送。下面不是人类体验结果。

### A 先质问，不等“正确剧情”

1. P3 → P4 → 问小雨。只知页面动作不符；普通误发仍合理。
2. 引用客户原话给主管。旧入口撤掉；若随后已经出现 P5/P6，能发现摘要不实，此时“强行挽留”足够解释。
3. 直接要求停发。主管更正并停发。**真实停止点：**不想再查的玩家可以离开，不能统计为公司调查成功。
4. 若玩家不信“项目回的是这条”，可打开被引用的消息，查看经办与依据。新事实是同一人、同一摘要；可再对照原话，判断这一次并没有来自另一方的佐证。
5. 想继续的对象现在可以具体到“最初那条重开申请又是谁在回”。原 P3 仍只有外部来源，不能自动归责周衡；此处留下有限疑问，不发布搜查待办。

**提前反驳：**第 2 步就阻止一切新发送，后面没有 P6，路线只完成制止。不能以缺少高潮认定玩家玩错。

### B 不问主管，直接找项目核实

1. 从 P1 直接交还，不先问主管。罗青自己打开原有入口、提出“不接下一期”，主管在取得仅答退出的许可后发出摘要与项目回复。玩家先读 P6 中声称她留言“愿意了解”的句子，点服务身份进入协作，或先看详情。这条路线的页面异常由客户发现，不能算玩家发现。
2. 问“原话在哪”。对方引用 P5，而非另造一份客户同意。玩家能对照自己已见的罗青原话；没有见过原话时，回原课程会话即可，不要求精准关键词。
3. 打开发送详情：两边实际经办都是周衡。**第一解释仍可为正常代运营。** 再看该答复依据只是他的摘要，结合他此前已读到的限制，才足以否定本次所谓两方确认。
4. 把完整原话给此渠道。项目身份的失实说明被更正，后续停发；周衡不能在内部再说“项目不知道她要退”，因为收到两端内容的是同一个人。
5. 不必回主管报到或等“原接待”。此路要观察的自主问题是“课程公司为何也在写项目答复，以及这些答复依据什么”。如果只关心谁来退款，仍可能退化为客服体验，需记为反例。

**提前制止的变体：**项目身份尚未发送时，玩家拿原话明确反对该摘要，则不再产生假原话回复；仍可发现渠道代运营，但证据更弱。普通询问和明确制止按表达的意思区分，不设置指定词句。

### C 拒绝工作，不拒绝自己的判断；也允许完全退出

1. 不读链接，先停名、交还。两项真实生效，罗青的联系许可另算。
2. 保留本案只读同步时，可以旁观后来已发生的回复，从 P6 直接查详情；不再被安排写摘要、重发链接或提交更正表。
3. 若看到双方实际由同一人回复，仍须比较依据；仅仅看到周衡姓名不足以判公司骗人。可以独立引用询问，不恢复本人名片。
4. 若玩家关闭同步、罗青也拒绝后续，新回复不出现。停在名字问题解决或销售失信均可；不得用另一名受害者或小雨的暗示把玩家拽回来。

**这条路线暴露的限制：**设计不能保证每个拒绝者都想追查。评价的是有继续选择时是否出现自主核实，不是强行让所有人通关同一揭示。

### 漏看、误判与改口的回查

| 逆序 / 边界操作 | 必须保留的差异 |
|---|---|
| 只见周衡代回就说“远桥全是我们公司” | 仅证明本案渠道和经办；允许改口为“这次回复没有另一方确认”，不认证品牌所有人员都相同 |
| 漏附“不发下一期”，后来才补 | 要检查周衡是否已从其他实际渠道读到完整原话；同一人不能利用不同身份假装忘记。确实后来才知道时，不倒算早先明知 |
| 先怪小雨，再查到周衡 | 撤回无证据指控；小雨知道的范围按实际收件，主管不隔空知道员工私聊 |
| 漏看链接，先允许原 P5 发给客户 | 罗青自己看见继续条款后可追问；可补救，但不算玩家自主发现。她不自动确认资金 |
| 客户后来真的愿意了解 | 需她自己的新消息。此后按新意愿发送不算本次误述；此前失实内容与更正仍保留 |
| 重复追问、停名、点已取消项；说“知道了” | 不生成新发送或怒气值；不恢复权限。“为什么”和“请停止”不是同一动作，不能用同一句确认代替 |
| 先更正再停止，或先停止再更正 | 停止管未来，更正管已发送说法；收件时间定边界，不因读得慢补出损失。不同服务身份共享周衡知识，但不同收件人仍需实际收到更正 |

## 本轮删改与判定

删除独立项目席“查不到、我再转问”的等待；压缩重复转发和追问；撤回“发现改写就自然调查公司”的乐观推断。P1—P6 不增加文件，只让原有发送详情承担一次可直接完成的来源核实。普通办公与摸鱼继续自由访问。

**修订结论仍是待证据。** 同一人、两种身份、自己改写的摘要又被自己引用，可以否定本次独立佐证；强行挽留仍可能解释其商业动机，不能据此查明完整骗局。此处预期产生的是对公司提供何种服务、哪些答复有真实依据的具体疑问，不是系统宣布公司有罪。

[H001](../experiments/H001/game-design-hypothesis.json)记录本轮整体可用性，不作单变量归因。观察新玩家在停发成功后是否仍主动查来源，绕过主管是否得到实质新判断，以及拒绝是否真的可结束。若只像查客服质检记录，或必须靠主持人提醒“同一个人”才继续，**本段未通过**；不再靠加第三份证明、第三轮转问或强制危机延命。
