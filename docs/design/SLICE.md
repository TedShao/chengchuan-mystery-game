# 网页片段：退给你的钱

状态：2026-10-20，按 [700b7c2](https://github.com/TedShao/chengchuan-mystery-game/tree/700b7c2b182a52f0be0cd88e7354831d63d2c696) 完成无指引纸面审查并删改。**局部可核实，公司调查衔接仍不充分。** 作者已读底稿，只能限制每条路径可用的信息，不能声称自己是真正不知情的新玩家。本轮未运行网页、未改代码、没有真人数据。

## 先记录旧稿哪里失败，再写改稿

下表为从正文反向提取的六类证据。`explicit` 指原稿明写，不代表现实性或推理有效性已经通过。

| 类别 | 提取结果与依据强度 | 审查判断 |
|---|---|---|
| 事实 | 两人同笔收付及顾成事前安排：explicit；故意隐瞒：作者层 explicit | 意图未必能被玩家独立识别 |
| 认知 | 两端各以为与平台交易：explicit；新人必然继续查公司：weak inference | 两种用途可被代付解释，继续动机不能预写 |
| 线索 | 两条开场直接报姓名及财务角色：explicit | 太早给出关系，后续只是在验证已亮出的答案 |
| 动机 / 机会 / 手段 | 顾成有安排权限：explicit；误称与故意之间的区分事实：missing | 有权限不等于有欺骗意图，安排在付款前也不排除称呼错误 |
| 场面 | 对账、询问、再确认、联合核对：explicit | 玩家很容易只是在办售后；多一轮问答没有新问题 |
| 验证 | 拒绝资金动作仍可查：explicit；玩家何时被要求动资金：missing | 原本没有经办任务，却把拒绝资金参与列为主要路线；应检验实际拒绝转交或调查，而非宣称不存在的经办被停止 |

### 旧稿反路线：每条只使用当步已见信息

不是用“之后玩家当然去问另一人”补路；每条先走到一个合理结束点。

| 路线 | 所见 → 自选动作 → 可获得的回应 | 当步能判断什么 / 断点 |
|---|---|---|
| 1. 先问主管 | 只看沈航的“财务唐雯” → 问“你们哪位财务？” → 顾成原有代付解释 | 没见唐雯身份就没有矛盾；原稿已有“未说明对象先澄清”的边界，但单边问题缺具体回应；若照搬“别把两边混着回”，会泄露玩家未见的关联 |
| 2. 提前撤图撤约 | 只看唐雯 → 撤图、取消她电话 → 状态已完成 → 结束 | 唐雯的钱已到、意愿落实，没有自然必做的下一步。旧路线把“再读另一条”直接写进顺序，是作者替玩家继续 |
| 3. 只看唐雯 | 读退款上下文和沈航来款 → 问是否到账 → 是 | 陌生付款人不自动异常；不允许替玩家补上另一端“投资款”信息 |
| 4. 只看沈航 | 读指引和付款记录 → 问顾成登记是否收到 → 原稿登记已在 | 财务姓名加真实付款可解释为普通收款；没有唐雯身份，不能形成跨人冲突 |
| 5. 两边都读再问错字 | 完整记录 → “是代付，但把唐雯写成财务了？” | 原稿没有区分反证；顾成可以更正措辞且保持停止。先后时间证明参与，不能单独证明故意；这是主断点 |
| 6. 拒绝参与 | 不转述、不再接项目联系 → 停止自己的转交 | 合理离开，旧稿的“拒绝资金经办”没有对应要求；不能靠 NPC 自动调查补完 |
| 7. 误判后改口 | 先告诉沈航“没问题” → 后来看到退出会话 → 更正身份 | 可以收回背书，但不知道他一定取消预约。旧稿把知道角色与立刻退出绑定，人物过于听话 |

第五路包含一个原稿未逐字写出的合理解释压力测试，不是假装已经看到它在网页中触发。把“称呼错误”视为可容纳解释，恰好暴露原证据的非唯一性。

## 修订开场：不让两条摘要替玩家连线

首屏短背景：林见，澄川课程服务，第 47 天。知禾是你服务的课程品牌，顾成接项目咨询。你可以处理本组宣传和预约，不能动学员的钱。无需读公司犯罪背景或先选工作内容。

唐雯今日开场前发来：

> “钱收到了。那张图撤了吧，我只发给你们确认一下。今天的电话也不用打了。”

沈航在同一收件列表的另一条消息：

> “今天还是两点吗？我午休就那一会儿，别再晚了。”

沈航只关心预约时间。他昨晚的付款指引和付款记录在原会话前文，唐雯的原收款截图也在她的会话中。**从开场就能打开，不能删掉姓名、模糊正文或读到指定进度才解锁。** 列表照常显示各自姓名及上述摘要，没有“关联学员”标签。

这项修改只移除摘要剧透，不宣称它增强了吸引力：减去直白关联后，也可能变成两条无聊待办。这个代价必须保留在状态与验收中。

撤图、取消唐雯电话各一次即可完成，普通文字反馈就够。不能在完成后弹出“还有一名付款人”等续查提示，也不要求先查资金来源。沈航预约独立，未实际取消就维持原状。

## 探索空间与事实材料

保留自由办公。主线需要的只有本组服务台、原宣传与预约入口、可并排查看的历史消息与附件；不要求轮流使用所有办公软件。

| 已存在材料 | 内容与用途 | 可从哪里自然进入 |
|---|---|---|
| 唐雯原服务会话 | 退出、退款账户；18:10 顾成回复“按这张卡退回”；稍后的收款截图 | 她要求撤下的正是该截图，原消息可展开；不是完成撤图的前置 |
| 唐雯收款详情 | 昨日 19:02，收入 3,000 元；付款沈航尾号 7721，收款唐雯尾号 4086 | 原附件，或她愿意就本笔澄清；不是必索取一份新证明 |
| 沈航原服务会话 | 18:35 项目席顾成发送收款信息，称“平台财务”；沈航随后反馈付款 | 任意打开会话往前查看，或询问他实际收到的指引 |
| 沈航付款详情 | 昨日 19:02，支出 3,000 元；同一双方及对应尾号 | 已发附件；用于支持本笔对应，不能只凭同名同额 |

姓名搜索只搜本组已有资料。读到沈航这个名字可以搜沈航；读到“财务唐雯”可以查她是谁。这些是**可用出口而非宣称新人一定会采取的动作**。只看一端仍可结束，不让信息自动传到玩家脑中。

引用既有完整材料即可提出质疑；删掉“必须向双方再确认一次才能证明”的门槛。只在对象或来源确有歧义时追问，不把重复核对当解谜。不同银行的交易编号无需相同，账号尾号也不是通用配对密码。所有材料均虚构，不连接真实银行。

## 主管与两名学员：答具体问题

| 玩家实际问什么 / 当前信息 | 人物回应与行为 | 不得自动附带什么 |
|---|---|---|
| 只问顾成沈航的登记 | “昨晚那笔登记了。两点还是原来的时间。” | 不主动提唐雯或“别混两边”，不承诺真正买入了投资资产 |
| 已指出同笔付款，问是否代付 | “那笔按远汀的安排付，唐雯这边确认收到了。” | 不自曝公司全套业务，不把这句当授权或合法性的证明 |
| 指出“唐雯明明是学员，怎么写财务” | “那条称呼写错了。我去跟沈航说清楚。”若玩家同意交给他处理，他实际向沈航更正“唐雯是收款学员，不是公司财务” | 不额外捏造授权书，不恢复任何取消；更正不证明故意或无辜 |
| 唐雯被问付款人 | “记录上是沈航。你们说是退款，我就查了一下到账。” | 不自动知道沈航的投资安排 |
| 沈航被告知收款人是另一名学员，但未收到其他信息 | “那登记的三千还算不算？我当时问的就是转给谁。” | 不自动相信被骗、不自动取消预约；他需要解释自己的处境 |
| 唐雯得知另一方想找她 | “图撤了就行。别把我联系方式给他。” | 不强制拉群、不要求退钱；拒绝联系不等于她有罪 |

顾成负责的会话原本可见，只在实际发出更正后出现新消息和已送达状态，不把承诺当发送。玩家可选择不让他代为回复；主角自己的草稿不广播。共用服务台也不承诺永久私密，顾成实际查看该会话后才知道其新增内容。

顾成的更正路线必须存在，否则玩家只能问到一套专为显得可疑设计的回避话。**允许解释足以使玩家停止，正说明公司后半缺少区分事实；不能把顺畅退出反写成更深阴谋。**

## 选择改变什么

原稿已经允许不拉群。本轮进一步压缩联合核对的高潮地位：分别告知也能改变关系；若玩家主动提出且双方愿意，仍可有限交流。拒绝共享不锁其他已获材料。

| 实际操作 | 后续变化 | 证据与权限边界 |
|---|---|---|
| 只撤图撤约 | 唐雯不再被本次宣传使用，她的电话取消 | 不延迟生效换取调查，不影响沈航预约 |
| 将身份疑问交顾成 | 他实际更正后，沈航得到纠正、可能继续保留电话以询问登记 | 玩家可以核对发出的内容；不能把知晓身份直接等同退出 |
| 自己只更正身份 | 沈航问登记是否有效，尚无公司资金结论；没有改约操作就保留预约 | 不替他宣布被骗或必须取消 |
| 告知具体收付关系及有限疑虑 | 沈航要求“今天先别约，我先弄清楚这笔”，经该请求取消；唐雯若未收到仍不知其疑虑 | 需要真实传达及当事人的请求，不靠阅读完成度触发 |
| 撤回自己曾发的“已核实没问题” | 实际收到更正后，沈航追问“你核实了什么？”；可以只得到诚实的有限回答 | 私下改变看法不等于通知，更正不保证立刻获得信任 |
| 停止自己的后续项目转交 | 当前负责的未来转交停止；既有消息可回看 | 不扩大为全公司停业，不悄悄换同事替玩家继续已停止安排 |
| 完全拒绝调查与联系 | 保留停止状态，可以回自由办公或结束 | 不以拒绝不存在的经办请求充数，不生突发损失或同事代查送谜底 |

没有人向主角提出经办资金，因此不把“拒绝转账”写成承担主要后果的选择；玩家口头表明不碰钱可简单确认边界。复合问法“我不接了，但你先说清收款人是谁”分别处理停止转交与询问，不把拒绝解读成关闭全部对话。

重复撤约显示原状态，重复询问定位原消息；不同问题得到不同事实，新的材料或实际更正才改变回应。误判唐雯知情时，她可拒绝额外分享；撤回指控后重新征求许可，不刷好感恢复证据。

## 删后按同路再走：保留哪些问题

| 路线 | 删后结果 | 本次判定 |
|---|---|---|
| 沈航先行，直接问主管 | 先得到预约 / 登记范围内回应；只有自己打开指引或提出身份疑问才谈那一层 | 消除提前泄露；首条仍可能像普通待办，兴趣未证明 |
| 唐雯先行，提前撤图撤约 | 可以立即完成并离开；若主动打开原图，付款人提供可搜对象 | 没有强制拖延；缺少必然继续动机，不假装通过 |
| 只看任一方 | 形成该方有限事实，不生成两端结论或 NPC 全知回复 | 信息公平；不追查是有效选择 |
| 全读后问“代付加称呼错误” | 可以得到更正并保持停止；原有材料仍不能区分故意 | **公司调查反证仍未解决，R01/R02 继续** |
| 拒绝参与 | 没有虚构资金经办任务；真实停止自己的转交，仍可问事实 | 拒绝落到真实的转交；完全拒绝有正常结束 |
| 先背书后改口 | 依据实际发送更正，沈航先关心自己登记，不自动配合作者取消 | 后果更具体；不声称已产生更强悬疑 |

目前能支持“公司参与了这笔安排，角色说明不可靠”，不能支持“公司故意以新还旧已查明”。继续调查的兴趣可能来自对人的关切、题材预期或单纯不信任主管，都应与推理效果区分。

**本轮结论：**删掉摘要直给与重复确认，压缩联合核对；拒绝转为停止真实转交，取消不再仅由身份告知触发。局部更诚实，也更短；仍未补出可区分“正常安排加称呼错误”的公司业务事实。若后续设计仍只有再问一次、再看一份凭证，就应放弃这个核心，不以更多售后对话补满十分钟。状态与下一步见 [PLAN](../PLAN.md)、[H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
