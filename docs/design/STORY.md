# 故事规范：你的离线时间

状态：2026-10-20，完成“普通客服发错链接”专项纸面反证后修订。**不是陌生玩家盲测，尚未证明好玩。** 当前事实以本文为准；可见材料、分支和逐步排演见 [SLICE](SLICE.md)，执行状态只在 [PLAN](../PLAN.md) 维护。未改游戏代码。

## 本幕现在讲什么

入职第 47 天，林见收到老学员罗青的消息：昨晚“他”说先别撤掉申请，她想确认这句话还算不算数。实际回复者是同事小雨，正常的课程代班被用在了课程之外。

林见可以马上问清、停用名字、拒绝继续接待。这些行动都有效。但罗青手上还有一个远桥发来的链接，对方说可以用它重开退出申请。打开后，页面却要求她确认把现有项目资金留到下一期。

**撤名有效，旧链接也可以撤掉；新的问题是，罗青明明只愿意问退出，公司转给项目方的却成了“愿意了解下一期”。** 项目方随后按照这份转述发来续期说明。玩家可以比较原话、公司实际转出的内容及对方真正发来的东西，逐步区别误发、误解与主动改写诉求。安排联系人本身不构成罪证。玩家可以先查网页、跳过身份调查，也可以拒绝再联系任何人，到此结束。

本幕保留公司电脑、罗青、小雨、周衡和自由探索。删掉转正填报、答疑会、收齐回执、“结束交班”总按钮、第二天排班与固定绑架结局。上一轮两个骨架的比较留在 Git 历史，不继续占据当前故事正文。

## 公司与工作的事实边界

澄川是境内财经内容与用户运营公司；知禾学堂是它运营的课程品牌；远桥是课程之外的投资项目服务品牌。真实授课、资料分发、课程退款与发工资都存在。澄川核心经营者同时为境外虚假投资团队引流、维系客户，并隐瞒这种协作。这不是一家没有业务的纯空壳。

| 人 / 岗位 | 日常工作 | 本幕可接触的范围 |
|---|---|---|
| 林见，24 岁，课程运营助理 | 上传资料、解决播放问题、接待课程学员 | 分给自己的会话、自己名片、公开网页、客户主动提供的材料；没有投资账户操作权 |
| 何小雨，28 岁，学习服务 | 代班、课程订单售后、把超出权限的问题交给主管 | 知道自己发过什么及收到的安排；看不到项目资金处理 |
| 周衡，36 岁，客户运营主管 | 分配接待、安排项目介绍、处理持续投诉 | 知道引流用途和两端联系安排；可以决定重发什么，不能读玩家本地草稿 |
| 罗青，39 岁，小店经营者 | 经营店铺；曾购买课程并接触远桥 | 自己收到的消息、自己的项目申请；不认识全部内部人员 |

林见待业三个月才找到这份工作。此前 46 天他确实解决过课程问题，4 月 7 日帮罗青恢复过播放。课程组可以借用学习助理名片代班，后台记录真实经办人。林见知道这种安排，**不能让熟悉自己工作的他假装完全不懂代班，只为陪玩家猜盗号**。

他此前没有参与罗青的项目事项。昨晚小雨以其名片作了承诺，再将课程会话交回他；今早第一次看见原本分开的事项。为什么没早发现，靠岗位及会话范围解释，不靠员工集体迟钝。

现实依据仍限于公开案例存在的境内引流、境外协作及分层组织；姓名、系统、链接及本幕安排均为虚构，不称为真实案件复刻。[2024 年典型案例](https://www.court.gov.cn/zixun/xiangqing/439351.html)、[2022 年典型案例](https://www.court.gov.cn/zixun/xiangqing/371131.html)。共用客服、境外地址和外包关系本身不足以证明犯罪。

## 人物要什么，为什么现在这样做

**林见**先想把自己的责任说清。他可以止用名字、帮罗青核实、先相信公司或离开。继续调查的理由应是刚看到的行为与承诺不相容，不是突然被赋予拯救所有人的使命。撤名不需要重新接手案件；更正误判也不等于同意继续工作。

**罗青**在远桥投入了两万元，这一金额目前只是她的陈述。她想退出，怕自己弄错步骤，既不愿无休止等，也不愿误确认继续。她信任林见来自过去一个具体的小忙；不会因陌生员工一句“诈骗”就全盘相信。她把链接交给林见是为了问昨晚的建议，不是专门给侦探送线索。她可以自己读懂页面并选择不确认，不需要玩家解救才有判断能力。

**小雨**想留住沟通，也不想承认自己承诺过满。她办成过罗青的课程退款，因此高估了公司处理另一项业务的能力。昨晚她只知道周衡说今天会有人接；没打开远桥的新入口。玩家直接问，她直接承认代班。若玩家把页面内容发给她，她会自己打开检查；确认页面要求继续后，她撤回对入口的推荐，追问周衡。她仍不知道投资后台，不能突然说完整犯罪真相。

**周衡**需要罗青继续留在项目沟通中。直接再发被识破的入口容易激化投诉，他会撤掉链接，以“回复退出问题”取得一次文字联系的机会；给项目接待方的摘要却写成罗青愿意了解下一期。他把“允许回复”当作可以重新推介的空隙，指望客户看过说明后改变决定。不能让他口头宣布这套打算：玩家看到的是两端实际发出的内容。被拿原话质疑后，他可以停止后续推介、补送更正以平息争执，但仍拿不出退出结果。及时纠正是一项真实让步，不抹去此前转述。

| 罗青允许仅答退出，原话实际送达后 | 周衡读到“下一期不要再发了”，给她回复“旧入口先不用了，项目会回复你的退出问题”；随后以公司身份转出“罗青愿意了解下一期，请发说明，先不要催她确认” | 新摘要由他人工发送，未附原会话；他将有限联系意愿换成了产品兴趣。若未获联系许可或已收到全面拒绝，不发生这一行 |
| 项目收到新摘要后 | 接待方据此给罗青发“按澄川转来的咨询，现有金额可沿用到下一期……”及续期说明 | 这次行为有明确新请求来源，不是旧链接自动重试；原客户限制没有传给该接待人 |
| 原话与转述被指出后 | 周衡撤掉未发项；若已转出，则向项目补送“她不接受下一期，停发”，通知罗青停止推介；退出仍未解决 | 保护关系、收束争执。更正只影响后续；已送达内容不删除，不把阻止成功伪装成受害结果 |

这些是条件事件，不是人人必看的剧情。即使没人调查，周衡在取得相应联系许可后也会作同样转述；翻页或“猜对”不触发发送。新摘要必须有晚于原话接收的实际发送记录；旧模板、未发草稿或已取消项不能证明已经误导客户。

周衡没有留下犯罪自白。他仍把重新推介当作能辩解的客户挽留，低估了课程同事会核对两端的诉求。转出内容本来就随本案协作消息留存，供交接人员知道对方按什么问题答复；不是为玩家开放一个秘密犯罪后台。不要追加删记录、定位 IP 或暗号。

| 项目接待席（不另扩人物线） | 收到的公司摘要及自己的续期说明；没有原退出申请的处理权限 | 新接待人未收到罗青原话；本幕不推定其掌握全部历史 | 按实际收到的内容回复；若原话直接送到，就不发续期内容，只转问原接待，不虚构退出结果 |

**企业会话不是私密保险箱。** 课程会话标明团队可查阅；发给罗青不等于只有她永久可见。周衡接手或有人转发时可读到相应记录；他必须实际打开或接收后才反应。员工私聊、未发送草稿和本地笔记不自动进入团队会话。复制给小雨哪几项，她就先知道哪几项；有权限不等于全知。

远桥接待席不在课程团队中，只收到实际转出的摘要或附件。林见交还后保留本条会话的只读协作副本；新外发和回复若同步到本案才可见，不获得其他客户或项目后台权限。协作来源是员工视图，罗青只看发给她的正文，不能自动读到公司内部转述。选择退出并关闭后续同步则停止通知，不能靠全知视角补齐证据。

不需要 P7 额外申请截图、转介页的边界声明或一堆预约回执才能发现核心矛盾。原来的“共用后台因此可疑”降为背景，删除“已核实”一词的语义考试。客户页面是游戏内只读材料，林见不能代她按资金确认按钮。

## 表四：竞争解释与可用的验证

| 解释 | 为什么合理 | 玩家可做的区分 | 尚不能下的结论 |
|---|---|---|---|
| 普通代班说过头 | 小雨有权限，也确实曾帮过忙 | 直接问发送者即可解决这部分，不拖成主谜题 | 此后入口一定没问题 |
| 远桥或周衡发错入口 | 单看 P3/P4，完全可能 | 指出具体页面用途，保留原客户要求；旧链接撤掉后再看新外发，不用重复次数当罪证 | 第一次误发必然出于恶意 |
| 继续参与是退出的必要步骤 | 玩家可能不了解产品流程 | 询问是否延长参与及对应依据；没有依据就保持未核实，不要求客户按一下试错 | 作者凭空宣布所有现实产品都不可能如此 |
| 只是公开挽留，客户可以自己决定 | 退出时作产品推荐不罕见 | 对照客户“只答退出，不发下一期”、主管已读及其新摘要“愿意了解下一期”；后者并非如实转交后公开征求兴趣 | 一切挽留都违法；此处已经查明完整诈骗 |
| 是远桥自行推介，澄川只是无能中间人 | 若只见续期说明，仍合理 | 从本案回复的关联来源查看公司实际发出的请求；作者、收件人、时间和正文共同限定责任 | 项目接待席也看过被省掉的原话 |
| 公司把退出诉求主动改写成产品兴趣 | 已知限制、新摘要和按其执行的回复相互支持 | 先阻止未发项，或在已发后把原话送到实际收件方并观察停止；不需要继续伤害客户来“取证” | 境外地点、真实资金控制及法律定性 |

本幕是调查行为与目的的悬疑，不伪装成“多个凶手中猜一个”的本格案件。玩家可以早猜公司有问题；真正需要验证的是具体安排，不能以猜到坏人就判失败。

## 表六：专项反证与仍然存在的风险

| 维度 | 审查结论 / 证据强度 | 修订与边界 |
|---|---|---|
| 推理 | 旧稿 `explicit` 主管撤链接并公开改谈下一期；`missing` 为何这不是普通挽留 | 删除以该句为揭示的写法；改为收到限定原话后的新转述与实际执行 |
| 事实 | `explicit` 已发摘要与原话冲突；`strong inference` 公司主动改变处理方向 | 不能倒推第一次链接一定故意错发，更不能跳到钱去了境外 |
| 认知 | 只传页面时，主管未必读到“别发下一期”；项目席位也看不到课程原会话 | 部分转发只得部分结论；须实际送达限制后才成立“明知仍改述” |
| 动机 | 主管想重新推介，但为何不直接说服客户？ | 客户已拒绝下一期，直接推介容易失去回复机会；假借退出回应争取阅读。留痕来自正常交接及他的轻视，不来自自白 |
| 交互 | 若要求抄原话、填会谈议题、等三张回执，仍是办公 | 引用、查看来源、停止/更正足够；两端消息在已有会话中，不增加提交清单 |
| 心理 | 小雨、罗青若读到页面还继续背书，会显得刻意迟钝 | 小雨查后停止推荐，罗青可以直接拒绝；主管收到明确全面拒绝则不继续发，允许证据停在较弱层 |
| 公平性 | `explicit` 来源与状态可查；`missing` 新玩家是否愿意去查 | 相同内容不会随怀疑变化；不拿副本权限、精确问法或强制联系制造锁；仍待陌生玩家体验 |

**本幕最多支持的推断链：**原介绍与页面不符 → 发错尚可解释 → 原客户限制实际送达 → 公司之后主动转出相反诉求 → 对方依此发来续期内容。最后两步使“只是第一次发错链接”无法解释全部行为，但仍可存在强行挽留、夸大客户意愿等解释；没有查明完整犯罪网络。

玩家下一步值得问的是“我们交给项目的究竟是不是客户真正提出的事”“退出请求有没有被送到能处理的人那里”。这些是作者预期，不显示为任务或 NPC 总结。若玩家仍仅感到在纠正客服工单，不能靠更多文件或境外威胁补救。后续资金调查与终局不扩写。
