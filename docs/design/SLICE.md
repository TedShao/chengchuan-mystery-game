# 《回来以后再联系》｜网页场景与纸面验证

与 [STORY](STORY.md) 共用同一事实；界面和状态规则见 [INTERACTION](INTERACTION.md)。以下均为待实现设计。开场目标时长约 10–15 分钟，完整故事不以读完多少页计进度；未测量实际用时。

## 1. 无指引时，玩家最先看见什么

屏幕是林见已登录的工作电脑，右下角 09:08。桌面没有“发现公司秘密”的任务栏，也不弹公司介绍课件。工作通讯软件里只有小雨一条未读：

> 十点那个售后岗改到明天了，我已经跟人说过。你别再催一遍。对了，前台刚接了个电话，找上周接待陈平的人。我看记录是你，要现在转过来吗？

可选“接过来”“先看是哪位”“让他留个回拨方式”。这三个选择决定通话时间和是否需要回拨，不判正确答案。旁边可展开当天日历：国内客服面试、午休、次日海外项目初面。候选人自己取消后日历真实更新，只有日历不授予玩家暂停全部项目的权力。

点“先看是哪位”，打开自己发出的面试通知，不跳到全公司档案。页眉显示“林见 · 招聘助理”；通知签名是澄川人力资源服务；正文只有面试地点、日期、接待人、改约线程。左栏可看正常国内面试，知道自己的日常工作。无需先做一件无聊的工作证明会用电脑。

第一次进入通讯软件时可有一次**操作**演示：点开线程后动效停止，明确已打开哪个对话；不自动发消息。用户关闭帮助后，标签、未读和回拨按钮仍然可见。此处不出现红框“线索在这里”。

## 2. 可见材料，不是给玩家看的答案表

正文不展示下面的材料编号；编号只用于创作与验收。

| 对象 | 屏幕中的具体内容 | 为什么存在 / 访问限制 |
|---|---|---|
| M1 我发出的面试通知 | “陈平：周三 14:30；前台报姓名即可。录用结果由项目主管联系。”下方改约：“能改到三点吗？我这边交接晚一点。”林见：“可以，我跟孟宁说一声。” | 助理自己发出的正常通知；不包含出发安排或父亲隐私 |
| M2 父亲来电 / 留言 | “孟经理说他嫌工作累。我想问问，他来面试的时候，有没有说不想去？”若问联系：“前晚还跟我说想回来。昨天打过去，说不方便，晚点再说。今天没回。” | 父亲解释找人原因，不一上来讲园区或绑架；家属身份未核对前不向他透露档案 |
| M3 当批岗位介绍 | 中文电商客服；面试中实际承诺的工作与泰国地点；“有在岗人员可介绍情况”，可打开陈平当时收到的赵启明介绍 | 林见接待时可见的同一版本；待遇、工作范围不用法律长文压过生活问题 |
| M4 孟宁对本次询问的回复 | 问安危：“我今天跟那边约一次，让他爸也在。”问工作：“当时谈的是客服。他想回来这件事，我再问具体卡在哪。” | 这是她实际承诺的行动，不足以洗清或定罪；只转交问题就只收到问题 |
| M5 家属自愿发来的最近消息 | 陈平：“我想回去了。”父亲：“那你把什么时候到跟我说。”陈平：“还没定，等我能自己打电话再说。” | 在玩家询问最后联系、或父亲解释为何仍需回拨时出现；不要求特定问法。没有完整求救说明，也不要求玩家破解暗语 |
| M6 约定通话与之后的联系 | 会话列明实际参加者；陈平能说“想回来”，对单独回拨没有可兑现时间。父亲随后仍无独立联系 | 让玩家区分见到人和确认自由；通话完成不自动标安全，漏接可向参加者问经历 |
| M7 赵启明的在岗介绍 | 正常的个人经验：“刚来要倒班，住的地方有人管。先把这边工作学会。”不是“我完全自由、安全有保障” | 陈平曾用它降低顾虑；单凭介绍不能证明胁迫。只有赵后来确认时意义才改变 |
| M8 赵的自愿陈述与往来 | 看似报平安时已在争取离开；回国后向孟宁说明“实际不是电商客服”、自己为何无法直接走。另有他向郑立提出问题及得到回应的往来 | 本人的资料；部分分享、遮去私人内容、拒绝转发分别成立。原接待同事只转达邀请，不交出全套通讯录 |
| M9 次日预约与邀请的实际版本 | 陈平之后安排的同一岗位初面，发送者、对象、已发/未发明确；主角的境外岗位意向在本人旧聊天中可见 | 早就存在的经营与选择，不是调查后凭空新增的受害事故；草稿不是已经招募 |

M5 只支持追问本人能否自主联系；一句等待不能证明控制。角色不要求玩家汇钱、套话或冒险做试验。

## 3. 第一段：电话之后做什么

### 场 A｜父亲到底在问什么

玩家接电话时可选问面试、最后联系、负责的人，或承认自己只接待过。若选“他面试时挺想去的”，父亲回应：

> 那他现在想回来，总该是后来出了什么事吧。你能不能帮我问一句，他能不能自己给我打电话？

这只是家属合理愿望，不能被系统记为“陈平一定出事”。若玩家说“不归我管”，父亲要孟宁的工作联系入口；可以由前台转接，林见不必透露私人号码。父亲继续找公司与外部帮助，主角不会突然收到感谢和全部证据。

身份未核对前，林见只收听对方陈述并提供公司公开入口，不向来电人泄露简历、行程或私人号码。父亲可先自愿提供他持有的通知；它只能支持联系来源，不能单独证明亲属身份。涉及陈平的具体资料披露，须通过本人原有联系渠道或既有授权确认；如无法确认，保留转交求助、向本人发起联系的路径，不让身份审核成为营救前置谜题。

如果玩家不开电话，留言保留可回拨；不自动扣信任、不偷偷发生事故。主动选择结束这一天可以离场，但不是完成调查。

### 场 B｜直接问主管也成立

玩家不看文件就问孟宁“陈平怎么了”，她能解释自己已听到的家属担忧，并提议安排联系。不能要求先找到三条线索才准问常识问题。

玩家说“你把人骗过去了”，她不会马上承认：

> 你听到了什么？我能先把联系约上。其他的，拿到具体情况再说。

若玩家没附家属消息，孟宁不会引用“等我能自己打电话再说”。若只概述“想回来”，她按概述答；要验证具体差异，可以将一段消息经同意转交。转交不是必须做的工作单，问题也可由父亲本人提出。

若玩家问“那他随时能走吗”，孟宁不能替境外保证。她可说需要确认；如果先前保证过，后续必须承认自己没确认，不能改写已发记录。公司主动联系的部分可能是真的，这使她不像一道只会否认的门锁。

### 场 C｜用联系检验解释

玩家可以请求一起通话、只让父亲参加、先尝试本人已有联系渠道，或不参与。提议共同通话时，屏幕清楚列出谁会参加，确认后才发邀请。

通话不是审讯小游戏。普通问题得到普通回答；问工作时，陈平只能谈自己被允许说的部分。玩家可以提出“结束这通后，你方便时单独给你爸回拨”，由陈平本人回应。不能用这一请求当即时测谎：一次没有回拨容纳多种解释。之后仍无法自主联系、明确想离开却没有本人能够落实的安排，与此前招聘承诺一起构成持续担忧。

若玩家相信“见到人就没事”，可给父亲发“刚才接上了”，但不能在保存通话笔记时自动发送“安全”。如果明确发送安全保证，父亲会暂时减少向林见追问；其本人已在做的求助不会被系统取消。后来改口可以重新提供具体理由，原保证仍留在历史。

这一段理想的下一问是“能不能自己离开”，不是“下张表在哪”。没有形成这个问题的人可从父亲的实际后续联系得知安排没有解决需求，不用额外丢一封神秘邮件。

### 场 D｜回去问一个回来的人

若玩家问“以前去的人呢”，孟宁可提到有人已经回来；小雨也知道赵的国内接待，M3 有在岗介绍来源。三个入口指向同一人，不能要求先听某句标准台词。

点赵的介绍后可选择“请原接待同事转达联系请求”，而非直接获得陌生人的手机。小雨：

> 我可以替你问一声。先别直接把他的联系方式发出去。

她只知道赵曾回来，不提前暗示他被强迫推荐，也不替他决定配合。

收到请求后，赵可答：“你是问陈平，还是又要让我给人介绍那边？”这暴露他的具体顾虑，不讲全案。玩家可诚实解释目的、仅问一般经历或撤回请求。撤回后不强行接通；只问一般经历不赠送私人求助记录。

第一段在玩家决定怎样问赵，或决定停止调查时结束。不是以“所有任务完成”结束；是否真的愿意问，要在盲测里观察。

## 4. 后半场：每次推进必须改变理解或关系

### 场 E｜不是假的介绍，是不自由的介绍

赵同意联系的条件是知道对方为何来问，不是累计好感。问“是不是公司教你这么说”，他可以否认自己与公司合谋，只承认说过那些话。

> 那几句是我发的。不是别人盗我的号。你别拿这个跟我说，我在那边过得挺好。

后续可以问发出时的处境、回国后找过谁、是否愿意让陈平家人知道。赵不一次回答全部；玩家选一个话题，回答后其余合理话题仍在。追问不需要猜关键词。

实际可变行动是**停止使用这段介绍，并让赵决定其纠正发给谁**。林见能撤掉自己尚未发出的引用，不能保证公司全部渠道都撤掉。赵允许只发给陈平父亲时，孟宁不会知道全文；公开扩大范围会使赵收回之后的合作，不抹除已发内容，也不凭空取消陈平的求助路线。

这一步把“前辈是否可靠”变为“可靠经历如何被拿来替不可靠承诺背书”。若玩家只愿停止引用，也成立有限结论，不逼其继续审问。

### 场 F｜公司什么时候知道

玩家可将赵的求助日期与自己的面试通知并排，也可以直接询问孟宁什么时候第一次收到反映。前者是为了检验一个具体解释——公司会不会在陈平出发后才知道，而不是为了完成“证据拼图”。

孟宁若收到原往来，不能继续说从未收到；她可承认接过投诉，却坚持当时信了境外的解释。玩家仍须区分收到警讯与已掌握全部真相。赵亲自对郑立的陈述及郑立回应单独确认，不能靠抄送列表或孟宁的职位自动认定老板知道。

少给一方材料会有实际差异：只问小雨，她能暂停自己发的介绍、协助当事人联系，不能回答老板收到什么；只向孟宁表达“我不参与”，她只撤林见经办；明确将具体警讯送到负责人并要求暂停当批安排，才形成负责人需要作决定的场面。没有任何按钮叫“证明公司诈骗”。

### 场 G｜你想让他回来，我也想

郑立在被正式告知具体情况后提出处理范围：协调陈平的联系与回家安排，停用相关介绍，暂缓本批面试。玩家可接受其中任何帮助，同时保留独立求助，不设“接受善后等于签保密放弃调查”的隐形陷阱。

> 先让他跟家里能说上话。明天那批可以往后挪。你手上发出去的通知给我看，我让孟宁处理。

这句话不是洗白；以其实际行动判断。若真暂停，日历显示暂停，候选人收到准确通知；如果只是撤林见，则他已发出的面试仍在，责任人改为孟宁，不能把“我不接手”误记成全局暂停。若只停未发通知，已经发出的部分要另有实际告知结果。

玩家也可直接通知自己联系的候选人：“这份岗位的实际工作和离开安排目前有具体争议，我不能继续作保证。”不用附上不获许可的私人聊天。候选人可撤回报名、询问、或仍决定了解；不是 NPC 必然服从。公司会失去部分招募，不是只给玩家扣分。

公司一旦知晓已被具体指认，允许真的停止项目和减少沟通。之后查的是既往事实和当事人去向；不新增一次作恶来保证玩家拿到高潮。

### 场 H｜把决定落实到收件人

玩家可以继续提供给家属 / 外部求助渠道、停止替项目回复、或结束工作并离职。外部渠道在游戏内模拟：可提交已知事实并区分亲历、转述、未知；不要求正确罪名，不弹“证据不足，不予报警”。初次反馈是已收到及可能需要补充的事实，不承诺解救时间。

结局前让玩家看到选择的实质：谁收到纠正、哪些面试真取消、谁愿意配合、哪段联系仍无法独立进行。未知人员状态不被“已完成”勾掉。之后用明确的时间跳转进入 STORY 的结局，区分确认、未确认及因行动失去的信息。

坏结局支线在场 A 之前的本人聊天已有岗位意向。仅在合作仍存、主角未明确退出且仍相信相关保证时可以继续。不同意这份岗位与拒绝查案都不会通向被卖结局。

## 5. 关闭指引的作者纸面排演

方法：只使用当步已展示的内容，模拟不按顺序的选择；作者已知真相，以下是因果检查，不是真人行为记录、实测时长或吸引力证明。

| 路线与当步假设 | 实际操作顺序 | 应发生的变化 / 可形成的结论 | 本次删改 |
|---|---|---|---|
| 先相信主管：只是家属担心 | 不开通知 → 问孟宁 → 同意联系 → 只说已接通 | 联系是真的；父亲仍不能自主联系；可再问本人自由，不把接通当安危认证 | 删除“通话完成 = 问题解决” |
| 直接指控：这就是诈骗 | 接电话 → 质问孟宁 → 拒绝面试 | 孟宁收回经办，可能停当前项目；手上仍只有有限信息，可独立求助 | 删除强行说漏嘴和激怒惩罚 |
| 先拒绝：不是我职责 | 拒接转给孟宁 → 自己退出 | 来电实际转走；不发全套证据；回头可从原通知问具体处境，或有限离场 | 不用新事故强行拉回 |
| 漏看家属消息 | 只读通知 → 参加联系 → 问以前的人 | 不能引用没读过的私人消息，仍可从职位与赵的介绍进入后半 | 去掉必须阅读标记 |
| 不参加通话 | 父亲自行参加 → 玩家之后问经历 | 得到转述而非亲历记录，陈述时标明来源 | 不能给没参加的人完整观察权限 |
| 先找赵 | 从岗位介绍转达请求 → 赵问目的 | 有真实联系入口；初次只谈其本人，拿不到陈平当前位置 | 删全知证人、自动交底 |
| 赵拒绝继续谈 | 请求经历 → 赵拒绝 → 不再追问 | 可继续确认陈平处境、停止担保和求助；缺赵材料时不能获得事前明知的完整结论 | 不让小雨突然代替赵爆料，不逼刷好感 |
| 错怪赵后改口 | 指控其合谋 → 承认不知道压力 → 请求有限说明 | 赵可只谈自己，不立即恢复全部信任；许可按新范围生效 | 不用一句道歉重置历史 |
| 只撤本人 | 明确“不做经办” → 看日历 | 自己不再发送；已发安排仍有效，可进一步通知或要求全批暂停 | 区分退出与业务停止 |
| 提前停整批 | 向有权限者说明具体风险 → 对方确认暂停 | 暂停真实生效；旧通知得到更新；仍可查已出发者 | 不让另一账号偷偷恢复来救剧情 |
| 只发部分材料 | 经赵许可给父亲发摘要 → 问小雨 | 父亲知道摘要，小雨不知道内容；她可转达，不回答未收材料 | 修正同事共享脑袋 |
| 事后撤回保证 | 先发“应该没事” → 再发“无法确认自由联系” | 父亲看到改口及理由；之前等待已发生，后续可重新求助 | 不回写旧消息，也不永久封路 |
| 重复、打断、否定 | 重问同问题 → 取消发送 → 改问“我不是说他不想去” | 重问回到先前回答；取消无收件；否定调整问题对象 | 不重复生成来信或误触任务 |
| 先向外求助 | 父亲来电后即提交有限信息 → 继续问具体岗位 | 求助真实记录，调查与后续核实并行 | 删除“必须查完全案才准求助” |
| 只想下班 | 关应用 / 保存退出 | 保存进度，不因现实等待出事故；主动结束调查才进入有限结局 | 无暗中时钟逼人继续 |

反向审稿：

- **主要弱点（弱推断）**：赵愿意有限说明并不保证玩家愿意追问；拒绝分支只能支持较窄结论，不能暗中发他的一整套资料。
- **主要弱点（待证据）**：坏结局的岗位吸引力尚未实测；若玩家已明确识破而仍能被诱骗，就是状态错误，必须撤销邀请，不能靠强制出差完成结局。
- **已修正的知情问题（明确）**：小雨不预先说赵不愿当例子；父亲消息不凭空加入汇款危机；未核身份时只收听，不泄露简历。
- 六层回查：事实时序、角色认知、线索出处、动机/机会/手段和场景关系均在 STORY 明写；真实权限可信度与陌生玩家兴趣属于验证缺口，不是已证事实。

审稿结论：联系人来源、权限、先后及停止效果已在文本中明确；“赵是否愿意继续谈”“玩家是否把有限联系理解成足够安全”仍不能由纸面证明。当前主要是调查型悬疑，尚不能宣称是成熟的公平推理成品。

## 6. 下一次陌生玩家纸面试玩怎么做

只给第 1 节的实际开场，不给材料表、故事梗概或路径目标。主持人按实际选择提供对应页面，可扮演角色，但不得用即兴新事实帮助通关。无素材支持的追问记录为内容缺口，不说“以后再问”。

记录：打开了什么、提了什么问题、认为谁知道什么、做了什么操作、期待什么后果、为什么继续或停止。结束后再问：你以为自己做什么工作？为什么父亲来找你？你现在能肯定什么？还想确认哪件事？不先解释正确结论。

反证标准：若玩家需要主持人说“再去找赵”才继续，先修联系入口或人物动机；若核实后仍只想处理一次投诉，不能以新增受害、倒计时或犯罪文件补强；若认为暂停无效，先修后果；若剧情成立但操作找不到，改界面，不加谜底高亮。

本轮仅完成上表的作者逻辑排演。真人观察、对白口语度、实际阅读负担与十分钟吸引力均待证；不要填虚假通过率。
