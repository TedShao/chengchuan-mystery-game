# 网页片段：替你说的话

状态：2026-10-21，替换退款结构。事实、知识与竞争解释见 [STORY](STORY.md)；本文件记录先行纸面排演发现的问题及修订后的玩家材料。仅作者限制信息的纸面验证，没有真人盲测、网页运行或代码修改。旧稿固定于 [b48188c](https://github.com/TedShao/chengchuan-mystery-game/tree/b48188cb2fa2a45d881cc62f102ca767a6acea1f)。

## 纸面验证先排掉的三个伪谜题

| 草案走法 | 为什么不成立 | 写入本稿的修正 |
|---|---|---|
| 原接待转回我的席位 → 公司骗人 | 正常代班、品牌昵称都可解释 | 代班从背景直接承认；只有真实问答中的明确雇佣关系否认，结合实际操作者才区分欺骗 |
| 改成员工名片 → 沈航马上骂公司 | 他可能以为只是换了接待；内改名片也未必对客送达 | 身份以明确的本会话事件发出；他先问是不是换人，实际告知昨夜操作者后才改变判断 |
| 暂停后让顾成继续假冒，以证明恶意 | 强迫玩家放行新误导，而且违背暂停有效 | 停止阻断本席新发送；昨夜已发生的针对性答复足够查，不制造新受害事件 |

另否决“再让学员转一笔来验证”和“让主管自己说我们是托”。本案调查公司怎样制造第三方推荐，不再判定旧代付案。

## 第一眼：有人要找你没做过的那份工作

只给生活与岗位背景，不先介绍骗局：

> 待业三个月后，你在澄川做了课程服务。今天是第 47 天。昨天按时下班，夜间由组内代班。你没投过远汀，也不替学员操作钱。

眼前是值班收件箱。沈航的消息：

> “昨晚跟我聊的那个人今天在吗？我还有一句想问他。”

普通操作是打开原会话或找原接待，不要求先选工作内容、不出现“检查是否诈骗”。“原接待”显示 **小林 · 同学交流**；打开席位详情会见到 **本席负责人：林见；上次接待：顾成**。对外头像仍是你认得的那张入职照。玩家知道自己负责课程服务，却不知为何在当“同学”；不能仅据头像就断言诈骗。这时仍只是一处角色疑问。

所有前文、操作者信息、暂停与接回入口从开始可用。沈航没有在第一条就说“你们冒充了别人”。自由办公仍可打开；没有十分钟倒计时或强制教学任务。

## 原对话：需要验证的是这句否认

这些是沈航真实会话中昨晚已发送的消息，不是新增证明文件或系统给出的犯罪摘要。人物用词可调整，事实含义须稳定。

> 沈航：我想问个真做过的，介绍项目的就别转了。
>
> 小林：你想问哪一块？
>
> 沈航：你是在澄川上班的吗？
>
> 小林：不是。我也是从课上听到这个项目的。
>
> 沈航：所以问你不算再问一遍销售？
>
> 小林：你就当问个同学。我前面取过一次，才又放进去的。

服务台的普通消息详情显示该组回复由 **顾成** 操作发送；外部昵称仍为小林。原对话保留消息时间和所属会话，不能被切换名片重写。它不是秘密黑账，代班出处是服务系统正常交接所需。

不要求读齐：只读到角色名不够；只读到获利经历也不足以证明是林见本人说的。明确的雇佣关系问答和实际操作者相合时，才支持局部欺骗。不要设置找齐几条后弹“真相已解锁”。

## 行动：我接回去时，对方究竟把我当谁

玩家不是被要求复述材料。他要决定是否承接这段关系。普通席位面板显示三个独立状态：当前操作者、对外身份、是否允许组内代发。

| 动作 | 当场反馈 | 不会顺带发生 |
|---|---|---|
| 暂停本席代发 | 本席新发送停止；现有会话保持可读 | 不取消所有人的预约、不删历史、不偷偷改由另席续发 |
| 仅内部接回 | 当前操作者变为林见，组内不再代回这一会话 | 对外身份尚未改变，沈航不知道换了谁 |
| 以真实员工身份接回并告知 | 确认后在同一会话送出“林见 · 澄川课程服务已接入”，沈航可见；这一步不带投资保证 | 不自动发送解释、不自动取消咨询；送出前可退回 |
| 只在自己的设置改身份 | 设置改变，对话未送达身份事件 | 不得算沈航已获知，也不能触发他的质问 |
| 结束自己的项目接待 | 本席后续项目转交停止；是否保留普通课程服务另选 | 不等于全公司停止业务，不禁止自己查看有权读的既有会话 |

若接回时本席已暂停，可选择只发这次真实身份与更正，发送后仍保持其他代发暂停；**不是恢复整个席位才允许说真话**。普通课程身份不会被隐藏的“同学角色”覆盖。

沈航看到身份卡后先问：

> “换人了？我想找的是昨晚那个。”

这不是认罪证据，而是他仍把“独立同学”和公司分开。玩家可说明昨晚由本组顾成代班，也可先查原文，或保持停止。实际收到身份与操作者说明后，他才问：

> “那我问他是不是你们公司的人，他为什么说不是？”

问题来自已发对话。若玩家不发送说明，他不会自动知道顾成；若沈航已结束联系，身份卡仅标未读，不触发离线即时回话。历史本身也能完成有限核实，不能强迫重新联系。

## 公司为什么值得继续查

旧角色表面是在提供另一位学员的经验，实际接待者仍是卖方的运营公司。玩家亲手切回真实身份，原本的“同学建议”失去其独立性：这不是退款到账与否，也不是财务姓名的笔误，而是针对明确询问给出的关系否认。

接回操作同时产生需要面对的结果：沈航要知道昨晚的保证来自谁，玩家是否继续代表那个人。玩家能明确撤回本席的独立推荐，或仅停止自己的参与。**暂停只阻止下一句话，不会自动纠正沈航已经相信的内容。** 这个差别构成行动动机，不需要另发新待办。

本席既有会话可按当前就已存在的“同学交流”分类查询，用来追查自己的席位曾承担什么接待；归属项目显示远汀。分类和客户归属不自动证明其余会话都骗人，不突然列出更多受害人。本段只证明本席的做法，不证明全公司制度性要求。片段末可以停在“公司卖的是咨询，还是独立推荐的假象？”不由旁白替玩家说出，也不以查询数量决定过关。

## 直接问、拒绝、只读一部分与改口

| 玩家行为 / 已知范围 | 回应或事件 | 对推理的影响 |
|---|---|---|
| 一开场问顾成谁代班 | “昨晚是我。你先接回来。” | 合理代班直接说清，不装神秘；不能凭这句得出欺骗 |
| 问为何叫同学交流 | 他可以说是项目接待分类，允许换回员工身份 | 分类解释仍正常；不是逼他讲诈骗动机 |
| 引用雇佣关系问答质问 | 顾成可以不回答、同意更正或停止本席。若交由他更正，只有实际发出才改变沈航认知 | 他今天如何解释都不改变昨天由谁作了那句明确否认；无需坦白 |
| 提前暂停、取消自己的后续接待 | 新发送停止，旧会话可查；若沈航主动取消其预约，按对象取消 | 不要求放行谎言或新付款取证，也不暗中恢复 |
| 只看身份卡 | 可怀疑角色不对，但仍可能普通代班或代运营 | 系统不标欺骗，不用同事补齐未读前文 |
| 只读获利话、不看关系问答 | 可能是顾成讲自己经历 | 不以林见没投资就认定全部虚构；可继续问具体所指，也可停止 |
| 只看历史、拒绝再对外联系 | 查到实际发送的关系否认与操作者，可得局部结论；沈航仍不知 | 不需新受害事故、不强制做社交实验 |
| 已如实表明身份，随后改称“只是代班，没问题” | 沈航会追问那句“不在公司上班”如何解释，已获身份不会被新称呼抹去 | 改口可发送，但不能重置他已经知道的事实 |
| 先顺着独立同学接话，再收回 | 新消息确实发出才建立新的背书；更正实际到达才改变认知。沈航会区分昨夜与今日是谁保证 | 不因为选择错误自动扣钱或产生事故；信任不能一键复原 |
| “我不接了，但先说昨晚谁回的” | 停止接待与回答来源分别执行 | 拒绝不等于关闭全部查询；没有无任务支撑的拒绝资金菜单 |

拒绝独立推荐不等于拒绝正常课程工作。完全退出调查可结束，没有坏结局处罚去逼继续。重复接回或暂停只显示当前状态；身份告知对同一会话同一版本不重复刷消息。顾成只有实际收到说明或在权限内实际查阅，才知道新问题；看不到私人草稿。

## 非预设顺序的纸面走查记录

先按每条所见走到结尾，再检查是否借用了作者真相。以下是假设路径和逻辑结果，不是真人行为统计。

| 路线 | 实际顺序 | 可以得出的结果 / 剩余风险 |
|---|---|---|
| 主管先行 | 先问谁 → 接受代班解释 → 真实身份接回 → 对方问是否换人 → 查既有关系问答 | 不靠主管失言。若不继续查问答，可合理停在换接待，不能强给真相 |
| 立即止损 | 暂停代发、结束本席后续 → 打开已存在的前文与消息详情 → 不再对外发送 | 明确否认与在岗发送人构成局部反证；停止不毁证，不生成新联系 |
| 先聊天不读史 | 真实身份接回 → 沈航要找原同学 → 告知已知代班人 → 他引用自己原来问过的问题 | 来源是同一已存在问答，不是新证词救场；可回原位置核实 |
| 先查史不聊天 | 看获利句 → 暂按顾成亲历解释 → 读到雇佣关系明确问答、查操作者 → 停本席 | 真实经历不能解释虚假独立性；不用查看任何银行材料 |
| 单边误判 | 只看昵称就指控 → 发现正常代班规则 → 收回笼统指控 → 选择是否查具体原话 | 修正的是“代班有罪”，不是洗掉另一条尚未查看的关系否认 |
| 拒绝参与 | 不接回不发送，仅结束自己转交 → 自由办公 / 结束；若愿意可读旧史 | 可以退出；不保证拒绝所有探索仍看全案，不制造惩罚 |
| 顾成配合更正 | 玩家提出具体问答 → 顾成实际发出员工身份与更正 → 沈航不再把本席当独立推荐 | 眼前误导停止，但局部虚假陈述已明；继续查公司来自这项业务，不靠逼主管再次作恶 |
| 改口与重复 | 实际披露后撤回措辞 → 对方保留已知关系 → 再接回/暂停不生成新事件 | 角色有记忆；重复动作不制造证据或额外危害 |

**纸面判定：**“正常代班加称呼错误”能解释席位与昵称，解释不了在岗员工面对真实客户明确询问后的关系否认；可检验的区别由原问答、实际操作者及真实身份接回共同呈现。成立范围仅为这一处有意伪装。若把关系否认改成模糊称谓，或把原文改为未发示例，本案就失去区分力，不能靠配乐或更多台词补救。

仍待真人检验：是否会自然使用“原接待 / 接回”而不觉得是工单；是否关心这句以本席发出的推荐；是否能接受明确局部欺骗但尚未揭开资金真相。新旧内容同时改变，不归因于单个按钮，不标十分钟必然好玩。验证入口见 [PLAN](../PLAN.md) 与 [H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
