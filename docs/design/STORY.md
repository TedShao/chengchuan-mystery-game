# 《回来以后再联系》｜故事总纲

当前唯一故事基线，2026-10-21。完整剧透；作者设计，尚未实现，也未经过陌生玩家验证。用户已确认：招聘公司方向、境外诈骗与人员受控的真相，以及主角也可能被骗出境的坏结局。具体人物、时序和分支是本轮补写，可继续修订。

## 先读这个故事

林见失业三个月后，在澄川找到一份招聘助理的工作。公司替本地电商企业招聘客服：有人因为夜班不愿去，有人问工资是否准时，也有人入职后回来介绍朋友。林见做了七周，接过真实的抱怨，也收到过真实的感谢。他终于不必每天向家里解释为什么还没找到工作。

这天，一通电话转到他的电脑上。陈平的父亲联系不上儿子，已经问过项目主管孟宁。孟宁说，陈平到了国外，觉得工作不合适，正在和当地负责人闹别扭。父亲没有要求林见救人，只问：“他来面试的时候，有没有说过不想去？”

林见记得陈平。他怕面试迟到，特意改过一次时间；离开时还问，什么时候能知道结果。林见只负责接待，此后的录用和出发安排由孟宁接手。他不能仅凭这个印象断定主管撒谎，也没有理由替主管保证陈平没事。

林见可以把电话转回去，问孟宁能否直接联系本人，或先问父亲最后一次正常联系是什么时候。事情起初确实像一场海外用工纠纷。孟宁愿意找人，也能安排一次联系。陈平说自己想回来；对工作本身却含混，无法像面试时那样自在地问问题。通话能证明他还在，不能证明他可以离开。

招聘记录里有一位已经回来的同项目求职者赵启明。林见没有权限翻遍他的私事，只能请原接待同事转达联系请求。赵启明起初不愿谈。他回来的经历似乎支持公司的说法：有人可以回来，也许只是陈平与负责人没谈妥。直到林见问起陈平面试前看过的一段在岗介绍，赵启明承认，那是他本人发的；他说环境还不错时，已经在争取离开。他以为答应帮忙安抚后来的人，自己就能早点脱身。

这不是一位完美证人的自白。赵启明想证明自己也受了害，却不愿面对曾经相信过他的人。玩家可以不信他，可以只问自己的接待有没有被利用，也可以让他决定是否愿意向陈平一家说明。赵启明能提供的是自己的经历和此前向孟宁求助的往来，不能替玩家指出整个犯罪网络。

林见逐渐拼出一条有先后关系的事实：公司收到过工作内容不符、离开受阻的具体反馈；孟宁后来仍用原来的工作介绍招陈平，还把赵启明的报平安当作可信经验。问题不再是某一份广告夸大，而是已经知道风险的人继续利用不知道风险的人。林见那次普通的接待，也成为了“这个招聘有真人负责”的一部分。

负责人郑立可以让步。他愿意撤掉林见的对外联系人身份、暂停本批面试，帮陈平家属联系境外负责人。他甚至愿意支付一部分善后费用，因为这比让长期业务和公司声誉一起崩塌便宜。林见想要陈平回来；郑立想让事情止于陈平回来。两个人可以暂时做同一件事，却不会因此拥有相同的目标。

最后的冲突不要求公司当着玩家的面再骗人。若下一批已经被阻止，调查就转向之前的承诺和已经发生的去向。若玩家仍相信公司会自行解决，新一批面试可能按时开始；若玩家选择把已经确认的事实告诉相关求职者和外部调查者，接收人会作出自己的决定。家属可以先求助，赵启明可以拒绝公开，国内同事也可能在看见具体事实后停止协作。林见无法指挥所有人，却能决定是否继续替自己无法保证的事情作保证。

最好的一条路不是在电脑前攻破园区，而是让国内招募停止、已有线索进入调查，并在一段时间后等到陈平能够自由联系家人的消息。也有不圆满的结束：林见离职，证据有限；陈平的处境仍未确定。最坏的一条路上，林见把每一次解释都当作安全保证，接受早先谈过的境外岗位，最终发现自己也被送进同一套控制关系。那时，国内系统里他的记录仍可能只是“已到岗”。

## 一、公司究竟做什么

澄川人力资源服务有限公司是虚构的十余人小公司。主要收入来自本地电商企业支付的招聘服务费；成功招到并实际入职后，按双方约定结算。它不是这些客服的用人单位，不发他们的岗位工资，也不是劳务派遣公司。真实业务支付办公室和普通员工成本，提供信誉，解释林见为什么相信自己的工作有用。

| 部门 / 负责人 | 日常产出 | 海外项目中的位置与知情边界 |
|---|---|---|
| 负责人郑立 | 维护企业客户、决定合作、处理重大投诉 | 收到过具体求助，知道不能再作原有安全保证；仍保留合作，掌握项目收益与联系人。不是园区管理者 |
| 国内招聘组，何小雨等 | 核对需求、筛简历、安排面试、回访入职 | 多数只做国内业务；小雨知道有人回来、有人投诉，不知道诈骗场所内部情况 |
| 项目主管孟宁 | 客户沟通、职位说明、面试与录用衔接 | 独立负责海外项目；已知道有人被安排做诈骗相关工作、离开受限制，仍把这些说成个别纠纷 |
| 招聘助理林见 | 回复基础咨询、预约、接待、转交复杂问题 | 七周主要做国内项目；最近替请假同事接待海外初面。看得到自己经手材料，不能看全公司机密 |
| 行政、财务 | 考勤、工资、报销、按批准资料结算 | 知道有海外招聘收入不等于知道人员受控；不承担替玩家吐露真相的职能 |

海外项目对外宣称为东南亚中文电商客服岗位；候选人收到的现行说明列的是泰国工作地点。孟宁称境外合作方负责后续雇佣及手续，澄川只协助前期招聘。**这是人物说法，不是作者认定合法的外派模式。** 国内招聘资质、真实办公室或所谓合作关系，都不能自动证明有权组织境外用工。资质、真实雇主、工作地点需要分别核实，资格问题也不等于已经证明诈骗。

作者真相：该合作联络渠道为缅甸境内某诈骗经营团队招人。候选人相信客服职位，后续被以培训或工作调整等借口转移、控制，被迫参与诈骗；本作不提供转移路线或控制方法。澄川收取招募协作报酬，负责提供愿意相信招聘承诺的人。它不经营整个园区，不控制出境机关，不保证每个人都被送到同一地点。

孟宁最初把项目当成利润较高的招聘合作；收到返国者的具体求助以后，已不能以“不知道”解释继续招募。郑立在同一阶段听取过当事人投诉，却选择保留项目。这一转变发生在开场之前，不能在末尾把他们改回无辜中介。普通员工的正常工作和受骗状态也不能被一笔抹掉。

## 二、人物要什么，为什么不一次说完

| 人物 | 当下需求与关系 | 已知、隐瞒、误解 | 会主动做什么 / 不会做什么 |
|---|---|---|---|
| 林见 | 保住工作；对亲手接待过的人有责任感 | 知自己承诺过什么，不知境外实际工作；易把国内项目的信用套过去 | 可核对、拒绝背书、离职、求助；不自动成为卧底、律师或黑客 |
| 陈平 | 自由离开并联系家人；不想给家人增加危险 | 知道实际被要求做什么，不知国内谁明知 | 能表达想回来；受控联系不能畅所欲言，不靠暗号讲完全案 |
| 陈志远，父亲 | 确认安危，得到可兑现的回家安排 | 有本人消息；不懂分工，起初信孟宁能协调 | 按面试通知打公司电话，先找过主管；可以先求助，不等主角凑证据 |
| 赵启明，返国求职者 | 不再被卷入，害怕被后来的人追责 | 经历过受控；曾发报平安材料，后来向孟宁求助 | 可允许转交、拒绝公开；不在首次来电倾倒所有资料，也不要求刷好感 |
| 何小雨，国内招聘同事 | 把国内职位招好，不替不熟悉项目担保 | 知接待安排和赵曾回来，早先只收到笼统离职消息 | 可转达联系、核对自己发过的通知；收到具体事实才改态度，不读私人聊天 |
| 孟宁 | 保住收入、项目和自己的说法 | 已知关键风险；不知园区全部人员与每次联系现场 | 可协调联系、取消面试、收回经办权；不会为玩家取证坚持自证犯罪 |
| 郑立 | 保护国内经营，降低暴露和损失 | 已获具体投诉，选择继续合作 | 可认错、停项目、提供部分帮助；让步不抹掉既往，也不代表能命令境外放人 |

境外联络人仅负责招聘衔接，不拥有所有人的位置和处置权。本轮不扩展其个人传记，避免一个远程反派解释全案。

人物口吻：父亲先问能否联系，不讲司法术语；小雨只谈经手的事；孟宁给具体安排，不反复说“按流程”；郑立谈愿意承担的代价；赵划清愿谈到哪里。沉默、拒绝和改变行动比重复解释更有信息。

## 四、完整发展与转折

| 段落 | 表面事件与可做的事 | 新认识 / 尚不能确定 | 推进的问题 |
|---|---|---|---|
| 1. 接待过的人 | 回拨父亲、看自己改约、向主管或本人核实 | “本人还在”不等于“可以自行回家” | 我曾放心把他交给谁？ |
| 2. 回来的人 | 请小雨转达给赵；比较在岗介绍与他现在愿谈的经历 | 他确实回来，曾替项目报平安；回来不说明此前自由 | 同样受骗的人为何替公司说话？ |
| 3. 早就收到的消息 | 经同意看赵的求助与回复、对照陈平招募日期；请公司解释当时承诺 | 负责人事前已获警讯；每人的知情仍分别核实 | 我是否接续了早就有人投诉的招募？ |
| 4. 肯帮忙的人 | 接受善后同时独立求助、通知自己负责的候选人、拒绝担保 | 认错和停业务可以是真的，也不能消除既往责任 | 是否为眼前的回家承诺，把此前的事都留在公司里？ |
| 5. 回来以后 | 依据发送、候选人决定、调查进展及主角去向收束 | 国内调查与境外救助不是同一进度；未知就保留未知 | 最后一次自由联系，回应标题 |

第三段不要求公司继续作案，第四段不安排新受害事故补动机。下一批候选人从开场日历就存在，是可被保护的人，不是剧情卡住就刷出的事故。

郑立若真停项目，现场冲突可以结束。余下问题是已经出去的人、旧求助为何未改变后续招募、回家承诺是否兑现。玩家若不愿继续，作品承认离场，不宣称所有人必然想查到底。

## 五、线索与推论边界

| 线索 / 正常出处 | 初看解释 | 第二层意义与核实 | 不足以证明 |
|---|---|---|---|
| C1 林见发出的通知与改约 | 普通面试准备，陈平积极 | 父亲联系有来源；林见可核实参与范围 | 陈平之后没改变主意；公司犯罪 |
| C2 家属与本人近期往来 | 忙、不适应、手机不便 | 实际回拨及不同联系条件支持持续想回、缺少自主联系机会 | 失联就等于拘禁，或能确定地点 |
| C3 陈平收到的赵启明介绍 | 真前辈推荐 | 赵承认发出时已想离开，并非无压力经验 | 赵必为同谋；所有推荐都是假 |
| C4 赵自愿提供的求助与实际回复 | 已处理的投诉 | 内容、收件人和日期早于陈平招募；郑立收件单独核实 | 一条已读证明理解、全公司知情 |
| C5 当批岗位说明与陈平经历 | 外派条件变动 | 工作内容和自由退出有实质差别 | 证照问题单独证明诈骗 |
| C6 知情后的公司实际安排 | 协调善后、保护声誉 | 区分暂停、通知、要求隐瞒，不能只听表态 | 停项目等于无罪；继续国内业务等于继续骗人 |

推理链：C1 确定关系 → C2 支持安全担忧，可直接求助 → C3、C5 与亲历交叉，区分职位差异与一般不适应 → C4 支持具体负责人在警讯之后继续承诺 → 相关事实进入调查，逐步确认境外诈骗与人员受控。两位负责人分别举证。终章调查消息可以确认已有方向，不能凭空输入决定性新真相。

这是责任与去向调查，不是“七人中谁是凶手”。竞争解释依次是普通用工纠纷、合作方单独欺骗、主管个人隐瞒、负责人明知继续协作。

| 对象 | 动机、机会、手段 | 可疑表现的其他解释 | 区分办法 |
|---|---|---|---|
| 赵启明 | 想脱身，有经历，发过介绍 | 羞耻、害怕追责；受控参与不等于主动获利 | 自认行为与自愿提供的可核对求助 |
| 何小雨 | 完成招聘，有联系方式 | 只收过笼统离职消息，不知具体危险 | 对实际收件分别查验，不凭职位推断 |
| 孟宁 | 保收入，掌握岗位与联系渠道 | 也可能误信境外解释 | 具体警讯的时间和之后实际承诺 |
| 郑立 | 保护经营，能决定合作 | 善后本身也可能是负责 | 他自己收到过什么、之后决定什么 |
| 境外联络方 | 招募被控制人员，掌握后续安排 | 正常合作关系不等于犯罪 | 本人、返国者与调查交叉；不用口音、域名定位 |

## 六、结局与不可逆选择

结局依据实际事件，不用隐藏好感分、错误点击次数或“搜齐全部文件”。

| 方向 | 成立条件 | 收束与代价 |
|---|---|---|
| 回来以后再联系 | 具体风险送达能行动的人；林见停止无依据保证；经当事人许可提供线索 | 招募被阻止或查处；时间跳转后陈平自主联系家人。未承诺所有人同时获救、立刻判决；主角可能失去工作 |
| 我不做了 | 拒绝或退出，仅有有限材料，没选择赴境外 | 离职与有限线索真实保留；不明的人物结局明确未知。这不是系统惩罚，抽身与查清全案是两件事 |
| 到岗通知 | 未识破或接受“只是个案”的解释，主动接下此前提过的境外岗位，出发前仍继续 | 时间跳转后主角也被转移至诈骗场所、受控。熟悉网页上出现被要求发送的报平安草稿。责任在犯罪者，不责备受害者、不用猎奇镜头 |

坏结局有三个独立节点：接下岗位意向、确认进一步安排、出发前最后选择。说明角色相信的工作和仍未核实的内容；任一节点拒绝即取消。公开揭露、公司已经停止合作或主角明确拒绝后，邀请撤销，不换皮重发。出发前改口能阻止；已发生事件不能回滚。完整信息下主动冒险不描述为“毫不知情”。

不沿用“激怒同事就被卖走”或“同归于尽”的旧结局。普通同事不掌握跨境暴力，也不因重复提问突然成为凶手。
