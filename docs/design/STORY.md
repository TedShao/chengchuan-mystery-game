# 故事规范：这单是我下的

状态：2026-10-21。基于 [f882ebf](https://github.com/TedShao/chengchuan-mystery-game/tree/f882ebf39015953e5ebf991abd86bcc7a77e5080) 重构撤回后的调查。采用“撤掉旧单，试图把明示未付款的演示交付成真实首单”。旧关店锁、收费复核、补凭证均不恢复。已作作者纸面反路线验证；未做真人盲测、未改代码。屏幕与操作见 [SLICE](SLICE.md)。

## 一句话事件

**公司同意撤掉我误以为串错的样单，却在补首单时，主动把我写明“演示、未付款”的内容改成“买家已付款”，准备发进同一个学员的正式店铺。** 我可以停掉交付，也可以让学员直接看见它原本是什么；不需要先让他付钱来证明问题。

这一段区分的是：同一交付中，谁已经知道交易未发生，却仍选择对真实商户声称发生。不是从一张错误页面推导全平台诈骗，也不是宣判现实法律责任。

## 先固定公司在卖什么

| 对象 | 对外说法 / 收入 | 作者事实与知情边界 |
|---|---|---|
| 知禾 | 网店入门课程 | 提供学员入口；不据此推定所有讲师知情 |
| 澄川 | 课程运营、样店演示和新商户开店支持；向远汀收项目服务费 | 日常做商品页、演示订单、客服练习。核心项目人员将这些产出交给远汀用于包装真实商户的首单；普通课程员工通常只见教学端 |
| 远汀 | 跨境托管店：开店服务费、逐单采购款；声称海外买家货款已托管，商户采购后由平台供货发货 | 经营者用人工生成的买家订单诱导商户采购投入；本段揭示其中一次明确知情的交付行为，不直接揭露完整资金网络 |
| 林见 | 入职第 47 天的课程运营 | 知道自己没有买过那盏灯；过去交付的是课堂练习，不见真实商户收件端。本次异常使他被临时拉入自己这份内容的共同交付页 |
| 沈航 | 刚开店的学员、现在是商户 | 想接好第一单，但不想垫钱买一笔没有买家的货；本段采购款始终不必支付 |

孟宁负责本项目的课程与商户交接；远汀项目席负责把交付内容投放到本单商户端。两人的行为必须分别可见，不能用一个接线员代表全公司。项目席沿用既有远汀对接渠道，不另增神秘主管。读者先看到它的机构、权限和实际操作，不靠外地口音或 IP 判断。

## 本轮比较后选了什么

| 后半设计 | 检验与去留 |
|---|---|
| 停单后又自动冒出已付款订单 | 可解释为缓存、队列、复制错误；需要放行才能观察，容易补新事故。放弃 |
| 旧单真实撤销；在同一补发交付里，操作者知道来源未付款，仍主动选正式商户和已付款说法 | 有具体人的新选择，且可在送出前制止；能区分收费争议与制造交易表述。采用，但必须满足下面的知情与用途条件 |

不用随机改金额、埋暗号或创建假客户测接口。玩家的动作是在决定**自己的演示交给谁、以什么身份交出去**。

## 完整局部梗概

周二上午，沈航问首单能否周五送到。林见建议他问买家，来信却进入自己的课堂样单账户；也可从林见一端先留言。双方确认会话关联后，林见可以撤回。远汀撤掉该笔采购项，沈航不再受这笔要求约束。旧单不复活，善后确实成功。

孟宁认为问题是暴露了演示席与正式商户的关系。她宁可放弃这一笔，也不想放弃已开店的商户和首单转化。她让远汀“旧的别动，补发那份先让林见看收件端”，把林见拉入本次交付。对林见，她把这说成防止再次串错；对远汀，她照常协调项目交付。她相信课程员工会把商户展示当作包装工作，并不知道玩家已经向沈航说了哪些话。**公开指控或把沈航加入交付讨论，会使她收手，不会逼她当众继续演给玩家取证。**

共同交付页不是秘密后台。林见只能看自己那份源内容、当前对外预览和收件对象，不能读全公司订单或操作资金。旧工作流一直允许交付同一份内容；本次新增的是为纠错而给原作者看最后收件端。新访问发生在邀请被实际接受后，不无故获得管理员权限。

源内容明确是一笔练习，未付款、不发货。林见可以将交付限定在课堂，并把这个性质保留在收件正文中；他也可以不改原内容，直接问“这份发到谁那里”。孟宁和项目席能在同一条交付中读到这项具体限制。远汀项目席随后实际把接收对象改回沈航的正式店铺，把收件预览中的“课堂演示、未付款”改成“买家已付款”，预览将向商户提出正式采购要求；孟宁在同一会话认可这个对外版本。这不是两张未经核对的截图，而是对**同一份已知演示**的定向改写。

此时玩家没有义务放行。提交真实教学版本、撤回内容使用或拒绝发出，都可以阻止这次假首单。若选择交付，只有明确确认正式接收对象后才送出；沈航的正式店铺收到与预览一致的内容，但本段没有自动付款。玩家可将原本的演示性质直接告诉沈航，改变他对公司而不只是对软件的信任。

新问题来自工作意义翻转：**澄川交给远汀的，到底是教学材料，还是被包装成真实买家需求的原料？过去我做的东西也这样发过吗？** 这是这次可见行为引出的具体调查对象，不等于已经证明过去每笔如此。片段结束不给下一份办公待办，留下自己的既有交付列表作为自愿追查方向，不预放黑幕结论。

## 知情制造的最小证据条件

必须同时出现：

1. 源确实是这份未付款演示，且操作者实际看见其性质；不是玩家未发送的草稿。
2. 操作者知道接收对象是沈航正式店铺，采购要求是商户的实际资金用途；不只是沙盒预览或课程示意。
3. 对这同一份源内容，远汀项目席做了新的、定向的改写：隐藏演示性质并宣称买家已付款。孟宁实际协调或认可该版本，不能仅由岗位猜她知情。
4. 玩家能区分保存的候选、获认可的待发版本与实际送达。仅看到初稿，没有前两项，不能定故意；阻止后只能认定本次知情制造的企图，不能声称假交易已经送达。

这组行为排除了“只是不知情串接”和“只是对取消收霸王条款”的充分解释：旧收费已撤，新问题是主动把未发生的付款说成发生。**不声称排除世界上一切解释，也不把企图称为完整电诈定案。** 真实买家、平台自购或补贴若确实存在，本就需要另有真实交易，不应由这份未付款演示改写而来；仅说可能有补贴不足以解释操作者已经知道且认可的这一交付。

## 六表

### 一、事实与触发

| 时点 | 作者固定事实 | 为什么现在发生 |
|---|---|---|
| 昨日 | 林见做台灯样单，备注周五送前台，演示不扣款 | 普通课堂准备；历史可回看 |
| 今日开场 | 沈航的正式首单连着同一演示会话 | 远汀复用生成对象并未隔离消息端；这是本案虚构的暴露口，不能当行业常识 |
| 实际核实、撤回 | 会话关联可见；取消与撤采购真实完成 | 放弃一笔比让员工与商户继续追问更划算 |
| 仅作工作层面的纠错 | 孟宁邀请林见核对这次补发的收件端 | 想保住开店转化，误以为员工只反感弄错对象；不是因为作者需要送后台 |
| 真实教学限定已送达 | 操作者看见源性质和用途限制，仍改正式对象与已付款表述；孟宁认可待发版 | 核心人员将其视为正常项目包装，想保住首次采购。玩家尚未公开指控时才发生 |
| 公开异议 / 加入沈航 | 当前未发交付停止，对接收紧到项目负责人 | 对方避免暴露，不能为保证取证强行继续；停止前已发生的内容不会消失 |
| 放行 / 阻止 | 放行才送达；阻止则不发，旧单仍取消 | 选择改变是否实际误导，核实不需要新增损失 |

### 二、人物知识与动机

| 人物 | 知道什么、想要什么 | 行为限度 |
|---|---|---|
| 林见 | 自己未购买；看到源与目标才知道交付用途 | 拒绝新工作仍可说旧事实，不能控制别人的账号或已经送达的消息 |
| 沈航 | 知道自己首单取消；按实际收到的信息理解原因 | 不付款可直接结束风险；若看见原演示与正式预览，才有理由不信首单来源 |
| 孟宁 | 知道演示来源与交付目标，想保住项目服务和商户转化 | 不读私人聊天；公开指控就收手。仅见样单取消时不自动知道全部异议 |
| 远汀项目席 | 对自己的这份源、已送达限制与正式商户目标知情 | 只有真实改写才产生证据；未读消息不算知情，不能永远忙到不回应又自动定罪 |

### 三、线索的两层含义

| 可见物 / 行动 | 初读意义 | 核实后的限度 |
|---|---|---|
| 消息进自己的演示席 | 弄错会话？ | 演示与正式商户有关联，未证明有意 |
| 旧单与采购一并撤掉 | 公司愿纠错 | 确实纠正了这笔，不因此宣布公司清白或有罪 |
| 同源交付的正式店铺目标 | 也许给商户做开店教学 | 需看完整收件内容是否明示模拟，不凭目标单独判罪 |
| 已读教学限定后主动去掉未付款并显示买家已付款 | 也许是未定稿？ | 有权限者明确认可才是知情制造的企图；送达才是实际虚假交付 |
| 沈航收到与已认可预览一致的要求 | 真实商户被当作支付对象 | 只限此项，仍未发生采购付款或证明资金去向 |

### 四、竞争解释与区分

| 解释 | 应出现的正常差异 | 当前可检验行为 |
|---|---|---|
| 系统错误 | 撤旧单，下一份保留模拟性质或停止正式投放 | 撤单让步不算证据；知情后的定向改写才相反 |
| 霸王条款 | 对原有取消/服务费用发生争议 | 原费用要求已撤，本次没有真实买家付款却新造已付款表述，非同一收费争议 |
| 正常商户教学 | 正式账号也可收教材，但收件时能辨识演示、不要求实际垫资 | 只要演示标识保留就不能指控；本案操作者实际移除它并认可正式采购版本 |
| 刷展示或营销案例 | 声称销量可能虚假，但不一定制造个体采购要求 | 对象是沈航的正式首单及其实际采购项，不止首页宣传 |
| 单人草稿错误 | 发现后更正，不获项目另一方知情认可 | 只见初稿保留此解释；实际知情改写加孟宁认可才推进到项目协作 |
| 作者真相 | 两方有动机把自己产出用作首单并继续收商户款 | 本段支持这一次业务做法，不推出全部历史订单、员工和具体境外地点 |

### 五、场面如何改变目标

| 场面 | 玩家能改变什么 | 为什么可能继续 |
|---|---|---|
| 交期与双端相遇 | 回应买家、说明身份 | 我为何成了他眼里的海外买家？ |
| 撤回成功 | 结束这笔订单与采购项 | 可以退出；没有硬造未解决收费 |
| 补发交付邀请 | 看目标、限定教学或拒绝 | 我不想自己的演示再被当成真购买；为何这次要核对正式店铺？ |
| 知情改写 | 退回教学、撤内容使用、告知沈航或明确放行 | 对方是在修错误，还是有意把我的工作变成不存在的交易？ |
| 选择后收尾 | 决定谁知道、是否发出、是否继续参与 | 我阻止了一次交付，过去工作的真实用途仍未解释；也允许停在这里 |

### 六、作者纸面验证

| 路线 / 风险 | 修订结果 |
|---|---|
| 直接问远汀 | 问用途可跳到同源收件预览；公开指控会停止该交付，不强制取得最强证据 |
| 提前停止 | 撤旧单、停补发、停新工作分开；已停范围不重启。强证据未发生就不补发 |
| 拒绝参与 | 无需为通关替公司产新样单。拒绝新制作仍可核对既有内容；全拒绝允许结束 |
| 只看一边 | 仅看到已付款或演示皆不足；只有已见事实进入判断，不让 NPC 补齐答案 |
| 隐性草稿 | 单独改文字不等于送出限制；明确发出后才构成对方知情 |
| 会不会又像审批 | 只保留一次用途限定和一次真实回改，不设补材料、审核积分、等客服；玩家可直接退出或找商户 |
| 最弱处 | 为何让课程员工看最终交付须由纠错邀请呈现；若仍像管理员送罪证，需退回或放弃。陌生玩家的续查兴趣仍待验证 |

## 现实依据与虚构边界

2026-10-21 核读的[江苏省公安厅 2025-02-13 提示](https://gat.jiangsu.gov.cn/art/2025/2/13/art_89956_11491354.html)描述了虚假跨境电商平台以所谓买家付款、采购成本和回款为理由让商户投入资金，以及操控订单的情形。本稿据此选择业务外壳，不照搬真实受害者。

[长青街派出所于 2026-02-01 发布的提示](https://www.dxh.gov.cn/XWZX/XWYS/202602/t20260206_2725401.shtml)也涉及假跨境平台、虚假订单与垫付货款。两份来源**没有证明“课堂样单被转成商户订单”、双端消息机制或本轮共同交付界面**，这些是明确的虚构设计。作者固定远汀核心运营在境外、澄川为境内协作方，但本段玩家尚未证实具体地点，不以服务器或货币显示代替调查。
