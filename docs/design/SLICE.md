# 网页片段：还有谁在听

状态：2026-10-20，按 [db1a2e4](https://github.com/TedShao/chengchuan-mystery-game/tree/db1a2e48636b5ddf677cc2ac9f8b08f12a4e8bce) 关闭指引复查并删除后半段审批结构。作者知道底稿，以下仅按当步可见信息排演，**不是陌生玩家实测，不报告虚构的兴趣、耗时或成功率**。当前仅剩局部事件，公司调查后半未就绪；事实见 [STORY](STORY.md)。

## 先走原稿：合理停下，不补作者的下一步

本轮不改金额、不预先判断顾成犯罪、不要求读齐材料。问完得到合理答复，就允许停止。表内是具体反例路径，不是玩家行为统计。

| 路线 | 依次可见与操作 | 原稿反馈及可知结论 | 真实断点 |
|---|---|---|---|
| 直接问依据 | 看本案原申请 → 问“付款回单有吗？” → 按要求给出单号 → 顾成引用同一申请 → 说“这个还是受理，先别恢复” | 没有新回单，原入口保持停用，候选也未发布 | 可判断这次答复不能证明付款。接下来完全可以等真正依据，没理由必做另一稿或查公司介绍 |
| 先拒绝恢复 | 已发现替代页仍写到账 → 不改文字，直接说“没有回单不要上线” | 顾成保留两稿、停止发布 | 一份未发布稿可以是暂存、等材料或未清理。旧稿将其当成继续造假的动作，超过证据 |
| 只看候选 | 不打开原申请、不查教学原件 → 见结果稿写到账 → 问依据 | 原稿未获分享时只能问哪一笔；取得后给原申请 | 单凭候选无法判断真假，更不能知道其固定组件不查款。主持人不能替玩家补完引用内容 |
| 只看两页状态 | 见同单号等待出款与已入账 → 问是否同步慢 → 要求先停 | 有冲突，顾成可以正常停用 | 足以要求查明，尚不能说明教案来源或实际资金业务；不应自动解锁这些结论 |
| 只查投放 | 从 A17 使用位置停用 → 对客入口不可用 → 不看唐雯分享 | 证明公司维护该入口 | 正常外包也如此；通用候选不能变成唐雯本案证据。缺少实际用途信息就停在有限结论 |
| 全部核实但不改稿 | 看原申请、实际投放与候选 → 索取依据 → 没有新依据 → 坚持不恢复 | 无依据的交付可疑，但没有新的对客事件 | 仍可停在“这页不能用”；下一问只是同一问题换措辞，尚无新的可核实对象 |
| 先误判再改口 | 将两页冲突说成钱被侵吞 → 发现证据有限 → 改称“这页不能作到账证明” | 原已发指控留痕，停用维持，资金未知 | 改口应被接受为收窄结论，不能用主管恼怒或报复补悬疑 |

六表复核：局部投放事实与停用结果为 **explicit**；顾成实际收到本案才知道玩家在问哪笔为 **explicit**；“本次未给回单”为 **explicit**，“没有任何付款依据”为 **missing**；保交付的动机是 **strong inference**，暂存稿代表执意造假是 **weak inference**；候选核对后的新调查对象为 **missing**。结构判断：能呈现不可靠确认和责任疑问，尚不构成完整的公司调查推进。

## 删除什么，保留什么

直接删除主管自动生成替代稿、加演示说明 / 保留原话的比较、两稿选择、恢复审批，以及“他留着草稿，所以修错已不足以解释”的推断。旧全文留在固定提交历史，不复制另一份报告。也不恢复已退役的改金额必经步骤或资金申诉结案链。

保留唐雯已有投入、两页状态矛盾、真实投放、直接询问、可选输入反证、有效暂停与实际告知。**没有新增秘密文件、付款事故或主管坏动作来救场。** 下文是删减后的局部玩法，不声称已经补出公司调查后半段。

## 当前局部片段：看清一件事，允许结束

开场定位只说明：林见在澄川做课程内容，第 47 天；知禾的回放、课件和交互示例归他，社群找许蔓，项目发布找顾成。最近使用中有上周的 A17《到账状态说明》，无“可疑线索”标记。普通办公与摸鱼入口保留，不要求先填汇报。

唐雯已有服务会话：

> “今天的电话取消吧，不加了。前天申请取回的三千还没到。这边还在等出款，点进去又说到账了。陈姐说她昨天就到了，我这笔该信哪个？”

她附本案只读分享卡与引用的陈姐图。申请详情为 `3,000 元 / 已受理，等待出款 / TW-0417`；其结果链接针对同单号显示 `收款账户已入账 / 金额一致 / 尾号一致`。查看许可只限本案。页面读取时间与原处理时间分开，不通过刷新伪造进展。

玩家可以先取消电话、问依据、核对单号或查图，任一路都不需要先浏览全部办公软件。查图时许蔓可承认陈姐由运营维护、图来自教学，并实际撤图停止追加联系；她不讲解资金后台。

### 直接问，不再先做一份材料

- 只说“你有付款依据吗”，顾成不知道问哪笔时答：“哪一笔？把申请发我。”只需要指明对象，不要求固定措辞、附件数量或证据齐全。
- 已收到本案时，他可答：“我这里也是这张申请，没有付款回单。结果页先停。”这说明他本次能给什么，不是招供。先前已经停用则答：“先前停的还没恢复。”不能重复执行或创建候选。
- 玩家只拒绝恢复、不愿改稿：“先保持停用，不用你重做。”随后状态确实维持。顾成没有被迫泄密，也没有暗中补发。
- 同时问依据并拒绝经办，两项都保留：回答已知依据，停止发布，不把问句当作接受新的工作。

若顾成没有本案权限或资料，不能突然查到私密交易；自己的项目用途他原本知道，不必装作全靠林见介绍。私人草稿、未发比较与仅打开网页都不通知他。

### 可选核实各有上限

| 操作 | 当步可见反馈 | 能判断到哪里 |
|---|---|---|
| 开原申请、核对同单号 | 等待出款与结果的入账主张不一致 | 有具体矛盾，仍可考虑同步慢或表述错误 |
| 查自己的固定投放版本 | 教学原件、实际使用位置和固定版本关系可核对 | 仅同外观不够；确认实际使用同一不接交易的组件后，才可说演示被当成真实结果 |
| 暂停组件 | 动作前说明只停内容；对客结果页不可用，原资金申请不变 | 公司维护此结果，不等于控制银行或冻结资金 |
| 自主输入不同金额 | 同编号、新有效金额仍被逐项判为匹配，结果回显本次值 | 可否定核验承诺；没有同事提示此做法，不做也可质疑与停用 |
| 要求独立付款依据 | 本次仅得到原申请或明确缺少回单 | 不能用此确认到账；不推出世界上没有其他记录 |

先停仍可在隔离预览查看原固定版本，不需重新公开结果。内部演示会显示成功本来就正常，须结合实际投放关系；不以技术术语解释代替玩家可见关系。唐雯撤回分享后不再取得新账户状态。

### 局部反馈不变成下一份待办

若玩家实际告诉唐雯“这页不能证明到账”，她可以回应：“知道了，我不拿它当回单。电话不用再安排。”不自动知道公司全部问题，也不替玩家追查。仅停页面没发解释时，她只会见到入口不可用，不能说出玩家的推理。

若玩家仍问钱怎么处理，应明确当前没有查明；可按唐雯意愿继续本案沟通，但不能在本片段自动生成一套投诉、审批或新任务。自由办公与退出可随时继续，不靠新增损失留下人。

| 分支 | 实际保留的后果 | 不自动授予什么 |
|---|---|---|
| 直接索取依据后停止 | 原结果停用，尚无独立回单 | 不授予“已查明诈骗”或下一站任务 |
| 最早拒绝恢复 | 保持停用，无替代发布 | 不用新版本偷偷抵消选择，不产生未发生的送达 |
| 只读部分材料 | 根据看过的对象有有限判断，入口仍可回来 | 不因片段进度补齐未看的证据 |
| 拒绝申诉 / 拒绝经办 | 不代理客户事务，可以自查或离开 | 不让唐雯自动办完投诉再带回必达线索 |
| 误判后改口 | 原话留痕，后发更正只送实际选择的对象 | 不自动恢复内容、抹掉记录或传播私下反悔 |
| 重复问、反复暂停 | 只回应没有新增依据 / 已暂停；缺对象时澄清 | 不刷好感、怒气、新事故或重复通知 |

用户若明确选择恢复原内容，应展示将恢复的具体版本和影响再执行；这只保留自由操作的状态规则，不设计“恢复审批”任务，也不靠玩家放行错误来取得后续。

## 删后同路复查与决定

直接问可以拿到目前能给的材料并停止；拒绝恢复可以成功结束发布；只看候选的旧路线已随候选删除，不再以少读材料判失败，其他部分阅读保留有限结论。没有新增对白把普通停止重新包装成犯罪发现。

**结果：删除审批链后，局部行为更短、证据边界更清楚，但公司调查后半仍未成立。** 本轮不是“改完又通过”。尚缺一件在纠正页面之后仍存在、能让玩家提出不同于“付款凭证在哪”的新问题，并通过自身正常权限核实的业务事实。当前没有写出这件事。

现有局部材料可检查理解，不能作为完整十分钟悬疑的生产稿。重构必须先修事实链，而非继续替“已入账”换措辞；状态与否决条件同步到 [PLAN](../PLAN.md) 和 [H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
