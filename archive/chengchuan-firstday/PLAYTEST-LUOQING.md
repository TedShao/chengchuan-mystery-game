# 罗青案例落地与试玩记录

日期：2026-10-19。版本：罗青案例版 v12。验证对象：实际静态网页，Chromium 浏览器；各剧情路线以独立的新浏览器存档启动。

## 实现范围

原先的项目数量、虚假外派确认、人事附件等剧情已从加载和发布目录移除。当前材料以《第一天完整分场剧本 v1》为依据，固定历史见 `dist/case-data.js`。

- 从工作记录可进入资料补发、课程通知调整、复盘图表三项真实工作。
- 罗青邮件保留原主题，新来信与折叠的历史分开显示。
- 同名用户、事项编号、时间、原始回信和经办记录可以跨应用对照；没有强制解锁顺序或“证据已集齐”提示。
- 回访快照、共享复盘和当前服务记录各自独立。转给小雨的新信会追加到当前记录，不覆盖旧快照。
- 向谁转发，谁才获得那份材料。笔记、收藏、草稿不传播。
- 共享稿更正、个人稿撤回、培训整条替换、后续负责人、境外岗位意向分别保存。
- 沈念只确认转交范围，不据此证明款项已到，也不提供第一天不该出现的银行调查结果或完整犯罪结论。

## 从新玩家视角实际走过的路线

| 路线 | 实际操作 | 检查结果 |
|---|---|---|
| 漏看 | 关闭指引，从工作记录选课程时间调整，核对邮件与课程页，提交 Word，直接下班 | 不强制打开罗青邮件；正常案例成立，未自动接手罗青事项 |
| 先误判 | 从共享复盘开始，复制原结论提交并同意培训引用 | 培训网页出现实际个人稿，明日任务变为补充操作步骤，不只是弹评价 |
| 后纠正 | 随后打开新来信与历史，筛选罗青三条事项，索取旧对接片段，撤回个人稿并提出具体更正 | 原稿保留；共享新版本收窄范围，培训稿相应变化；资金结果仍未解决 |
| 顺序交叉 | 整条撤出培训之后，再更正共享稿、再撤回个人稿、重新打开网页 | 培训始终保留替代案例，没有复活罗青引用；修订文件可再次打开 |
| 接收范围 | 只读来信、仅转小雨、不转周衡 | 小雨获得新情况；周衡没有凭空获知私人来信 |
| 追问与误指控 | 质疑伪造感谢，收回指控，再问引用；一次问杯子和汇报，随后模糊追问 | 对话区分“是不是”和否定；多话题后要求明确指代；杯子归还后不再说未找到 |
| 操作边界 | “先别问沈念，只要现有记录”；重复索取；重复提交询问 | 聊天不发新询问；明确请求只提供现有片段；重复发送不增加工作单和当前表记录 |
| 提前拒绝与改口 | 拒绝境外常驻、拒绝接手；发送一次询问；反复变更后续分工 | 国内工作可继续；已发询问不消失；反复改口最终与当前选择一致 |
| 罗青回应 | 私人阅读摘要，再实际附送给罗青；错误保证款项已退，随后收回 | 她只对实际收到的摘要作出反应；错误保证被追问依据；撤回保证留在记录中 |
| 继续了解 | 请求她提供课程、平台和款项经过 | 提供本人陈述；银行查询仍未回复，不提前给出案件结论 |
| 自由办公 | 新增 PPT 页并放映、编辑表格副本、指定范围求和、查看原件、申请用品、喝咖啡和翻牌 | 正常使用；编辑副本不修改原始材料；休闲不推进任务 |
| 序幕 | 正常渐变、自动翻页、暂停、键盘、快速连点、跳过、重新打开、390px 入口 | 保持序幕与存档分离，明确点击后进入工作空间，无浏览器运行错误 |

## 试玩中发现并修复

1. “是不是伪造”被当作“不是伪造”，导致人物错误接受改口。
2. 指引在抬起鼠标时重建按钮，吞掉“关闭”点击；另修复隐藏属性被样式覆盖。
3. 最大化窗口遮住桌面下班入口，增加常驻系统栏入口。
4. 分工去重曾把“再次改回之前的选择”误判成重复，现按当前状态处理。
5. 项目邮件回邮曾默认选到罗青，现沈念回邮保持正确收件人。
6. 多重 Re 标题、回信时间先于发信的细节已修正。
7. 表格公式曾忽略指定列与范围，现支持指定范围计数、去重计数和求和。
8. 重问同一话题不无限追加同一答复；已有附件不重复发放。问罗青既有经过时承认已经提供过说明。

## 验证与边界

- `tests/luoqing-day.cjs`：6 组实际界面路线与状态/文本断言通过。
- `tests/luoqing-prologue.cjs`：2 组序幕、重新打开和手机入口检查通过。
- 网页游戏技能检查器执行通过，检查最终序幕截图和状态输出；相关浏览器控制台错误为 0。
- 人工阅读了入口、错误稿采用、修订后培训稿、罗青补充说明和序幕截图。
- 旧版剧情脚本不适用于本版，没有将其计为通过。
- 聊天是有限规则与对话记忆，并未接入 AI。不能保证理解任意表达；不明确时澄清，不推定用户已确认任务。
- 当前只实现第一天，明日任务会根据选择留下不同内容；未制作第二天调查、真实收发短信电话或完整终局。
- 旧剧情存档键未清除；新故事单独保存，避免旧状态提前泄露新材料。
