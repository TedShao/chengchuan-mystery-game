# 网页片段：替你说的话

状态：2026-10-21。从 [a294217](https://github.com/TedShao/chengchuan-mystery-game/tree/a294217ca66b187b9cf000f6a7a2dfa65ac2eb40) 重构更正后的公司调查。本次先比较可区分的行为，再作限制信息的作者纸面排演，最后回写分场。**不是实际陌生玩家试玩；没有用时、完成率或兴趣测量。** 不改代码，事实与六表见 [STORY](STORY.md)。

## 先淘汰两个看似能推进的办法

| 候选 | 纸面反例 | 处理 |
|---|---|---|
| 公司不接受实名员工交流，甚至取消订单 | 正常采购真实独立学员也会拒绝员工；取消恰好可能是纠错 | 不以拒绝、减价或取消作为欺骗证据 |
| 停掉小林后，公司换顾成继续 | 可以是普通替班；负责人可能没收到真实问题 | 换人只引出疑问，不承担结论 |

采用的区分事实是：**玩家已让有权限的负责人知道实际员工与“非工作人员”承诺冲突，负责人仍把这个员工配置正式确认给原付费客户。** 同一人、同一服务、同一已知关系；不是未发布草稿，不靠下一名受害者验证。可以提前阻止，代价是这项“告知后仍确认”的事实不会发生，不能预写人人拿到相同证据。

## 无指引分场：从一个复访开始

### 1. 我的头像，昨晚的话

开场仅给生活位置：

> 失业三个月后，你进了澄川，做课程服务。今天第 47 天。昨天六点下班，夜间由组里代班。

沈航：“昨晚跟我聊的那个人今天在吗？我还有一句想问他。”

左侧仍有课程聊天和自己的出席日历。玩家可先看日历、回复、问顾成、自由办公或离开；没有“发现异常”待办。原会话从开始就能展开，消息详情可见顾成操作：

> 沈航：我想找个自己做过的问问，别再转介绍项目的人了。
>
> 小林：你想问什么？
>
> 沈航：你也在澄川上班？
>
> 小林：不在。我也是上课才知道的。
>
> 沈航：你自己取过钱吗？
>
> 小林：取过一次，后来才又放进去。

只看取钱句，仍可解释为顾成讲自己的经历；不能替玩家补全关系否认。直接问“谁回的”，顾成可答“昨晚是我”。追问“你为什么说不在公司”，他可答“他一听项目组就不愿聊了”。这解释个人动机，不让他代公司自白。

### 2. 先把眼前的事结束

普通回复会以“林见 · 澄川课程服务”发送，并接管当前对话。只亮员工身份，沈航可以问“换人了？”；明确更正昨夜也是公司员工后，他可以取消预约。停本席代发不自动告诉对方，更正也不默认恢复代发。

取消后显示具体事实：“沈航的预约已取消；本席代发已停。”不再发“还有一位客户……”维持主线。林见退出本单时，一次移除自己的后续出席和本人对外展示；保留历史。沈航可以就此不再出现。

### 3. 看看我被安排去做什么

这是可选入口，不是取消后的系统派单。**“我的出席”从开场就可见**，与课程日历相邻。卡面初见是普通工作信息：

> 远汀 · 同学交流
>
> 今日 14:00—14:20 · 服务时段
>
> 出席：林见｜课程服务
>
> 委托客户：远汀项目组
>
> 学员预约：沈航（取消后显示“已取消”；无其他学员）

不要在卡面写“公司付钱买假同学”。点正常的“学员看到的介绍”，才看到：

> 和参与者聊一聊
>
> 本场交流者不是澄川或远汀的工作人员。
>
> 你可以先问问他的经历，再决定要不要了解项目。

同一卡片的客户视图说明远汀购买这段交流服务，状态为公司已接单；不堆价格表、证书、银行流水。入口名称明确区分“学员介绍”“客户安排”；这个客户是远汀，学员是沈航，不能把二者都叫“对方”。

第一次发现只支持两个可能：人员配错，或服务本身在装独立。可以直接将这句介绍连同自己的员工身份发给负责人；也可以完全不问、撤自己。普通日历的交付联系人为孟宁，无密码、文件阅读量或准确搜索词门槛。

**动机留白：**玩家可能只想确认自己的头像撤没撤，顺手打开这张卡；也可能没有这个兴趣。界面不给奖励提示“追查购买者”，纸面不把回看预写成必然。

### 4. 不写报告，直接说自己的条件

向孟宁表达以下任意意思即可；不设置要照抄的正确句：

| 玩家实际表达 | 她实际知道 / 可发生的行动 |
|---|---|
| “我不出席。” | 只知道缺人。把林见撤掉，安排替补；不认定已收到欺骗异议 |
| “我可以按课程员工回答，但不能说我不是公司的人。”并带上本场介绍，或明确指出其承诺 | 知道真实身份与外部承诺冲突。可答：“你的出席先撤。顾成那边我处理。”不说一整段销售理论 |
| “顾成也在公司，你知道吧？” | 她实际答“知道，他是我们组的”；不能据这句就定罪，后续业务动作才有分量 |
| “先停整场，这句身份介绍核实之前不要确认给远汀。” | 明确整单异议，新增安排暂停；不是仅撤自己。可答：“先挂起，我跟那边确认。”随后客户侧必须真的显示暂停 |
| “你们是不是诈骗？”没有指向具体内容 | 可以要求说清哪件事；不从笼统指控自动知道旧会话。不强制投诉措辞，也不按攻击性关键词扣隐藏分 |

一个“别再安排”若对象不明，只澄清一次：“你自己的出席，还是这笔远汀的交流服务？”“别再让任何员工冒充同学”已明确指向整项服务，按整单异议处理；不能故意缩成只撤本人。此前已指定对象则不重复问。不将语气委婉理解为同意继续，不把问问题等同接手。

### 5. 她确实让你退出了，然后呢

玩家可以离开，也可以回看同一张卡。等待以一次明确的“查看交接结果”推进场面；不因阅读速度或重复刷新偷跑。尚未处理时显示待处理，不能把预定剧情冒充已发生。

**A：只撤本人，或仅要求自己如实出席，未提出整单暂停。**

孟宁将林见移除，替补顾成；公司保留远汀已买的交流时段。这一步单独是正常调度。林见没有权直接改客户订单；撤个人由本人控制，整单暂停由孟宁收到请求后执行并反馈。查看客户安排时可见本次调整**已由孟宁确认给远汀**；关联的学员介绍仍保证出席者不是两家公司工作人员。这里显示与本次确认一起发给远汀的服务介绍，标注同一版本，不混用缓存旧页。这是本次已确认服务版本，不是可继续编辑的预览，也不是一份藏起来的制度文件。

- 若玩家之前完整告知冲突，并确认孟宁知道顾成受雇，她随后仍实际确认这份安排，才取得公司层面的区分事实。
- 若之前只是说不干，仍可能是孟宁不知道错误。玩家可以现在指出；她随即挂起已确认的安排，不再追加一次错误发出来“证明她坏”。此路线对她此前是否明知保留判断。
- 林见的头像不再出现；沈航预约保持取消，没有换个席位联系他。该服务此刻没有其他学员预约。此段确认的是公司愿意向远汀交付什么，不虚构有另一场会谈已发生。

玩家的实际试探是“把我的真实关系放在桌面上，允许正常咨询，看公司会改资格还是只换人”，不是寻找一处页面错误再填修复单。孟宁的退让保护了林见个人，却未改变她要卖的东西，这才是本段的不安来源。

**B：提前要求暂停整笔服务。**

新增出席安排冻结，不出现上述确认。客户侧可见暂停；玩家可再允许“真实员工咨询”这一明确范围，也可继续拒绝。孟宁此时不会当着完整异议再次确认非员工承诺；她保留暂停，或撤掉不实资格后改为员工咨询。两种实际处置需在分场中择定：**本片段先固定为暂停，不自动替玩家做降级恢复。若玩家后来明确说“我愿以课程员工身份出席，请只恢复这种咨询”，孟宁把本单改为员工答疑，撤掉非工作人员承诺，将变更送远汀确认；客户未确认前不恢复对学员开放。画面显示“员工答疑 · 待客户确认”，没有已举办会谈或客户已同意的假反馈。**

这一路成功防止继续销售原承诺。已有员工配置与错误介绍仍可支持怀疑，但不足以证明她收到异议后仍继续经营。不给“证据不足”失败结局，不为了强结论让暂停无效。

**C：拒绝一切参与。**

移除个人、停止本席、关闭页面均有效。没有强制看最后一封邮件。可留在课程工作或结束片段；不是每次合理退出都必须被设计成犯罪现场重开。

### 6. 收尾由玩家的判断决定

| 到此真正知道什么 | 可采取的下一行动 / 当前后果 |
|---|---|
| 只知道顾成个人否认关系 | 更正、撤自己；不自动产生对公司或远汀的指控 |
| 已看见公司卖的承诺，但负责人未被告知 | 向有权限者具体指出，或暂停；能将问题从个人带到项目，不等于已证明知情交付 |
| 完整告知后仍实际确认 | 可把已经确认的服务介绍与实际员工关系一并向原客户提出核实，或要求整单暂停；当前片段停在该决定，不接出新一轮固定聊天 |
| 已提前暂停 | 保持暂停、明确恢复员工答疑后将本单变更送客户确认，或退出；已阻止的后果不再次发生来补证 |

结尾不出现“已发现诈骗公司的真面目”。更窄也更有用的问题是：**这项付费服务为何必须让学员误认为推荐者独立，远汀买它要影响哪一个决定？** 本段已确定购买者，不用再搜索公司名字装作新谜题；资金去向、境外联系和更高授权都未证明，不凭 IP、英文名揭底。

## 实际行动、收件与重复的约束

- 私下打开学员介绍，孟宁不因此知道异议。转发只含人名时，她不知道玩家还看过哪句承诺。
- 顾成收到质问不等于孟宁收到；她有管理权限也不能读取玩家草稿。已实际查阅本单内容才进入认知。
- 对客确认必须在屏幕上有清楚的结果和确认者；“孟宁说会换人”“有一份待确认稿”都不能冒充这一事件。
- 沈航取消预约、个人退出、整单暂停是三个可见对象。操作后说清改变哪个，不加一排需要全部点满的状态灯。
- “我刚才误会你了”撤回的是指控，不默认恢复代发、出席或原资格。需要的对象不明才澄清，不每次让玩家重填。
- 已确认的安排后来暂停，会显示现在暂停及原确认记录；不抹历史，也不把已暂停显示成仍在履行。
- 重复停止、重复质问已回答的问题，不产生新订单、新确认或新谎言。角色引用现状作简短回应，已结束的对话不自行重启。

## 纸面反路线与删改结果

方法：只使用当步屏幕或已收到内容，允许停止；下表是作者对分场的条件检验，不是替真人宣称“想继续查”。没有按完整线索顺序把每条路线补齐。

| 路线 | 所见 → 行动 → 结果 | 当步可判断 / 改掉的强行推进 |
|---|---|---|
| 直接问顾成，先解决局部 | 确认他代班、看关系问答 → 他配合更正 → 沈航取消、本席停止 | 局部可结束。删掉顾成再撒一句谎或沈航继续求救；公司入口是原有自己的出席卡 |
| 先看日历，不读旧聊 | 员工排班 + 非员工介绍 → 向孟宁指出、只接受实名岗位 → 她撤人换顾成并正式确认 | 可独立形成项目矛盾，不强制返回旧聊。顾成过去具体说了什么仍未知 |
| 完整更正后只撤人 | 沈航离开 → 看自己的交接 → 顾成替补、介绍未改 | 若未告知孟宁，仍可能误配；补充具体问题后她暂停。删“换人就证明公司”捷径 |
| 完整告知，但接受自己退出 | 说明员工与承诺冲突、她确认知道 → 她让玩家退出 → 自行回看已确认的客户安排 | 支持该项目知情出售虚假独立性。没有新学员、新损失，也不要求玩家恢复任何联系 |
| 一开始就阻止整单 | 看见错误介绍 → 要求暂停 → 确认到客户的更新被冻结 | 阻止有效，没拿到后续明知确认的事实。保留局部怀疑，不补秘密资料兜底 |
| 只看一面 | 仅内部排班 / 仅学员介绍 → 退出或问一次 | 前者可正常外包、后者可正常同学交流；不自动亮红，相关双视图仍可由卡片入口找到 |
| 拒绝所有联系 | 停代发、撤自己 → 自由办公 / 结束 | 无保证的公司结论。退出不受惩罚，不给“坏结局”逼看材料 |
| 改口 | 先暂停，后说“正常员工咨询可以” | 仅改变允许范围；本段服务仍暂停，需明确恢复该范围才有下一动作。不能被当成恢复伪装 |
| 漏附承诺、直接质问公司 | 孟宁仅收到雇佣事实或骂名 → 问具体哪件事 → 玩家可补同卡链接或不再说 | 信息不足不是角色失忆；删掉她自动知道旧会话、立即自白的回应 |
| 先错判、再撤回、反复操作 | 曾将普通代班说成诈骗 → 撤回笼统指控 → 后见明确资格矛盾 | 新事实支持较窄新判断；重复不累积罪证，改口不恢复已停止对象 |

**本轮纸面结论：**有了一个条件明确的区分行动；公司层结论不再依赖顾成的第二段自白。但不是所有路线都取得同等结论：提前阻止会改变事件，漏看可以保留误会，彻底退出允许结束。人物关系和证据强弱随实际动作变化。

**下一轮可推翻它的观察：**如果陌生玩家看见付费客户与非员工承诺，仍只想“找管理员改两行字”；或撤出后只因任务提示才回看；或把“已确认服务”误读成新的受害事故，那么这一段仍未达到目标。先调整或删除场面，不再加长解释、延长聊天、增加事故。当前只进入 R03 的纸面呈现观察准备，不批准代码开发。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
