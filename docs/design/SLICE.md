## 核实段落：撤掉旧链接之后发生什么

以下编号只供作者排演，玩家界面不显示步骤。可从网页、同事或新来件进入，不要求依次读完。

### 一、先允许普通误会成立

只问小雨“昨晚是你？”——“是我。她一直找你，我就沿着那个会话回了。这事我该先问你。”她承认代班；停用名片立即生效。只问周衡“入口再发一下”，他会发原链接，不能据此判断故意误导。

若引用 P3/P4 问退出为何要接下一期，小雨实际打开后说：“我刚看了，这页是下一期。这个先别发，我问周衡。”转问内容可见；她不会顺便说“公司靠这个挣钱”。直接问周衡同样可行，无须先过小雨。

周衡收到具体问题：“旧链接先撤。我请项目回她。”**P5 原转发确实取消。** 这时仍可能只是纠错，不播放悬疑结论，不凭没有退款结果就宣布骗局。

### 二、把客户真正同意的事送过去

罗青已在原会话说不想接下一期；如果有人提出请项目回复，她可明确范围：

> “可以回消息。就说怎么退，下一期的东西别再发了。”

不是让玩家填新的联系表。原话可直接引用给周衡，也可由他接手并实际打开；已有明确原话时不要求罗青重复一遍。她同意文字回复退出问题，**没有同意讲下一期、打电话或操作资金**。若当前经办人已收到她不要再联系的意思，后面整段不发送；保留较少证据也是有效结果。

周衡实际读到后，回复罗青：“旧入口先不用了，项目会回复你的退出问题。”这句只创造一个可检验的承诺，没有给出真相。若他只收到页面、没收到限制，不能将后续称为“无视已收到的明确拒绝”。

### 三、看新行动，而非再听一轮解释

主管接手且罗青只同意退出文字回复的路线中，随后出现两条正常业务消息：

| 本案中的实际内容 | 谁能看见，为什么 | 此时还不能说什么 |
|---|---|---|
| 周衡 → 远桥接待席：“罗青愿意了解下一期，请发说明，先不要催她确认。” | P5 显示公司身份、实际发送与收件时间；这次转问只发送摘要，没有附罗青原话 | 草稿不证明已传达；只有公司给客户的标题也不够 |
| 远桥 → 罗青：“按澄川转来的咨询，现有金额可沿用到下一期，安排见下面的说明。”附续期说明 | 本次协作回复同步回 P6；从“回复哪条消息”打开刚才的公司摘要，也可由 P5 看关联来件 | 不是客户已同意，不能让她自动点确认；项目接待席并未获知被省掉的限制 |

说明只保留两行实际内容：**本期金额转入下一期；确认后按下一期结束时间申请退出。** 不再增加一份长规则供背诵。玩家可以打开原 P4 对照，或直接从回复查来源。新内容重复的是参与要求，新增的是它如何从公司转述变成实际发送。不能用两次相同链接冒充两条独立证据。

可形成的疑问从“入口发错了吗”变成“谁告诉项目她愿意了解？”再变成“我们说替她问退出，实际递过去的是什么？”这些问题不由 NPC 念出来，也不生成必须完成的待办。

### 四、追问要产生后果，不能靠主管自白收尾

| 已收到的内容 / 玩家动作 | 合理回应与实际变化 |
|---|---|
| 只问“是不是哪里弄错了” | 周衡先问指哪一条；若当前已引用公司摘要，就回答该摘要，不重新索要已有材料 |
| 引用原话和新摘要，指出没有同意了解下一期 | 周衡：“那就停。我来回她。”向实际收到摘要的项目席补送“她不接受下一期，停发”；向罗青告知停止推介。退出问题保留未解决 |
| 继续问“既然要退，为什么转成愿意了解” | 周衡：“我想先把人接上，没让她确认。”这只是他的辩解，不能覆盖已发摘要；不要求玩家接受，不再创建同一安排 |
| 保留原话，从本案协作入口直接问项目接待席 | “这张退出申请我这里查不到，我问原来接你的人。”不发续期说明，实际转问原接待，尚未收到结果就保留未答；不能强制绕回主管让他再误述一次 |
| 问小雨“你也知道这样转？”但没发摘要 | 她只知自己看过的页面和转问，不能先评论周衡新消息；拿到摘要后才撤回“主管会处理好”的保证，并把客户原话补给周衡，不替他辩解资金流程 |
| 没发出的安排被阻止 | 取消未发项，显示未送达；没有项目后续，也不伪造一封续期说明来补齐揭示 |
| 玩家只说本人不接、名字不用 | 周衡接手，改用公司身份；罗青是否接受项目回复另算，不自动停止公司的所有业务 |
| 罗青的全面拒绝实际送达当前经办人 | 停止本次联系及未发内容；已经送出的保留。尚未转达的私聊不使其他人隔空停止，也不因“剧情要发生”忽略已收到的拒绝 |
| 先答应接手、后来改为不接；或先指控、再限定更正 | 经办与观点分别修改；道歉不恢复名片，不消除旧外发，不替罗青撤回拒绝 |

主管在异议明确后退让是可信的自保，不是“反派突然变好”。可疑的仍是：知道她只要退出，之前却代表她传了相反意愿。玩家无需逼他承认诈骗；阻止成功也有价值。项目方收到更正才停止，不会隔空知道员工改口。

## 关闭指引的纸面排演：故意不按顺序

**已见内容决定推断上限。** 以下为作者推演；未测实际阅读时长或真人兴趣。关键新发送的顺序固定为原话送达 → 主管外发 → 项目收件 → 项目回复，不因玩家打开页面临时改时间。未交还、未许可或已取消时，不借等待补出事件。

| 路线与逐步操作 | 当时可判断什么 | 后果 / 不应出现的补丁 |
|---|---|---|
| A 先问小雨 → 她承认 → 停名 → 看原链接 → 把页面和已有退出原话交周衡 → 罗青只允文字回复 → 交还 → 查看来件来源 | 撤名已解决；P4 初见仍可能误发；新回复出来后查 P5，才能发现公司主动改述 | 旧链接取消、新摘要及续期回复真的发出；继续调查的对象从小雨代班转到公司如何向项目表达客户意愿 |
| B 从 P3/P4 开始 → 直接引用“只问退出”给主管 → 不先查名片 → 主管接手读到 → 先看公司外发再看来件 | 不用认全人物即可检验发错说；外发与原话冲突支持怀疑，项目随后执行增强判断 | 没有第二套解锁条件；姓名仍按本人真实设置，发现异常不会自动停名 |
| C 先不接手 → 停名 → 保留本案副本 → 接手人读到罗青有限联系许可 → 项目回复来了才打开来源 | 自己不经办，仍可比较当时参与的同一事项；先看到续期回复只能怀疑远桥自行推销 | 查看公司来源后再限定责任；不是逼玩家接回工作。若连后续也拒收，则本幕安静结束 |
| D 只传 P4 与“可以回消息”给小雨，漏了“不发下一期” → 问为何还推下一期 → 再补完整原话 | 对方收到联系许可，没收到具体限制；小雨和主管不凭空知道被省略的内容。若接手读过完整会话则按已知处理 | 若尚未外发，补充后可取消；若已经外发，只能追加更正。不能把先前发送倒算为违反后收到的限制 |
| E 只见续期回复便怪远桥 → 查关联请求 → 改口“至少这次是我们先这样转的” | 新证据改变责任判断，但不能宣布远桥全无责任或原入口无害 | 可把原话补送到项目席，也可请主管补送；只有实际送达后才停后续，不要强制两边重复报告 |
| F 指控小雨故意骗钱 → 看昨晚代班和今早来源 → 撤回超出证据的部分 → 继续问公司摘要 | 不同时间与品牌不能证明谁清白，只能撤回未经支持的“明知”；她收到新摘要前不知此事 | 小雨接受限定更正但记得争执；私人指控不自动传给主管，已实际转发的内容不因道歉撤回 |
| G 漏看全部链接 → 明确允许发原 P5 → 罗青打开后说“我是要退，这里怎么是下一期” → 玩家核对并更正 | 可自然恢复；这是客户指出，不算主动发现 | 不自动确认资金；以后仍可进入核实新请求或直接停止，发过的错误推荐保留 |
| H 一开始拒绝所有参与，罗青也不接受新联系 → 之后重开历史 | 能看已有链接矛盾，无法看到没有发生的新外发 | 不补可疑消息、不强推会谈、不判坏结局；不能把此路也统计成“排除误发” |

### 再追问、改口和反向操作

- **“先别发，算了你接，但不要发下一期。”** 经办可交还，内容限制仍在。若限制是玩家自己的要求，应如实标为员工意见，不能代罗青许可联系；已有客户拒绝则优先不联系。
- **把客户原话直接送到项目，而非让主管概括。** 在本案已建立协作的范围内可行；对方不发续期说明，就不能凑齐“公司误述后实际执行”的事件。玩家仅能确认这个接待席无法给出退出结果，不可把正常转问当成完整骗局。
- **“她后来愿意听了呢？”** 必须有罗青真正新发的同意；此后安排下一期说明符合她更新后的意愿，不得继续当作本次误导证据。此前相反转述的历史仍在。
- **“再发一次 / 不是那个 / 我问的是她的钱。”** 有唯一最近引用时沿用，歧义时问清对象；不用每次重讲公司业务。不知道退出结果就说未收到，不编造一个到账日。
- **重复停名、问同一问题、重开已取消项。** 状态不翻转，不多发、不激怒计分；“行，我知道了”不触发授权。实质改口才追加一条更正，送达者才更新认识。
- **已转项目再取消。** 停的是后续；来件在取消送达前已经发出，就保留这一次及先后记录；取消先送达则不出现该来件。不用竞争时间惩罚读得慢的玩家。

## 本次取舍与验证边界

**删掉：**主管一句“讲下一期”就承担反转、反复索要退出入口的循环、第二次回复等于故意的推断，以及把所有拒绝路线写成同一结尾。P1—P6 六个容器不增加，旧线索不叠版本。

**保留的操作只有必要差异：**读页面发现动作不符；引用原话进行核实；从实际来件反查公司转述，或从外发查关联回复；阻止或更正决定后续真的停在哪里。没有抄写固定答案、议程表、完成标记或奖励分。只有罗青允许文字回复时才启动本案协作；新内容超出她准许的议题正是待核实的问题，无需主动制造客户损失。

证据分层：只有页面冲突时，误发成立；只有不实草稿时，是未执行的准备；主管读到限制后实际发出相反摘要，是可观察的转述失真；项目按摘要行动后，不能再用第一次误发解释整条链。仍未查明资金、境外地点或完整共谋，也未证明所有新玩家会觉得值得查。

[H001](../experiments/H001/game-design-hypothesis.json)继续记录整体可用性，暂停旧 A/B。待观察的是玩家会不会自发查“对方到底收到了什么”，并提出与公司作用有关的下一问题。**否决条件：**仍只做链接纠错；需罗青或主持者直接说出公司问题；只能喊“坏人”而说不清哪个动作改变了判断；或感觉只是在逐项转发工单。遇到这些情况继续删改或弃案，不用更长对白、境外地址或强制危机续章。
