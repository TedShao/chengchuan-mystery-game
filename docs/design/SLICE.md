# 网页片段：还有谁在听

状态：2026-10-20。本轮对 [992c0df](https://github.com/TedShao/chengchuan-mystery-game/tree/992c0dfd61248d30dd6c2973fd1e971638405f91) 做关闭指引的作者纸面反证，并直接删改。**局部图片调查可保留，撤图 / 撤约后进入公司调查的衔接未成立。** 未做真人盲测或网页运行，不声称片段已有十分钟乐趣；未改代码。事实见 [STORY](STORY.md)。

## 先记录哪里停止，而不是把想要的下一步写进路线

方法：不读作者犯罪底稿作为玩家证据；每步只用已经看到或实际收到的内容。每条路线独立重置。下列心理判断是作者提出的合理反例，不是玩家原话。旧稿把“自主打开预约 / 活动页”写进路线，本轮允许在此之前结束，不能将其算作漏玩。

| 路线 / 实际可用信息 | 按非预设顺序排演 | 停止点与反证 |
|---|---|---|
| 直接追问，跳过原件 | 看唐雯问题 → 问许蔓是谁、是否真实委托 → 她承认角色与配图 → 要求停用并向唐雯说明 → 唐雯取消 | 已知虚假营销且当事人退出，尚无理由必然去查 F27；不在下一格替玩家自动打开页面 |
| 提前阻止，暂不判断真伪 | 看到有人拿图担保 → 要求不要再用图答复 → 得到停用确认 → 唐雯选择先取消 → 此时再决定是否查图 | 暂停和撤约成功；原件依旧可看，但“还可以看”不是调查动机。允许未证实造假就结束 |
| 拒绝接班 / 不介入争论 | 不接角色也不审核 → 回答唐雯自己只能说明素材，不能保证资金 → 她自行取消 → 回桌面 | 旧稿没有新的业务矛盾；不能用失职评价、求救消息或后续损失把人拉回来 |
| 漏看群中原话 | 先近期文件 → 再 F27 → 只看到示例与合作推广 | 仍可理解为正常教学推广；询问图用途得到相容解释，不能凭后台角色先定罪 |
| 漏看原件 | 只看唐雯引用 → 直接问许蔓 → 问她是否有真实学员委托 | 回答已承认图从课件配来且无委托，不必再集齐原件才能要求停用；未看到具体数据时只主张缺乏真实凭证 |
| 先查接收方 | 先开课程页和预约 → 远汀、合作推广与接通交付已知 → 后查虚假图 → 撤图 / 撤约 | 后半段没有第二次揭示；“公司把人介绍给谁”已在开场回答，不能重包装成新发现 |
| 只告诉主管 | 发送具体矛盾 → 主管撤图并按未撤回许可继续接待 → 玩家准备结束 | 正常补救与未结束的服务足以解释；继续联系不是违规，不能当隐藏反派行动 |

**原稿判定：**局部调查成立；公司调查的持续动机缺少结构依据。没有证据证明真人一定无聊，也没有证据证明撤约后一定继续。原稿“正常广告解释不了虚构经历”的表述漏掉了仍然成立的“虚假营销”解释，已删除。

## 删改后的入口：回应一个人的疑问

背景两句足够：

> 你是林见，在澄川做课程内容，入职第 47 天。平时做回放和示意图，偶尔也帮知禾学堂的学员找资料。

前台是已有的课程服务会话。唐雯引用昨天的消息：

> “这张是钱到了，还是申请通过了？陈姐说很快。我约了今天的电话，还是有点不放心。”

引用能展开完整语境和图片。不是主管先要求核图、不是先选择岗位；玩家眼前的问题是“这张图能不能说明她担心的事”。不把这句话再做成任务提示。许蔓的聊天入口显示其社群岗位，近期文件可见普通标题“第 3 讲·到账状态示意”，不显示证据等级。

文档、表格、PPT、邮件、OA、浏览器和摸鱼仍可自由打开。离开主线不自动发生付款、坏结局或催办。普通工作不凭空产生线索。

## 四个材料位置，按需要读取

| 位置 | 玩家实际能看见什么 | 入口与边界 |
|---|---|---|
| M1 唐雯会话与她持有的昨日引用 | 陈姐“我这笔昨晚到账了”，图片，随后提及课后咨询；唐雯自己的疑虑与预约 | 首屏已有引用；群里之后撤图，不抹除唐雯已收到的副本；别人不自动获得副本 |
| M2 自己的 A17 原件 | “虚构数据，仅说明操作状态，不代表真实交易”；课程标题、制作者和普通裁切预览 | 近期文件、课程素材搜索；用“到账”“提现”“那张图”等合理语义找到同一内容，不要求记住编号；对外群页没有内部来源按钮 |
| M3 许蔓会话及实际发布状态 | 她的回答、昨日原帖和确实存在的未发回应；明确暂停后的确认 | 只核实这一角色；删除独立接班页与审批按钮。玩家无发送权时不能直接修改她的草稿 |
| M4 F27 课程 / 活动页与唐雯预约 | 接收方远汀咨询、投资咨询自述、合作方采购推广与按接通交付；唐雯预约的实际状态 | 开场即可访问；这是背景和操作出口，不是收集完成后奖励。号码遮蔽，只读本案，无全公司用户或资金后台 |

不把 M4 编成待提交的交付表。活动编号无需记忆；直接问接收方也能得到同样事实，不迫使玩家绕一圈网页取答案。境外登记不是罪证，课程推广不是犯罪证明。

## 对话与动作：不把合理表达变成附件验收

| 玩家表达与条件 | 人物回答示例 | 真实结果 |
|---|---|---|
| 问许蔓“陈姐是谁，你替她发的吗？” | “那个号我在用。没有陈姐这个学员。” | 归属明说；没有替用户发送、预约或追加判断 |
| 接着问“所以这钱根本没人取过？” | “这张图是我从课件配的，没人给我发到账凭证。” | 只回答她能支持的范围，不假装能证明整个项目没人取过钱 |
| 只问图是不是案例 | “是课里那张示意图。” | 未看公开语境仍可能正常教学；不额外解释骗局 |
| 说“先别拿这张图继续回她” | “行，后面这条先不发。” | 对实际操作者提出暂停；她确认后显示该项未发，不要求先证明犯罪 |
| 指出“你把示意说成自己到账，唐雯当真了” | “那条我撤。来源你可以跟她说。” | 许蔓按自己的已知事实处理，不强制玩家再附一遍她知道的原件。撤图不等于已通知唐雯 |
| 告诉唐雯这图是自己做的虚构示意，不是到账凭证 | “那我不能拿它当依据了。电话先取消吧。” | 能根据具体解释改主意；可索要原件留存，但不把附图当撤约门槛 |
| 只扔一张原图，没有可理解说明 | “你发的是群里那张的原图？” | 有歧义才澄清；若图片对照和上下文已经清楚，不机械重复问同一句 |
| 说“不接手，我不清楚资金的事” | 许蔓：“好，我自己回。你的名字不会挂上去。” | 只退出本人参与，不暗中取消客户许可；可再补“这图也别发”，两件事分别生效 |
| 向顾成问远汀是谁、公司做什么 | “这场是合作推广，咨询是远汀接。课程页有介绍。” | 正常问题直接回答；同样事实不再安排查合同、找人、回报三轮 |

上述是语义与状态例子，不是必须逐字复述的脚本。涉及暂停、更正、转发、公开或撤约的实际操作要明确对象和范围；只问问题不能触发它们。模糊时问缺少的对象，不把所有动作捆绑成一键“完成核查”。

许蔓把已收到的具体争议转给顾成，顾成才知道；如果玩家先找顾成，则由他通知许蔓。读了本地原件、写了私有草稿都不让同事自动知情。仅停未发内容不使主管无缘无故介入。

## 局部后果与有效结束

| 实际行动 | 留下什么后果 | 不能偷加什么 |
|---|---|---|
| 只停下一条 | 该条不发；昨天原帖仍按真实状态存在 | 不换号重发相同保证抵消暂停 |
| 只内部纠正并撤图 | 内部已知、公开图已撤；唐雯没收到来源则仍可能误解 | 不自动发学员感谢、不把未撤约咨询当违法继续 |
| 向唐雯说明来源 | 她知道图片不能作证；是否取消由她明确决定 | 不要求玩家陪她填完一套退订材料 |
| 唐雯明确取消 | 她自行取消，或在明确授权后由课程服务发起取消；确认原对象的状态 | 不恢复电话、不造资金损失、不以另一联系人重新联系 |
| 公开补充事实 | 正式服务身份下实际发送；顾成、许蔓在读到后处理；收件范围可回看 | 不转发唐雯私密预约资料，不让未读者全知 |
| 拒绝本次参与 | 无角色接班与代言责任；原有工作资料、服务会话仍可读 | 不用丢权限、愤怒分或绩效惩罚逼回主线 |
| 完全退出 | 关闭本案通知，继续自由办公或结束片段 | 不补匿名信、求救电话或强制下一任务 |

两条许可分开：玩家退出不等于客户撤约；客户撤约后，玩家改口也不能替她恢复。重复暂停 / 撤约不生成重复事件；改口收窄指控不删除既有发送记录。未查看原件者也可以帮客户取消，不把保护成功判成没玩明白。

## 撤图之后：删掉假悬念

若唐雯尚未取消，顾成按原约定接待不产生新的定罪信息；若已取消，联系停止。F27 页面仍可看，但没有新弹窗说“你发现公司真正的业务”。玩家已经先看过 M4，结尾也不会把同一事实再演成反转。

可自选的事只有当前真正存在的内容：问接收方、自行看服务介绍、核实图片用途、补充已发生错误的说明，或离开。**不把这些可选动作列成新的待办，更不把它们存在当作后半段成立。** 当前没有可验证的接收方额外矛盾；不要由主持人替玩家提出“它是不是境外诈骗公司”。

同意继续看页面的纸面玩家，应记录其原因和新判断；只因担心题材中的公司必然犯罪而继续，与材料本身驱动调查分别记录。调查应能被停止，不用绕开取消结果来维持悬念。

## 修订后用相同路线复查

| 路线 | 修订改善 | 仍未解决 |
|---|---|---|
| 直接追问 | 两个具体问题即可知道角色与凭证来源；不强制看齐原件 | 撤约后仍可合理结束，公司调查没有新证据 |
| 提前阻止 | 无须接受角色、核完图才可请求暂停；有实际确认 | 不把过去仍有资料误称为强续查动力 |
| 拒绝参与 | 没有交接审核门槛；可以说明自己不知道，继续正常办公 | 真正拒绝所有参与时允许结束，无主线必达保证 |
| 漏看群语境 | 暂留正常教学判断；需要时沿已有引用查看 | 不能凭原件或外国主体迫使定罪 |
| 漏看原件 | 用已知来源和明确回答也可指出凭据不足，取消不被卡住 | 若要断言所有数据虚构，应看原件或明确来源说明，不能越界 |
| 先查 M4 | 接收方当场回答，不再结尾重复揭示 | 这一反路线最清楚暴露后半段缺少新问题 |
| 误判后改口 / 重复操作 | 收窄为“这张不能证明到账”；不恢复许可、不重发 | 仅说明行为一致，不算公司悬疑通过 |

本轮实删：素材审核式开场、独立角色接班页、附件齐全才承认事实的潜在门槛、撤图后自动查 F27 的任务串、将正常履约当犯罪升级。保留自由办公、局部核实和有效停止。**R02 的公司调查衔接重新打开；R03 不能再以完整十分钟悬疑已就绪为前提。** 尚未构思新的业务矛盾，也未取得真人乐趣结果。阶段只读 [PLAN](../PLAN.md)，问题记录同步 [H001](../experiments/H001/game-design-hypothesis.json)。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
