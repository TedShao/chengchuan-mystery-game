# 网页片段：还有谁在听

状态：2026-10-20。当前为新核心事件的纸面候选，替换罗青和双身份流程；两案比较与作者真相见 [STORY](STORY.md)。目标是一个约十分钟的调查片段，未计时、未实现、未取得真人盲测。关闭指引也可操作；本稿不是新版网页已上线的声明。

## 首屏：先给一件正在发生的事

不以开场选择工作内容、长篇公司说明或强制教学开始。桌面只用两句交代：

> 你是林见，入职第 47 天。平时剪课程回放、做示意图，偶尔替学员找资料。今天许蔓临时请你看一下课后讨论的素材。

前台是公司聊天，普通未读提醒，不闪烁答案。许蔓发来：

> “我接个电话。陈姐那条先挂着，你看过图再说。别直接发。”

消息里有“查看待发内容”，旁边是本场讨论入口。当前发送身份、收件范围与未发送状态始终可见；打开不等于接班或发送。唐雯已有一条课程服务消息：

> “林老师，这张是钱已经到了，还是只申请了？陈姐说很快，我约了今天的电话，还是想先问清楚。”

玩家第一步可以开引用、看待发、问许蔓、看自己的近期文件，或先去摸鱼。唐雯叫“老师”是服务习惯，顶栏仍写“课程助教·林见”；不把主角写成投资老师。

桌面中的文档、表格、PPT、邮件、OA 和摸鱼入口仍可自由访问，本片段不要求使用全部软件。没有剧情用途的办公操作正常结束，不凭空生成线索，也不催玩家回到主线。

M5 不叫“犯罪合同”，不写抽成赃款，不含未完成章节。预约详情显示真实状态与接待方，只查本案。链接的页面标题、项目号 F27 和服务主体相互一致；不能用相似公司名、外国服务器或时差直接推骗局。

预约状态沿唐雯已有的课程求助关联，仅开放本次课程服务所需信息，个人号码默认遮蔽。退出角色接班不撤掉原有内容资料权限；玩家也不会因此取得全站用户后台。

## 场面与实际玩法

### 场一：这图我见过，但它不该证明这件事

玩家从 M1 可先判断只是普通分享，从 M2 可先判断是教学材料。二者并排才产生具体矛盾：同一张虚构图被当成个人到账证明。M3 的运营角色只是辅助归属信息，不能单独证明造假。没有点选“骗局”的答题面板。

**表达判断的方法：**引用一段消息、附上相关图片或选定原件片段，选择收件人并补一句自由文字；也可直接发普通聊天。引用不是门票，只是减少歧义。规则识别对象、主张、否定与动作意图，不要求关键词或整套证据：问是谁说的、停这条、问图片用途各自回应；复杂自由表达不能确定时，人物只澄清一次“你要我停待发这条，还是给唐雯补说明？”，不偷偷执行二者。

### 场二：直接问，不能把解释藏进长问答

| 已知与追问 | 对方可说的话 | 真正发生什么 / 还不能知道什么 |
|---|---|---|
| 只问许蔓“陈姐是谁，是你发的吗？” | “这个角色我在用。你先核图，不用替她说话。” | 知道运营归属；没有因此证明图片虚构、全群造假；问题本身不触发发布 |
| 指出 A17 是示意，尚未引用公开亲历表述 | “我用的就是课里的例子。” | 解释与已见材料兼容；玩家可选择去看公开语境，也可到此保留判断 |
| 追问“是哪个学员让你代发的，她真的取过吗？” | “没有陈姐这个学员。号是我们值班用的，图是我从课件里配的。” | 排除真实陈姓学员授权代述；她把这合理化为案例互动，不另造一个无法接触的委托人来拖延 |
| 同时引用原件和“我这笔到账” | “这句是我发的。图我撤，今天这条也先不发了。” | 撤下自己发的图、取消该条待发；不靠五轮狡辩拖延，不虚构真实学员授权 |
| 追问“那她知道你在举例吗？” | 许蔓：“没跟她单独说过。你发来源就发原图，别把她的预约信息发群里。” | 承认这一事实；保护他人信息是具体限制，不作为阻止更正的借口 |
| 向唐雯问“你以为陈姐是真的取过钱？” | “不然我问她干什么。我还没转，就是怕进得去出不来。” | 知道她的理解与未付款状态；她不知道角色后台，不替玩家总结公司模式 |
| 只向顾成问公司为何做免费课 | “合作活动。课程页下面有咨询方，活动说明你能看。” | 正常解释和正常页面都给得出；境外和免费都不等于犯罪 |

如果玩家先查 M5 再问人，人物承接已发送的具体引用；如果只在本地读过，人物不会自动知道。内容岗权限无需靠接受陈姐角色解锁。

顾成的接手有实际传递路径：许蔓收到明确的来源矛盾后，把相关已发送引用交给主管处理；若玩家先私信顾成，他实际读到后才通知许蔓停用 A17。转交项与通知可在本案看到，不包含玩家未发草稿或额外泄露唐雯隐私。仅停一条待发内容不会触发全公司知情。

### 场三：做一个能改变别人处境的决定

这里没有“提交推理”按钮，玩家的决定落在原对象上。

| 操作 | 立即可见的结果 | 顾成 / 许蔓 / 唐雯的后续 |
|---|---|---|
| 停止 M3，尚未纠正昨天 | 待发项“已取消，未发送”；原图与预约仍按实际状态存在 | 许蔓接回素材；唐雯若没收到来源，仍可能相信昨天的经历。不是新生成一条同样保证来抵消玩家 |
| 以本人身份把原件与简短事实发给唐雯 | 她收到的内容和发送范围可回看 | 她确认“那这张不能说明她取到钱了”；询问是否还要咨询。给足具体来源后，她可撤销预约；只有谩骂则会要求依据，不因此多投钱 |
| 在课程群补充来源说明 | 已发送的事实说明留在群内，只有当时可见的收件范围有机会读到 | 顾成暂停本场后续案例图，由正式客服接问题，许蔓撤原图；不会继续用陈姐同样推介。没有收到的其他群不凭空响应 |
| 只私下向主管提出异议，未通知唐雯 | 顾成实际读到成对材料后停用此图、接管本场 | 他保留唐雯原约定并改由接待方直接回答投资问题。玩家能看到该预约负责人变化；唐雯没有读到私人争论，不能说“谢谢你揭穿” |
| 拒接角色，但保留课程服务 | 显示“未接班”；角色写权限不授予；已有内容工作仍可读 | 许蔓接回角色。本片段不要求她为惩罚玩家而继续发保证；唐雯既有提问和自己的素材用途仍可查 |
| 完全退出本次事件 | 交还、关闭本案通知；可以继续办公或结束体验 | 不追发匿名求救、不绑架、不塞必做任务。不得宣称已救下唐雯或取消全部联系 |

唐雯在收到清楚的出处与说明后，优先选择取消本次电话，自己在预约页确认；她也可以先只问服务方，不需要玩家教她做每一步。提供给试玩者的场景响应固定这一有依据的倾向，不随机决定她听不听。仅发原图、没有说明关联时她会问“这和群里那张是一张吗”，不让收件附件自动变成全部知识。

**拒发、纠正、撤约是三件事。** 玩家有权停自己待核对的消息，有权用本人服务身份纠正素材，没有权替客户同意资金操作。顾成可以交接尚有许可的咨询，不能在唐雯明确撤约后再替她恢复。若只拒接而未要求停发、未指出问题，原负责人可以在明确交回后发布原待发项；该分支必须显示实际操作者与发送，不因阅读页面或真实时间流逝偷偷发生。玩家随时可在交回预览中选择“这条不要发”。

### 场四：撤图以后，公司在保什么

顾成已收到具体异议时的短回应：

> “图撤了，这条也别再用。她那边如果还约电话，我来接。别替她答资金的事。”

这句话不直接揭底，也不证明后续一定犯罪。玩家可沿**已经存在的预约入口**看接待方，或在本项目活动说明里看交付项。若唐雯取消，预约变为已取消、接通未完成，仍保留服务方和所属活动；不需要让电话接通才能得到关键事实。若她未取消，接待方按原范围继续，不自动发投资成功或损失结局。

可形成的新判断是：这次活动以课程取得信任、以“同学的经历”消除对取款的疑虑，最后把咨询交给另一个主体。正常广告合作能解释免费课，**不能解释虚构的亲历凭据为何被用于说服真实学员相信资金安全**。

下一调查出口仍在当前网页内：看 F27 的服务介绍和责任范围，或查 A17 的本活动使用位置。玩家可立即打开，不是“第二章解锁任务”。页内只给真实已设计的信息：对方自称提供投资咨询，课程不承担交易执行，本项目购买咨询接通；投资平台的实际交易、实际所在地、其他素材全公司用途尚未查明，不生成结论报告或无内容假链接。

停止后仍有疑问是本稿的待证假设，不是强迫玩家继续的理由。若真人认为这就是一次可结束的虚假营销，照实记录，不能把“接下来查境外”作为旁白提示塞给他。

## 非预设顺序纸面排演

以下为作者检查，不是完全无知识的新玩家数据；每路只使用当路实际看到的信息。每次读页、询问、发送分开计，不用隐含全知解释分支。

| 路线与顺序 | 形成 / 保留的判断 | 后果与继续条件 | 反证风险 |
|---|---|---|---|
| 直接问：先 M3 问许蔓 → 原件 → 唐雯引用 → 自主打开预约 | 运营角色正常；虚构经历向真人作证才异常 | 可立即拒发；公开语境与预约独立存在，不必陪她狡辩 | 若玩家听到角色就下完整骗局结论，不能算推理成功 |
| 提前阻止：不读旧图就停 M3 → M4 → M2 → M1 → M5 | 下一条没发；昨天的信任不靠新失误才存在 | 停发有效，唐雯可取消；取消后仍可查本活动接收方 | 若所有材料只为追究一次错图，调查动力仍失败，不拿完成路线掩盖 |
| 拒绝角色：交还并注明不要发 → 自己文件 → 唐雯服务会话 → 活动页 | 无需冒充或接班也能核实已有用途 | 保留内容岗位与课程服务权限；彻底退出可结束 | 不以“必须接受角色才能看原件”卡玩家 |
| 先看用途：M5 → M2 → 认为普通推广 → 只问顾成 | 当前只是合法合作与示例素材 | 没见公开冒充就允许普通判断；回 M1 可修正，不发惩罚邮件逼补课 | 不把合作收费作为犯罪证据 |
| 误判全群是假人 → 向唐雯直接指控 → 补原件和实际原话 → 收回过度指控 | 只能核实陈姐，不知其他人；承认范围并不撤回事实 | 唐雯要具体依据；得到关联后可取消，不因为玩家道歉恢复预约 | 不设隐藏怒气，也不以无依据指控换取内幕 |
| 只通知主管 → 停图后准备结束 → 看预约接手变化 | 公司停止此种素材但仍维护原有咨询 | 玩家可追查为什么要交付咨询；唐雯没看到纠正则不会突然改变看法 | 若这一变化被读成合理客服接手，须依靠已可读的用途关系，而不是继续新增坏行为 |
| 不看素材，只帮唐雯取消电话后离开 | 没证明图片虚假，但完成她的明确意愿 | 真正取消；不强行揭晓、不给“坏结局” | 这一结束不是卡点，也不计入主线动机通过率 |

### 改口、重复与权限的硬边界

- “不是说你们全是假的，是这张图不能证明到账”只收窄指控；不重发取消项，不恢复角色接班。
- “还是接电话，但我不投钱”须由唐雯明确重新许可；记录为一次新预约，范围仍仅咨询。玩家自己的改口不能替她决定。
- 公开更正后再私下改口，不能删除已经发出的消息；更正对象和可见范围明确显示。移除不实指控不撤回有依据的图片来源。
- 同时问身份与资金保障，分别回答自己知道的内容；任何人不得因收到两个问题就自动安排电话。
- 重复停发、重复打开素材或取消项均不新增事件。相同问题引用已答内容，有新限定才补充；无机械惩罚、无重复感谢。
- 许蔓接到明确停发后不能换角色重发同一保证。顾成未收到私聊不知情；公开群消息也要实际可见并查阅后才纳入他的回应。
- 公开图片撤下后，未读者只见撤回状态；不凭空获得其全文。唐雯开场已持有引用副本，M2 原件属于玩家工作资料，不因撤图消失；普通素材引用记录不等于可访问所有已删私聊。

## 这轮排演后直接删掉的设计

1. 删除“内部演练意外混入真人”。它要求主管骗新员工且又暴露整套操作，开场还容易停在环境配错；正式课程与虚构案例已经能形成矛盾。
2. 删除“整群只有一个真人”的既定惊悚结论。当前权限只能核实一个运营角色，不用不可证明的总人数冒充反转。
3. 删除故意发一条假的取款保证来验证反应的操作。过去的发言已经存在，玩家用事实更正或正常追问检验，不需制造新误导。
4. 删除查完所有文件才开放 F27，以及暂停后强制接通电话。入口开场即有，客户撤约有效，调查不靠损害继续发生。

本轮 G1/G2 为作者层面可排演：事实链、两条非线性路径、具体后果已写清。**G3 未通过，仍缺真人兴趣与理解证据。** 最弱假设是识破虚构经历后，玩家会主动看是谁购买咨询，而非只想撤图；后续验证只检验此点，不扩章。对应 [H001](../experiments/H001/game-design-hypothesis.json)，阶段状态只读 [PLAN](../PLAN.md)。
