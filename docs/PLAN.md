唯一任务与状态入口，2026-10-21。文本清理已完成；本轮按读者视角修订整条因果链，不以文档齐全宣称体验成立。

## 已落地的文本范围

- 用户确认公司方向、境外诈骗与受控真相、主角被骗出境的结局尺度。
- STORY 修正职业动机、个人求职与早期分流；开场改核实工作承诺，补赵返国与求助、双方信息互补及两名管理者各自的知情链。
- SLICE 补齐开场可见材料、八场行动与反馈、十五条基础路线、九条补充因果反路线及六条待遇与返程检查、陌生玩家测试方法。
- STORY 明确海外岗位的固定底薪、每月驻岗补贴、浮动绩效与长假；SLICE 同步旧聊天、陈平面试问题和家属动机。数额只有 STORY 一处定义，场景转述须一致；这些是虚构招聘承诺，不是工资行情。
- INTERACTION 补齐动态操作教学、软件职责、判断表达、收件边界、暂停/退出/改口、重复操作、存档和无障碍要求。
- 清除旧设计、研究、实验、试玩文本与历史稿导航。保留程序本体，不把任何旧剧情当新稿依据。
- 更新 GitHub 文档分支与既有草稿 PR。提交结果以 GitHub 分支为准；这里不把准备提交写成已发布游戏。

## 当前最重要的一张任务卡

**问题：**具体收入、食宿与连续长假能否解释林见和陈平为何心动，同时保留“普通客服为何开出这么多”的合理疑问？陈平从计划探亲转为要求结束工作后，玩家能否分清福利条件与自由离开，而非只处理一张请假单？

**范围：**先读 STORY 完整因果链，再分开排演 SLICE A–D 与较早分流的个人求职旁支；不让已知真相的读者假扮不知道，也不展开代码。

**观察：**梗概评阅记录每处“为什么非得这样做”的质疑；陌生玩家纸面排演另行进行，不提供梗概。分别记录当步所知、采取行动和理由，不由主持人建议方向。

**否决：**主角读到具体受控经历仍被写成无知出发；未申请就被派走；返国证人只能靠卖关子留悬念；一般投诉或心理变化冒充关键反证；高薪自动等于犯罪、休假未达条件自动等于被控制，或咨询补贴自动报名。仍像逐项办公时，回场景动机修订。

**下一动作：**收集对修订因果链的读者意见；之后另找未读梗概者从实际开场排演。两类证据分开，当前不填写真人留存、用时或通过率。
