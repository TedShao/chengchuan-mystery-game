# 故事规范：替你说的话

状态：2026-10-21。复查 [4b9353a](https://github.com/TedShao/chengchuan-mystery-game/tree/4b9353aa1fb37ae9c5fa8e957ce1cd552642b6bf) 后删改。保留局部冒充事件与可疑服务安排，撤回“已接上远汀调查”的判断；孟宁不再按玩家说话时序选择是否继续确认不实资格。完整反路线与修订分场见 [SLICE](SLICE.md)，本轮不改代码。

## 当前保留的故事

林见失业三个月后进澄川做课程服务，第 47 天接到沈航复访。昨晚代班的顾成用林见的席位“小林”自称不在澄川工作，并讲述参与远汀的经历。沈航曾明确询问雇佣关系，顾成的否认与已知事实冲突；获利经历本身是真是假尚不确定。

林见可以实际更正、停代发，沈航可以取消预约。预约详情关联林见自己的出席安排：被推荐的远汀付费购买交流，员工被列入“非澄川、远汀工作人员”的交流介绍。这可以把问题从一个人的发言带到公司的服务安排，不能仅凭付款方推出资金诈骗。

只撤本人、没有指出资格矛盾时，孟宁正常安排顾成替补。玩家若具体指出该场员工身份与介绍冲突，她核实后暂停这项安排；不论先撤人还是先询问，行为依据相同。暂停、撤人、更正都可以解决眼前诉求，不需要继续发生一件坏事。

**本段尚缺持续的远汀调查。** “远汀为什么付钱买独立推荐”可以由“为了获客”解释；玩家知道公司做失实营销，并不因此自然得到新的可检验问题。原稿关于顾成获利的说法也只能构成未核实信息，不能自动改成新的资金骗局证据。本轮不添新受害者、秘密文件或公司联系人自白。

## 公司与人物处境

澄川真实承接知禾课程服务，同时为远汀提供项目交流。林见此前主要接触通知、资料和排课，有理由不熟悉项目组的对外角色包装。远汀是商业客户，沈航是学员；学员不付这笔交流服务费。**远汀具体业务与承诺仍未写到足以设计下一场行动的程度**，不拿一个模糊“项目”假装完成公司背景。

孟宁负责项目交付，有排班与客户确认权限，知道顾成的雇佣关系，但原稿未给出她何时看过当前学员介绍或是否起草过它的事实。她的职位不能代替具体知情。受到针对本场资格的明确异议后，她会暂停处理：既可能是纠错，也可能是避免问题扩大；不替任一种解释提前定案。

林见能看自己的出席安排、对应学员介绍和本次交接状态；不能浏览秘密合同库。退出本人会一次撤掉自己的后续出席及头像。整单暂停是向孟宁提出请求，由她实际执行，不是新员工掌握全公司停业权限。

### 表一：事实与时间

| 顺序 | 固定事实 / 条件 | 原因与后果 |
|---|---|---|
| 昨日下班 | 林见离开，开启正常组内代班 | 昵称与代班本身合法合理，不作罪证 |
| 昨晚 | 顾成针对沈航关系询问，明确否认在公司工作 | 留住想找独立亲历者的咨询；实际原文与操作者可查 |
| 今日复访 | 沈航找昨晚的人，林见接回自己的席位 | 熟悉头像下出现自己没说的话，产生个人冲突 |
| 实际更正与停止 | 对方只知道收到的更正；取消和停止分别生效 | 沈航可离开，不追问已回答的问题 |
| 查看关联安排 | 远汀购买交流，员工排班与非员工介绍相连 | 可疑，但原稿未明确介绍由谁制定、孟宁何时读过 |
| 只撤自己，未给具体异议 | 林见与头像移除，孟宁可安排顾成 | 普通替班仍可解释；不自动判定她知情继续欺骗 |
| 具体指出资格冲突，或请求本单暂停 | 孟宁查看并暂停本单的新增安排 | 不按先后顺序决定继续还是暂停；个人退出同时落实 |
| 后来明确接受员工咨询 | 撤不实资格，同单改员工答疑，送客户确认 | 未确认前不开放；不恢复沈航已取消预约或本席代发 |

### 表二：认知与需求

| 人物 | 知道什么 / 不知道什么 | 需要与行动 |
|---|---|---|
| 林见 | 自己和顾成是员工；不默认知道对外介绍、买方全部业务 | 想避免替别人背书，可问、退出或阻止；不被作者要求关心所有后续 |
| 沈航 | 自己收过的对话；未更正前不知道背后员工 | 想听亲历；更正后可以取消，不能替玩家发现公司交易 |
| 顾成 | 自己发过的否认；不知未发草稿 | 可承认与更正；不安排第二次自白揭露买方 |
| 孟宁 | 同组成员、业务关系及实际看到的本单内容 | 想保交付，也不愿具体资格异议继续挂在本单；被指出后暂停，不抹历史 |
| 远汀 | 原稿只固定其是委托客户，未固定具体人员实际读过什么 | 不能从“发到了客户账户”推定全体买方知道员工在装独立 |

### 表三：线索与判断限度

| 对象 | 初读解释 | 可重新判断到哪里 |
|---|---|---|
| 小林头像与顾成操作者 | 正常代班 | 明确雇佣关系否认才支持有意伪装，头像本身不够 |
| 远汀委托的出席安排 | 普通外包服务 | 知道谁买这段交流时间，不知道资金与境外去向 |
| 员工与非员工资格并列 | 配置错、描述错或故意包装 | 足以指出具体问题；缺谁实际知情批准的事实 |
| 退出后的顾成替补 | 普通调度 | 仍应核实资格，但不能自动推出公司故意经营欺骗 |
| 孟宁暂停 | 正常纠错或及时止损 | 阻止结果是真的；不抹掉旧问题，也不替她证明清白 |

### 表四：动机、权限与解释比较

| 解释 | 与当前事实的关系 | 不能偷加的前提 |
|---|---|---|
| 顾成个人撒谎 | 原问答直接支持 | 不等于公司命令或远汀共谋 |
| 公司服务配置有错、孟宁此前未留意介绍 | 与当前安排及收到异议后暂停相容 | 不能因其职位自动推定逐字审过所有内容 |
| 孟宁也参与包装、暂停是止损 | 与同一结果也相容，值得怀疑 | 不能为排除此竞争解释，强迫她在投诉者眼前继续确认 |
| 远汀购买营销转化 | 可解释购买独立式推荐的利益 | 这说明营销动机，不证明具体人员知情或更深犯罪 |
| 公司经营更深骗局 / 涉境外链条 | 原稿没有可区分的业务事实或行动结果 | 外国名字、时区、服务状态和未核实获利话不能替代 |

“负责人明知员工身份且仍正式确认不实资格”仍是一条有效的责任判断标准。但本轮删掉为满足该标准而编排的时序分支，**不再宣称新稿已让玩家获得这个事实**。不降低事实门槛，也不要求玩家说指定话来制造它。

### 表五：场面与节奏

| 场面 | 确实带来的变化 | 删除的负担 / 未解问题 |
|---|---|---|
| 复访与原话 | 身份被借用与实际撒谎 | 不让人物复述完整推理 |
| 更正和退出 | 沈航与林见均可脱离安排 | 不以新增求救阻止结束 |
| 预约关联服务 | 个人事件连接到公司的对外介绍 | 从已有预约直达，不另发日历任务 |
| 直接问孟宁 | 已知业务直接回答，具体异议实际处理 | 删“你知道他是员工吗”的证明步骤及重贴材料门槛 |
| 暂停或员工咨询 | 真实改变后续安排 | 是局部收尾，不能将审批完成包装成新谜底 |
| 向远汀核实 | 目前只有可选方向，没有完整事件 | 不声称已设计出可试玩的下一场 |

### 表六：复查结论

| 项目 | 结果 |
|---|---|
| 局部公平推理 | 可识别顾成这一次关系伪装，不依赖先看作者答案 |
| 公司层判断 | 服务安排可疑；具体知情与责任仍未全部区分，不能沿用被删分支的强结论 |
| 关闭指引后的继续动机 | 可以合理止步“营销造假已阻止”；原稿未提供使此解释不足的新事实 |
| 直接问、暂停、撤人 | 分别允许了解、阻止、退出；不以同一信息不同先后制造罪证 |
| 操作负担 | 去掉专用交接推进、玩家端确认版本取证；保留普通网页显示真实结果 |
| 阶段 | 局部可观察理解；完整后半回 R01/R02，不将已知缺口推给真人测试 |
