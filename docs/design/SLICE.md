# 网页片段：这单是我下的

状态：2026-10-21。基于 [f882ebf](https://github.com/TedShao/chengchuan-mystery-game/tree/f882ebf39015953e5ebf991abd86bcc7a77e5080)，重写撤回后的公司调查。先排演旧单重生与同源知情改写两种后半，采用后者，再以非预设路线回走。以下均为**作者纸面验证，不是真人盲测或网页实玩**。未改代码、未新增事故。业务与六表见 [STORY](STORY.md)。

## 这次玩家要验证什么

不是“他们肯不肯免掉那笔钱”，而是“知道这只是我的演示后，项目方究竟把它当什么交给沈航”。旧单可以干净结束。后半只发生在现有商户、同一份源内容、同一条补发交付中，不加另一受害人，不要求真实付款。

最短可辨别的链条：**源明示未付款 → 真实教学用途已送达 → 对方实际改回正式店铺并去掉演示性质 → 孟宁知情认可 → 玩家阻止或明确放行。** 这是作者核对条件，不在游戏里显示成任务清单。

## 可见对象和权限

| 对象 | 何时可见 / 能做什么 |
|---|---|
| 课程聊天、普通桌面、音乐等 | 开场可用。沈航、孟宁是既有人物；自由办公不是任务奖励 |
| 昨日台灯样单 | 自己的记录、未付款性质、买家会话、撤回。不是全平台后台 |
| 沈航店铺本单 | 他分享的只读订单；正式角色和采购要求。沈航控制自己的账号与付款 |
| 本次共同交付页 | 接受孟宁纠错邀请后可见；只看自己的源、目标和当前完整收件预览。可发用途限制、撤内容使用、确认发送；无银行、管理系统或他人客户权限 |

取消旧单与撤掉采购项可以真实成功；它们不以接受邀请为条件。共同页的正式消息发送需要林见明确确认，这是本次为避免再串错约定的发送权限；远汀可以编辑、孟宁可以认可，但不能偷按玩家确认。该约定在邀请时说清，不是临时给的万能刹车。

## 一：先保留能靠普通操作遇到的异常

周二上午。短背景只交代林见做课程运营，沈航上过他的课、昨晚开店。桌面有昨日台灯演示：林见、16:40、未付款、不发货、备注“周五送到，放前台”。可看可不看，不要求记住没玩过的昨天。

沈航：

> “买家写周五要，页面又写五到七天。我能答应他吗？”

可以让他问买家能否晚点、问平台交期、承认不知道或不接。若实际请他问买家，他从订单发出询问，进入林见自己的演示收件箱。也可由林见先从自己的订单联系卖家。只在读到实际消息时获得相应信息，不自动告诉玩家这说明骗局。

看到来源后可说明身份、撤回或直接问远汀。尚未说出身份时，沈航不知道买家是林见；只看相似备注时保留模板解释。

## 二：这笔真的撤干净

林见撤回自己的样单；沈航看到买家取消。远汀按本单纠错撤采购项，不设关店锁、不要求先付。沈航收到来源说明后说：

> “那就好，我还没付。刚才差点以为真有人买了。”

没收到来源时只说“采购那项没了”。不把有条件对白全播一次。玩家可在这里结束，游戏不惩罚。

只有仍允许处理本人既有交付、尚未拒绝一切联系时，孟宁发来工作层面的邀请：

> “旧的已经作废。补发那份你看一眼收件端，这次别再串了。你没确认，他们先不发。”

“补发”指修正首单展示的交付，不表示玩家已经购买或同意新交易。只有进入页面才看见具体对象，不用这句对白泄露谁在造假。若玩家早已说“也别用我的内容补发”，则没有邀请转待办、没有另起订单；孟宁确认撤下这份内容即可。

## 三：交付给谁，不是一行无关的地址

接受后，页面只有一份源和两个正常收件视图：课堂演示、沈航店铺。源有“课堂演示／未付款／不发货”；完整商户收件视图包括平台页眉、订单性质和采购区，不靠故意裁掉提示制造嫌疑。初始候选可含“买家已付款”，但**初稿不是罪证**。

玩家不必重新写文档或创建第二笔交易。可以：

- 将已有内容限定“课堂演示”，保留未付款说明并发给本次两名操作者；
- 用原聊天明确这份没有买家付款，要求只作教学，页面采用同一限制；
- 撤回本次内容使用、拒绝发送；
- 向沈航说明或分享自己有权分享的本次内容；
- 只问“发到沈航店里是给他练习，还是让他采购？”不先作指控。

前两项都不是抄固定答案。限定只发给谁，谁才知道；草稿未发则没有知情反应。界面展示“已送给孟宁、远汀项目席”及其真实回应，不用神秘已读勾假定他们理解全部案情。

远汀对教学限定先回应一条具体话，例如：

> “这份是演示、没有付款，收到。”

这只是确认来源，不是承认全案，也不能单独判罪。接下来要看他实际怎么处理。

## 四：真正的反证是一次有对象的回改

在玩家没有公开指控或叫停、仍允许讨论这次交付时，远汀项目席实际保存新版本：目标从课堂改回**沈航正式店铺**；原有“演示、未付款”被删，收件内容变为**买家已付款，待商户采购**。版本只显示本次用户参与的改动和操作者，不能当全平台秘密日志。

孟宁在已收到教学限定、且看到这份完整收件预览后，实际认可这版：

> “店里用这一版。课堂那份你留着。”

她这时把它当作内部包装分工，不是长篇坦白。该句不承担全部证明：源性质、对方收到的限制、实际改动、正式接收对象缺一，仍不能自动授予结论。若只把说明发给项目席，孟宁尚不知情，就不能用同一句认可证明她明知。

**玩家没有发出前，这只是知情虚假交付的企图。** 不需要让它先害到人才能继续。可直接撤掉内容使用，回复“那就不发”，或把源与对外版本交给沈航看。共同页反馈明确写“发送已取消／该内容不可用于本次交付”；旧单不恢复，也不自动换一个人继续完成同一坏事。

若玩家选择发出，必须显示明确接收对象和完整正文，再确认一次；不把保存、阅览、认可原教学版当发送。沈航的正式订单页出现与所发版本一致的采购要求，他未付款。后续原样解释和取消新交付可止步，已送达事实保留。发送不同版本必须给不同结果：保留教学说明的版本只能作为教学内容送达，不能静默变成采购单。

## 五：直接追问不会逼坏人表演

| 实际输入 / 行动 | 人物反应与后果 | 能判断到哪里 |
|---|---|---|
| 直接问远汀“你们拿这份演示给谁看？” | 可以直接定位自己的交付，并看目标与完整预览，不要求先找孟宁聊一圈 | 初始预览仍可出错；看到知情回改才进一步判断 |
| 明确指出无付款，要求保持教学性质 | 只要送达并被处理，之后的回改按真实知情计算 | 不强制修改页面才能表达同一意思 |
| 一开始公开指控造假、加入沈航或明确撤用 | 两方停止未发交付，对接收回负责人，不继续为玩家表演作案 | 若尚未回改，仅有疑点；若已经发生，已有行为保留。早停不是失败 |
| 问孟宁“为什么演示要写已付款？” | 她可称“商户展示”，也可让人先停；不自动自白 | 解释不代替动作；若真停止或保留演示标签，不能仍判本次知情造假 |
| 拒绝制作新内容，但愿看昨天那份交给谁 | 不新建样单，可接收既有交付的查看邀请 | 核实不等于接受新工作，不能隐含恢复制作 |
| 只撤本人、未撤既有内容使用 | 本人不工作；共享的既有内容仍可能留为候选，不能冒充已送达 | 告知本人两个范围；若措辞是“别用我的东西”，按广义撤用，不钻字眼 |
| 改口只同意教学发送 | 正式采购发送仍停止；教学版本可送，收件方看到模拟性质 | 不因“同意”一词重新授权造单 |
| 不再回复 | 待发停在待发，无倒计时、无自动提交 | 不补一次新事故维持剧情 |

## 六：收尾不是采购待办

- **已知情回改、玩家阻止：**本次虚假交付没发生；玩家已经知道项目方如何对待明确未付款的工作产出。可告诉沈航，也可保留已见内容后退出。
- **教学版本实际送达：**沈航看到的是练习，不采购；若曾发生知情回改，该历史不因当前纠正被抹掉。若从未发生，则只是纠正成功。
- **正式版本明确送达后改口：**沈航知道自己刚被当作真实买家的假首单接收人，可以暂停并要求撤该项；不需要转账、受损或报警结案才收尾。
- **先停、拒绝全部或只读一边：**允许有限结束。没有行为发生，就没有最强证据，不伪称每条路线都完成公司调查。

自愿继续的入口是**自己的既有交付列表**：角色想确认过去交出去的东西去了哪里。这个入口从工作台原本就存在；本段不新塞记录答案，不要求翻全公司文件。下一阶段若采用它，必须另设计可核实的事件，不凭“还有列表”宣布续查动机已验证。

## 先排演，再落稿：本轮纸面结果

| 非预设路径 | 行动结果 / 修正 |
|---|---|
| 先撤样单 → 看到采购消失 → 不理补发 | 能正常结束；删除“撤完必须再查”的保证，下一邀请不强制接 |
| 直接问远汀用途 → 限定教学 → 看实际回改 | 可以跳过开场顺序；性质与目标都送达后，人工回改有区分力，不等收费客服 |
| 先看补发预览 → 立刻认为诈骗 | 初稿可能错，不授予强结论；先停即可，不强迫冒险补证明 |
| 不改任何字段 → 聊天说只用于教学 → 对方改正式版 | 普通语言也有效，不把会点编辑器当推理能力 |
| 明确撤用 → 对方仍偷偷发 | 此候选被否决；必须有效停止，不靠追加事故救剧情 |
| 公开问孟宁是否造假 → 她收回交付 | 不为证据强令继续；既往看到多少就保留多少，合法退出不是坏结局 |
| 只给项目席发说明 → 孟宁认可 | 只证明项目席的知情回改；孟宁认知未齐，不擅自连坐 |
| 拒绝新制作 → 想看旧内容去向 | 可查看同一内容，不造新订单、不重开已撤旧单 |
| 私下改了源但未送出 → 对方仍用原版 | 不算知情无视；反馈“仅你可见”，不能靠后台记忆补罪证 |
| 同意教学 → 后改成拒绝 → 再允许教学 | 以最后明确范围控制未发行为；已送达另行更正，不抹历史、不恢复采购 |
| 重复停止 / 重复问已付款含义 | 返回原状态与已知答复，不生成第二次回改、第二笔采购或固定训斥 |
| 公司真保留教学性质或停止 | 不论题材如何都不判本次有意制造；这是反事实校验，不伪称已经实现一条正常公司游戏分支 |

**采用理由：**收费可彻底撤掉，仍能通过公司的新动作区分“误处理旧单”与“知情准备虚假首单”。玩家动作改变实际交付，且无需先放行损失。相比旧稿，调查对象从客服规则转为自己工作的实际用途。

**仍待反证：**共同交付页是否像方便送罪证；只有一次用途限定与一次回改是否仍像改稿；成功阻止后玩家是否关心以前的工作。本轮只确认条件链与边界可排演，不宣称真人吸引力、十分钟时长或完整诈骗链已通过。需要时可推翻这份后半，不能再加一套客服解释补强。

## 参考游戏：实际走了哪些路

对象是用户给出的[新纪元电视台专栏](https://spectrum.shiroki-y2.top/neweratv.com_20051013_column.html)。2026-10-20 使用桌面 Chrome，选择纯净模式。未读攻略、未用源码取答案；完成的是下面这些探索路径，**没有通关整部作品，也未验证其完整故事或结局**。

| 实际操作与观察 | 对本作有用的判断 | 不照搬什么 |
|---|---|---|
| 从专栏阅读人物及节目背景，退到[存档查询](https://spectrum.shiroki-y2.top/webtimetower.html)，查询预填网址得到两个日期 | 网页给出可追踪的对象，玩家自己决定跨到另一年代；页面用途就是玩法 | 不把公司系统全部做成存档站；公司历史必须有业务上保存的理由 |
| 先选[2008 年](https://spectrum.shiroki-y2.top/neweratv.com_20080410.html)，看到关站通知，再查看[2005 年](https://spectrum.shiroki-y2.top/neweratv.com_20051013.html) | 不同版本形成问题，比任务列表先宣布“这里有异常”自然 | 关站本身不证明犯罪，也不照搬年代或停站情节 |
| 沿节目进入[财经页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_finance.html)，当次页面只有节目横幅及通用导航 | 仿真栏目建立网站感，但入口可能没有调查回报 | 不为“整站完整”堆一排空链接 |
| 输入专栏主持人姓名尝试搜索，收到需先输入密钥的提示；之后该标签控制中断，新标签继续 | 本次没有从所读页面找到密钥去向；搜索前置锁是可记录的障碍 | 不将通用搜索锁在无上下文密码后。浏览器控制故障不能归因为游戏 bug |
| 从[新闻页](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news1.html)点到[论坛讨论](https://spectrum.shiroki-y2.top/externaldata/digitalhome.com_content_it_2620.html)，读到数字和后续读法提示；按楼层、段落、去标点后的字序手算得到一句带威胁感的信息 | 日常聊天既是气氛，也能提供解读方法；发现后同一页面意义改变 | 这是作者手算解释，未获得游戏判定确认。现实办公室不凭空放密码诗，更不复制原谜题 |
| 从新闻进入[访谈](https://spectrum.shiroki-y2.top/neweratv.com_20051013_news_interview.html)，正文部分显示丢失 | 缺失的位置也能提出问题 | 不把所有关键证据都藏在“损坏数据”，更不靠故障特效冒充悬疑 |
| 另以网页读取方式查看[广告服务](https://spectrum.shiroki-y2.top/neweratv.com_adservice.html)，专栏制片人也列在广告联系人中 | 同一人物在两种用途页面中出现，可以提示关系；这是推断入口，不是罪证 | 这一步是补充阅读，不算浏览器试玩完成的分支 |

界面观察：电视台使用固定栏目、面包屑、年代化横幅与页脚；存档站使用另一套外观。统一的存档顶栏帮助辨认时间与站点。新作借用“不同机构有不同页面语言、共同浏览器保留路径”，不照抄其图片、文字、谜底或视觉资产。

本次未验证留言提交、投票结果、搜索解锁、完整音视频和后续全部页面。站内少数入口没有产生导航反馈只是此次观察，不能据此断言所有链接无效。参考提供设计线索，不等于“这部游戏所有机制优秀”。
