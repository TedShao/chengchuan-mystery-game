# 罗青案例：关闭指引的探索与对话修订（v13）

## 试玩方式

使用独立浏览器存档，从序幕进入后关闭指引。先找同事聊天，再沿其可见回复寻找案例页、服务事项和邮件；不按“先读全部材料再作答”的路线。另开新存档，直接沿用共享摘要交稿、采用到培训，随后尝试撤回、修改并重新提交，直到下班。此为开发者认知走查，不是独立陌生玩家的盲测。

## 实际遇到的问题与修复

| 问题 | 调整 |
| --- | --- |
| 问“培训材料在哪里”却讲境外、资金链；问“自己的部分是哪份”无法回答 | 先识别要找文件还是问事实；从开场消息承接“自己的部分”，给正常文件入口，不主动解释矛盾 |
| 表格右侧处理详情容易漏看，经办人没有直接联系入口 | 点击事项编号打开完整记录，保留原字段及经办人联系入口；不标红答案，不新增推理结论 |
| “三项”→“最后那一项”→“谁接的”连续追问失去话题 | 按收件人保留当前话题；多个话题后的含糊追问先澄清 |
| “别催，我只看原来怎么说”退回固定对白 | 区分查看现有片段与发起新询问，取文件仍需要明确确认 |
| 口头转述新信被忽略，或可能当成同事已看原信 | 明确承接转述，但与实际转发分开；不同同事只知道自己收到的材料 |
| 否定、收回伪造指控、改问工资会串到旧话题 | 处理明确否定与焦点修正，保存指控的收回，不将发薪问题当用户款项 |
| 问“我刚才写错了”没有解释已采用稿件的影响 | 根据已发版本与实际培训来源解释后果，提供撤回入口；本机改字不覆盖发送快照 |
| 撤回个人稿后不清楚共享复盘是否还在使用 | 回复当前实际培训来源，保留三种材料各自的版本记录 |
| 人事同事能凭空知道私人报告版本 | 未收到个人稿的同事只指向实际收件人，不能评审内容 |

## 两条完整路线

1. **聊天先行**：询问案例页位置 → 自行打开复盘 → 在工作簿筛选罗青 → 查看事项详情并联系经办人 → 追问状态和接收人 → 明确请求旧记录 → 打开邮件历史比对时间与事项。可以反驳“没有确认不代表没拿到”、暂停询问、质疑引用后收回错误指控；这些聊天不替玩家改表、发邮件或接任务。
2. **误用后恢复**：未核对就把共享摘要用于个人汇报 → 周衡收到发送快照 → 明确采用到培训 → 询问写错后的影响 → 明确撤回个人稿引用 → 确认培训仍使用共享复盘 → 修改个人报告并提交第 2 版 → 刷新后继续并下班。历史发送记录不消失，明日安排与实际稿件来源一致。

## 验证

- `tests/blind-dialogue.cjs`：22 轮自由文本以及跨软件操作；包含否定、改口、多问题、旧事重问、文件请求与任务不误触发、撤回与重交后的持续推进。
- `tests/luoqing-day.cjs`：保留不同调查顺序、漏看材料、普通案例、材料更正、境外意向与后续分工、客户误承诺撤回，以及自由办公和摸鱼的验证。
- 网页游戏标准测试客户端已运行；检查了完整记录与撤回对话的实际截图。
- v13 沿用 v12 存档，刷新恢复后仍保持指引关闭和既有稿件进度。

## 范围

聊天仍为本地有限话题系统，没有接入 AI，也不能理解任意自由文本。无法确定对象时请求澄清；事实来自既有材料和当前流程，实际动作由明确按钮确认。第一天仍不替玩家判定完整犯罪链。
