# 第一工作日：交互边界检查与修复

日期：2026-10-18。本轮针对重复操作、对话记忆、跨软件状态及流程回退进行了检查。测试使用隔离浏览器和游戏存档，不使用真实联系人或外部通信。

## 先复现，再修改

修复前实测：同一句杯子询问连续三次得到完全相同回复；杯子找回按钮点三次产生三条完成通知；切换软件后未发送聊天内容变为空；发送“目前不能认定是诈骗，不要停止业务，先查订单”会进入材料清点并暂停联络。

这说明问题不只是台词重复，而是事件、意图和工作阶段没有分开处理。

## 修复清单

| 问题 | 修改后的行为 | 验证 |
| --- | --- | --- |
| 同一话题不断复读 | 保存按联系人、话题、相关事实划分的对话记忆。首次回应、再次确认后自然结束；有新进展再开放回应 | 找杯子前后重复六次、刷新后重问 |
| 找回杯子可重复完成 | 完成事件仅执行一次，已完成按钮禁用，同时有逻辑层保护 | 完成通知及按钮状态 |
| 找到后快捷问题还在询问是否找到 | 改为确认已经放回；聊完后快捷项显示已讨论状态 | 截图检查 |
| 普通聊天出现不合时宜的早安、午休或催交旧任务 | 回复按实际工作阶段和同事职责选择，已归档时不再催重新交首份材料 | 七阶段、四位同事的全部快捷话题 |
| 否定、疑问、假设或引用被当成停工指令 | 只有明确提出扩大暂停范围才改变分工；否定、问号、假设和引用不触发处罚 | 否定句、无“是否”的问句、直接引述及转发原文 |
| 同一请求反复发人事附件 | 附件授权与通知只执行一次，后续告知仍是现有版本 | 同一事项反复询问及跨阶段矩阵 |
| 再问人事时自动跳走当前窗口 | 已开放字段的询问不再强制切换浏览器 | 首次及重复询问后当前应用不变 |
| 切软件或联系人丢聊天草稿 | 草稿按联系人单独保留，可跨应用及读档继续 | 两位同事不同草稿、应用切换 |
| 邮件草稿退出后丢失 | 收件人、主题、正文和附件保留，发送成功后清除 | 关闭再打开写信窗口 |
| 转发激烈措辞导致处罚 | 处理玩家新写的请求，不将转发原文当成新指令 | 聊天和邮件边界 |
| 外部联系人的“回复”误发周衡 | 已登记客户进入对应联络台；未开放发件人说明当前限制，转发需自行选收件人 | 北辰外部邮件回复；收件人不再默认周衡 |
| 给财务发 PPT 也被当成正式转正汇报 | 只有项目主管或人事咨询入口处理正式汇报；发给其他同事是普通附件快照 | 财务收件后正式提交记录保持不变 |
| 相同报告、邮件、表单重复触发通知与派单 | 重复内容不重复处理，修改后的内容可重新提交 | 相同汇报及表单保护 |
| 后续重交汇报重置下午任务 | 已派发任务中的汇报修订作为补充，继续当前工作；流程变化走当前工作单 | 发布中与归档后重交 |
| 旧表单回访仍能操作失效任务 | 提交前检查当前阶段、联络权限、表单有效性和重复内容 | 主线与分支回归 |
| 客户同一事项不断生成同样回函 | 已回复事项只读，另一个事项可以继续询问；当天归档后保留回函查阅 | 客户核对和主线回归 |
| 空白工作说明或重复用品申请 | 空格说明不通过；同一待审批申请不重复创建，撤回后可合法重新申请 | 相同申请、撤回、再次申请 |
| OA 修改意向与归档结论矛盾 | 当天交接归档后意向只读；显示、计数和审批节点随状态更新 | 归档后修改入口、审批详情 |
| 老存档曾出现“已归档但又被改为清点” | 按完成记录恢复归档状态，保留历史记录及已经确认的意向 | 旧版存档恢复 |
| 导入异常存档破坏当前游玩 | 先验证结构，再整体恢复；失败回滚，当前进度和文件保留 | 损坏报告字段的存档 |
| 导入另一个存档混入当前自建文档 | 自建文档随目标存档替换，不与另一份存档混用 | 旧版导入、重开和源文件隔离回归 |

## 验证范围

- **252 条对话状态测试**：七种阶段 × 四位同事 × 三个快捷话题 × 三次重复。检查普通询问不改变阶段、权限或归档状态；两类人事附件各只授权一次。
- **针对性边界测试**：重复对话、完成后反复操作、跨联系人草稿、否定与引述、邮件路由、归档后重交、重复审批及异常导入。
- **完整流程回归**：三份来源核对、错误处理正常签收的反馈、客户回函与交接；正常接手后的官网发布；扩大停工范围后的权限变更与限定复核恢复。
- **恢复回归**：旧版存档、导入导出、自建文档、重开、源文件隔离、工作表单跨应用与刷新后的保留、其他内网页面及无效地址。
- 运行检查及截图审查未发现本轮场景中的页面错误。

可复用测试保存在 `tests/interaction-edges.cjs` 与 `tests/conversation-matrix.cjs`，运行方式见 `tests/README.md`。七阶段矩阵使用明确构造的合法测试存档；它是程序状态覆盖，不是七次完整盲玩。

本轮没有声称穷尽任意自然语言或所有可能输入。当前对话仍是有限话题系统：不理解的内容会要求澄清，同一事项没有新信息时会结束回应，不会假装理解并凭单个敏感词改变剧情。
